# 你的网站可以优化的地方（只诊断，未做任何改动）

> 检查时间：2026-10-30 ｜ 检查对象：`网站/index.html`（2270 行）、`网站/data.js`、`网站/server.js`
> **我没有修改、删除、移动你的任何文件**，本文件只是建议清单。
> 下面每条都写清：现在是什么样 → 建议改成什么样 → 为什么（对备考有什么用）→ 怎么算做对了

## 零、总体判断

你的网站**内容层已经做得很扎实**：5 门 UNSW 课程、104 个周次/模块（UNSW 92 周 + 课外 12 模块）、180 份周级课件直达链接、402 项任务、101/104 有完整笔记、**104/104 全都有**双语术语表和课前思考题。这比大多数同学手里的资料强得多。

**但它现在是一个「资料库」，不是一个「学习引擎」。** 缺的是中间那一层——**「今天该学什么、该复习什么」的调度能力**。

```
内容层（已有，很好）        调度层（缺）              反馈层（弱）
104 周笔记 / 术语表   →   日期轴 + 间隔队列     →   自测 / 闪卡 / 薄弱点回流
180 份课件 / 402 项任务     今日待办 / 倒计时         把「学过」变成「会做」
```

具体说：**一个同学连续打开你的网站 30 天，网站不会告诉他任何一天该复习哪一周。** 这 30 天的记忆衰减完全没人管——这正是艾宾浩斯排期存在的意义。所以下面的 P0 全部围绕「补上调度层」。

## P0 · 最该做的四件事（对备考收益最大）

### 1. 给周次加上真实日期，首页显示考试倒计时

- **现在**：周次只有「Week 4」这种编号，没有任何日期信息；首页「本周日期」只显示今天几号，和课程进度无关。
- **建议**：每门课每个 Term 加起止日期（例：会计 Term 1 = 2026-03-02 → 2026-06-05），再给每门课加一个「期末考试日期」字段。周面板顶部显示「Week 4 · 11/03 – 11/09」，首页显示「距会计期末 87 天」。
- **为什么**：没有日期，网站永远不知道「今天」该推什么内容给你，复习节奏只能靠外部表格（我现在做的这份日历就是）。有了日期，网站自己就能当排期工具。
- **判据**：随便打开 3 门课，周面板都能看到那一周对应的真实日期；首页能看到每门课的考试倒计时。

### 2. 加「今日待复习」队列（间隔重复引擎）

- **现在**：进度只有「标记本周完成」一个开关，没有「上次复习时间 / 下次到期时间」的概念。
- **建议**：每个周次记录 3 个字段：上次复习日期、复习次数、下次到期日。按 1 / 3 / 7 / 15 / 30 天的间隔自动算下次到期；首页和课程页顶部出现「今日到期复习：N 项」的列表，勾掉一项，下次到期日自动往后推。
- **为什么**：这是整个网站唯一能直接对抗遗忘的功能。内容再好，不按节奏回头复习，考场上也提取不出来。
- **判据**：连续用 7 天后，首页每天都能列出当天该复习的周次；勾掉后不再出现在今天，且按间隔在对应日期重新出现。

### 3. 掌握度改成四态（现在的二元勾选会骗人）

- **现在**：只有「标记本周完成 / 未完成」。打开笔记看两眼就能打勾，但打勾 ≠ 会做。
- **建议**：`未学习 → 已阅读 → 练习中 → 已掌握` 四态。**「已阅读」只能手动点（打开页面不许自动标记）**；「练习中」在你提交练习后自动进入；「已掌握」必须由测试结果或你手动确认。
- **为什么**：二元状态会让「看过了」冒充「学会了」，进度条虚高，真正薄弱的周次被埋掉。
- **判据**：只打开笔记不做任何操作，状态必须停在「未学习」；各状态的数字能和你的实际记录对上。

### 4. 把「考前复习」页补齐到全部 5 门

- **现在**：6 门课里**只有计算机 1 门**有 `examReview` 内容（分「必考 / 可能考 / 了解」三档筛选）。其余 4 门 UNSW 课程点进去是「正在整理中」。
- **建议**：按计算机那套格式（章节 → 考点 → 必考/可能考/了解）补齐会计、经济、数学、学术英语，并让它和第 2 条的复习队列联动——「必考」档自动排进高频循环。
- **为什么**：考前 10 天你最需要的就是这种「按概率排序的考点清单」，现在只有一门有，等于其他 4 门考前要临时手搓。
- **判据**：5 门课都能打开考前复习页，且能按三档筛选；每门至少覆盖 10 个考点。

## P1 · 明显提升学习效率

### 5. 用现成的术语表生成闪卡自测

- **现在**：104 个周次**全都有**双语术语表（英文 + 中文 + PPT 英文释义），但只是静态陈列，没有任何自测功能。
- **建议**：术语表加一个「闪卡模式」——正面英文术语，背面中文 + 释义，两个按钮「认识 / 不认识」；不认识的自动进入第 2 条的复习队列并缩短间隔。
- **为什么**：这是全站**成本最低、收益最高**的一个改动——数据是现成的（98 周全覆盖），只是缺一层交互。碎片时间刷闪卡，比反复读笔记有效得多。
- **判据**：任意一周的术语表都能进入闪卡模式，点「不认识」后该术语第二天会再次出现。

### 6. 让薄弱点回流到复习安排（现在档案和复习是断开的）

- **现在**：「学习档案」会统计薄弱知识点（按出现次数排序，可点击筛选），但这些数据**只用于展示**，不会影响任何学习安排。
- **建议**：档案里出现 ≥ 2 次的薄弱点，自动把对应周次的复习间隔缩短一档（比如从 7 天降到 3 天），并在首页标红提示。
- **为什么**：薄弱点如果只统计不干预，就等于记了一本账却不去还债。
- **判据**：在档案里录入一个出现 3 次的薄弱点后，对应周次在 3 天内出现在「今日待复习」。

### 7. 计算机这门课的课件链接是空的（⚠️ 建议优先核对）

- **现在**：计算机 26 个周次里，**周级课件链接 = 0 份**，课程级 `generalFiles` 也是 0 —— 整门课在网站里一份可点的课件都没有。但你的课程文件夹里实际有 **143 个文件**（56 个 xlsx、46 个 pdf、20 个 docx…）。
- **另一个相关发现**：所有课程还有一个 `generalFiles` 字段（共 **151 份**，其中经济 134 份），但 `index.html` 里**从来没有渲染过这个字段**，所以这 151 份在页面上是看不见的。
- **为什么重要**：计算机是**上机考试科目**，练习文件（Excel 作业、练习考试卷）就是最重要的复习材料。现在做计算机那一周的复习块，你得自己去文件夹里翻文件。
- **建议**：① 先把计算机的课件按周挂回去（26 个周次）；② 给 `generalFiles` 加一个「本课程其他资料」入口，别让 151 份文件闲置。
- **判据**：计算机的 26 个周次里，至少 A 档那 12 周能直接点到课件；课程页能看到「本课程其他资料」分组。
- ⚠️ **另外提醒一句**：2026-10-26 那份盘点文档里记的是「342 份课件链接」，现在是 180 份。这个落差（主要是计算机的 121 份不见了）建议你让我查一次是重建时漏了，还是统计口径变了。

### 8. 补齐「课后作业答案」和「PPT 内例题」

- **现在**：`tutorialAnswers`（课后作业答案）只有 **38/104** 有，`examplesHtml`（PPT 内例题）只有 **37/104** 有。剩下 60 多个周次的这两个标签点开是空占位。
- **建议**：至少把 A 档（必考核心）周次的答案和例题补齐，或者干脆把空标签撤掉，避免每次点开都是空的。
- **为什么**：备考阶段最值钱的不是笔记正文，是**题 + 答案**。现在超过一半的周次没有答案可对照，自测闭环断在这里。
- **判据**：会计、经济、学术英语三门的核心周次，答案和例题 100% 有内容，不再是空占位。

### 9. 加「导出 Word / PDF」按钮（离线背、能打印）

- **现在**：页面里**没有任何导出入口**，只有 JSON 格式的进度/档案导出。
- **建议**：每篇笔记加两个按钮，导出的文件包含图表、例题、术语表、课前思考；分页规则要避免表格和图被切断。
- **为什么**：好消息是——**分页打印规则你已经写好了**，在 `网站/notes-quality.css` 里（`break-inside: avoid`、按 Unit 另起页、孤行控制、打印时隐藏标签栏），但这个文件**从来没有被 `index.html` 引用过**（目前外链只有 data.js / records.js / progress.js）。所以这不是从零做，是把现成的零件装上去。
- **判据**：导出的 PDF 逐页翻，表格和图没有被切断；Word 里标题层级正确、公式可读。

### 10. 让 AI 助手真的读到课件（并把 source-reader 接进来）

- **现在**：右下角 AI 助手发给后端的上下文，只是「课程名 + 周次 + 知识点词 + 学习目标」拼成的一小段字符串（约 2000 字上限）。**课件逐页文字没进上下文，笔记正文也没进，回答不标来源页码。**
- **建议**：提问时自动带上当前 Unit 的课件逐页文字 + 该周笔记全文；回答中标注依据（如 `Per Lecture Slides p.12`）；课件里找不到的内容必须写明「以下为补充解释，课件中未出现」。同时把已经写好但没用的 `source-reader.js`（逐页原文阅读器）接进来，让 AI 引用的是同一份逐页索引。
- **为什么**：现在的 AI 只能给通用回答，答不了「课件里那个例题的具体数字」——而对备考来说，通用回答几乎没有价值。
- **判据**：随便问一个只有课件里才有的细节，AI 能答对并给出页码。

**顺带一个很实用的小改动**：AI 面板在**双击 index.html 打开**（没有本地服务）时会报错。建议在打不开时直接给一个按钮：「复制问题 + 当前周上下文，去问 ChatGPT」——这样两种打开方式都能用。

## P2 · 打磨项（有空再做）

### 11. 搜索增强

现在搜索能搜到笔记正文（这点不错），但有三个限制：命中上限 **12 条**、没有关键词高亮、点进去后不会自动定位到命中位置。建议提到 30 条、加高亮、跳转后自动滚动到命中处，并把「核心术语」单独加进索引（现在术语不在索引里，搜术语只能靠正文里碰巧出现）。

### 12. 数学的 3 个缺口 + 公式排版

数学 Term 1 有 **3 个周次没有完整笔记**（只有预习笔记）；另外笔记里存在 `a^m·a^n`、`1/(√a+√b)` 这类编程式公式写法。建议按你自己定的规范补齐：真分式、上下标用 sup/sub、根号规范书写。这一项按你的科目优先级排在最后，但**轮到它的时候别走「逐页转写」的偷懒路径**。

### 13. 三色标记的密度

完整笔记正文里红色标记 **54 处**、蓝色标记 **4 处**（另有 **49 篇**完整笔记一个红色标记都没有）。按你定的规范：红色 = 重要规则/易错点，蓝色 = 例题与演算。现在蓝色几乎没用上，考前快速扫读时抓不住「哪里是例题、哪里是结论」。建议至少在例题和完整演算过程上补蓝。

### 14. 笔记内嵌图片偏少

全部完整笔记里只有 **7 处**内嵌图片（`sources/*.webp` 逐页截图），经济学主要靠构建期替换的 SVG 图。图表型科目（经济、数学）在关键图（AD-AS、成本曲线、函数图像）上建议保留原图，考前扫图比读文字快。

### 15. 备份提醒

学习进度和成绩存在浏览器 localStorage，换浏览器/清缓存会丢。档案页已有「导出/导入/复制进度」三个按钮（这点做得对），但**没有任何提醒**。建议加一个「距上次备份 X 天，超过 7 天请导出一次」的提示——你现在 87 天的排期全靠这份数据，丢了很麻烦。
