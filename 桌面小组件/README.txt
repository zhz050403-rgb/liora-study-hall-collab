学习小屋 · 桌面待办小组件（Windows 电脑版，免安装）

【第一次使用，3 步】
1. 第一次打开时若显示登录页，在小卡片里登录一次网站（用你平时的同一个账号）。
2. 右键下载的压缩包 →「全部解压缩」→ 打开解压出来的文件夹。
3. 双击 START-HERE.cmd。

几秒后，桌面右下角会出现一块小卡片，直接显示待办清单，不用点开就能看见。
可以直接在小卡片里加一条、打勾、双击文字改内容。

【以后开机】
第一次运行时会自动设置开机自启，以后开机小卡片会自己出现，完全不用点。
不想让它开机自动出现：双击 STOP-AUTOSTART.cmd。
请注意：解压出来的这个文件夹要留在一个固定位置（例如桌面），不要删掉。

【小卡片上的按钮】
↗  打开完整的学习小屋网站
×  关闭小卡片（也可以按 Alt+F4）
小卡片默认固定在右下角、浮在其他窗口前面。想让它不挡着，按 Alt+F4 关掉即可；
想再打开，重新双击 START-HERE.cmd。

【如果双击没反应，或弹出蓝色提示】
Windows 有时会拦截从网上下载的文件：
  · 在提示里点「更多信息」→「仍要运行」；
  · 或右键 START-HERE.cmd →「属性」→ 勾选「解除锁定」→ 确定，再双击。

【数据是不是和网站同一份？】
是。小卡片显示的就是网站里的待办，用同一个账号、同一份云同步。
在小卡片里打勾，网站首页、手机和平板都会跟着变；反过来也一样。

【小卡片打开后是登录页？】
小组件用的是一个独立的专用小窗口，第一次需要在里面登录一次（和平时浏览器是同一个账号）。
登录一次之后它自己会记住，以后开机自动出现时不用再登。登录用的是网站原账号，
所以待办和网站、手机平板仍然是同一份，会互相同步。
