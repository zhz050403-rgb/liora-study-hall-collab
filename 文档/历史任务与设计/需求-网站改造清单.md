### 3. 每个周面板里有什么

1. 顶部：WEEK N · 学期、标题、知识点标签、标记完成按钮、学习目标数 / 课件数 / 任务完成数
2. 学习目标（3–6 条）
3. 学习笔记（**三标签**）：
   - `笔记`（默认打开，优先显示 graphicHtml 完整笔记，没有就退回 notesHtml）
   - `PPT内例题`（字段 `examplesHtml` —— **0/97 全空**）
   - `课后作业答案`（字段 `tutorialAnswers` —— **0/97 全空**）
   - 笔记末尾附「课前思考」问题（97/97 都有）
4. 核心术语表（英 + 中 + PPT 英文释义，97/97）
5. 本周课件（342 份，按 lecture / tutorial / worksheet / exam 分组，点击新窗口打开）
6. 本周任务清单（382 条，可勾选，进度条实时更新）
7. 进度保存：localStorage 主通道 + `progress.js` 备用通道

### 4. 三色与图表现状

- `.c-red` 全站 162 处、`.c-blue` 244 处 —— 红蓝体系在用，只在关键句上
- 会计学 W12 是唯一有完整笔记但**零红蓝标记**的周次
- 笔记内嵌图片 15 组（`sources/*.webp` 逐页截图），经济图谱靠构建期 `[[DIAG:key]]` 替换成 SVG
- 有 `@media print` 样式，但只做了「隐藏导航/侧栏」最基础的一层

### 5. 已经写好但**没有接进页面**的零件（重要）

- `网站/source-reader.js` + `source-reader.css`：逐页原始资料阅读器，能按页翻课件原文、能记录每页阅读状态（`liora-source-reading-v1`）
- `网站/notes-quality.css`：笔记质量样式，里面**已经写好**了整套打印规则 ——
  - `table / tr / figure / .diagram { break-inside: avoid }`（表格和图不跨页断裂）
  - `.unit-start { break-before: page }`（按 Unit 另起页）
  - `p { orphans:3; widows:3 }`、`h1-h4 { break-after: avoid }`（孤行控制）
  - `.note-tabs / .task-row / .prep-q` 打印时隐藏（只留正文）
  - 还带 `.page-coverage` 逐页覆盖折叠块和 `.gx-page` 逐页结构
- 这两样在 `index.html` 里**一次都没被引用**，属于上一轮做到一半的成果

> 所以「Word + PDF 导出」不是从零做：分页排版规则已经躺在 `notes-quality.css` 里了，缺的是导出按钮 + 生成 docx/pdf 的链路 + 把 CSS 挂上去。

### 6. 两个容易误判的地方

1. **数学没有完整笔记不是漏做**——是 2026-10-26 你自己说的「数学暂时不需要做笔记，只给核心概念就好」，我当时删掉了 14 周的 `graphicHtml`，只留预习笔记。所以要恢复它属于**改主意**，不是修 bug。
2. **`notes-review-status.json`** 里记着每周的核对状态（`legacy; page-by-page explanation not verified` / `rewritten; partial visual verification`），可以直接用它生成「哪些周需要重做」的清单，不用重新盘一遍。

## 三、可以直接复制给我的话术

> 用法：整段复制发给我即可。每条都写了「要什么 + 不许动什么 + 怎么算做对」，避免我做完你还要返工。### 话术 1（最高优先）：恢复数学完整笔记

```
我之前说过数学只留核心概念就好，现在改主意了，数学也要做成完整笔记，
标准和其他科目一样：

1. 公式必须是真排版，不许出现 a^m·a^n、1/(√a+√b)、x^2 这种写法。
   分数用真分式，上下标用 sup/sub，根号用 √ 加覆盖线，对数写 log_a x 的正确下标。
2. 每个知识点英文定义在前、中文解释紧跟，保留英文术语。
3. 每个公式后面必须有 1 道数值例题，写出完整演算步骤（不能只给答案）。
4. 原来的 notesHtml 不要删，改完放进 graphicHtml，notesHtml 留作课前预习入口。
5. 逐页对照原始课件，不许编造；课件里没有的内容标成「补充解释」。

验收：我不打开原 PPT，只看这一篇也能把这个 Unit 学会。
先做 Term 1 Week 1–4 给我看，我确认格式对了再往后推。
```

### 话术 2（最高优先）：笔记页统一成设计稿框架

```
把每周的笔记区重构成统一框架，按我发的设计稿来：

顶部信息条：ACCOUNTING · TERM 1 · UNIT 4 / 标题 / 关联课件 · 笔记版本 · 最近核对日期
三个标签：课前预习 | 完整笔记（默认打开）| 考前复习

- 课前预习 = 现在的 notesHtml + 课前思考问题
- 完整笔记 = 现在的 graphicHtml
- 考前复习 = 从完整笔记里抽出来的 Key points + Common Mistakes + Exam Tips，自动生成一份精简版

现在那两个空着的「PPT内例题」和「课后作业答案」标签先撤掉，不要留着占位。
已有勾选进度和成绩记录一点都不许动。

验收：随便打开 3 个不同科目，顶部信息条都在、三个标签都能切、默认停在完整笔记。
```

### 话术 3：Word + PDF 导出

```
给每篇笔记加「导出 Word / 导出 PDF」两个按钮，要真能用的下载，不是打印预览。

1. 分页规则直接用你已经写在 notes-quality.css 里的那套，把它接进 index.html：
   表格和图不跨页断裂、按 Unit 另起页、段落孤行控制。
2. Word（.docx）：一个 Unit 一个文件，按 Unit 分节，标题层级正确，公式尽量保持可编辑。
3. PDF：页眉页脚带课程名和页码，图不许被裁断。
4. 导出内容 = 完整笔记全文（含图表、例题、术语表、课前思考），不是只导当前视口。
5. 文件名格式：Accounting_Term1_Unit4_Recording-Transactions.docx

验收：下载下来逐页翻，检查分页和打印效果，不能只看网页预览。
先做会计 Week 3 一个样本给我看。
```

### 话术 4：让 AI 真的读到课件

```
把右下角 AI 助手改成真正绑定当前课件：

1. 提问时自动带上：当前课程、Unit、对应的课件逐页文字、以及这篇笔记全文（不是只带知识点词）。
2. 回答里要标出依据来自哪一页（例：Per Lecture Slides p.12）。
3. 课件里找不到依据的内容，必须明确写「以下为补充解释，课件中未出现」。
4. 页面上已经写好的 source-reader.js 接进来，让 AI 引用的是同一份逐页索引。
5. 不许用笼统的通用回答冒充课件内容。

验收：我随便问一个只有课件里才有的细节（比如某个例题的具体数字），AI 能答对并给出页码。
```

### 话术 5：真实学习进度

```
把学习进度改成真实四态，不要用浏览行为冒充掌握：

状态：未学习 → 已阅读 → 练习中 → 已掌握
- 「已阅读」只能由我手动点，打开页面不许自动标记
- 「练习中」在我提交作业/练习后自动进入
- 「已掌握」必须由测试结果或我手动确认

统计分两栏，不许混在一起：
- 任务完成率（勾选了几个任务）
- 测试结果（成绩记录里的得分率）

验收：我只打开笔记不做任何操作，进度必须是「未学习」；两项统计数字能对得上各自的原始记录。
构建 data.js 之后，勾选状态、任务进度、成绩记录三项一条都不能丢。
```

## 四、建议执行顺序

1. 话术 2 → 框架先定下来，后面所有笔记都按这个框架写，越晚改越贵
2. 话术 3 → 分页规则现成，成本最低、见效最快（能拿 PDF 离线背）
3. 话术 1 → 数学是要撤销你今天的精简决定，工作量最大（14 周 × 完整笔记 + 公式重排），放第二批
4. 话术 4 → 依赖 source-reader 接入
5. 话术 5 → 独立于内容，可以并行，但会改存储结构，建议单独一轮

如果只想先看到变化：先做话术 2（框架）＋话术 3（导出）在会计、经济、学术英语三门的样本上，数学放到最后。

按你之前定的科目优先级（经济 = 会计 = 学术英语 > 计算机 > 数学），前三条正好落在前三门，数学本来就在末位，所以「恢复数学完整笔记」和优先级不冲突，只是要排在框架定稿之后。
