例 2（Tutorial 0 Terms） Explain: Circular Flow of Income; Leakage; Injection; Expansion; Contraction; Equilibrium; Disequilibrium.

Circular Flow of Income：收入、产出和支出在各经济部门之间持续循环的模型；产出产生收入，收入又用于支出，O = Y = E。
Leakage（漏出）：离开循环、不再直接用于购买国内产出的收入，即储蓄 S、税收 T、进口 M。
Injection（注入）：不是来自家庭消费、新加入循环的支出，即投资 I、政府支出 G、出口 X。
Expansion（扩张）：注入大于漏出，收入、产出和就业上升，循环变大，可能带来通胀。
Contraction（收缩）：漏出大于注入，收入、产出和就业下降，循环变小，失业上升。
Equilibrium（均衡）：漏出 = 注入，Y = E，经济活动水平没有变动趋势。
Disequilibrium（非均衡）：漏出 ≠ 注入，Y ≠ E，经济活动水平在变化。

例 3（Tutorial 0 Q1） Identify the 2 sectors in a Two Sector circular flow model. What are their functions?

两个部门是家庭和企业。家庭拥有并提供生产要素（土地、劳动、资本、企业家才能），用得到的收入购买商品和服务；企业雇用这些要素生产商品和服务，卖给家庭。

Two-sector model: money flows (gold) and real flows (navy) in opposite directions

例 4（Tutorial 0 Q2） Identify the money flows and the real flows in the Two Sector model.

实物流（real flows）：家庭向企业提供生产要素；企业向家庭提供商品和服务。
货币流（money flows）：企业向家庭支付要素收入（工资、租金、利息、利润，即 Y）；家庭向企业支付消费支出（E）。两种流向方向相反。

例 5（Tutorial 0 Q3） With the aid of the Three Sector circular flow model explain the concept of equilibrium.

三部门加入金融部门：家庭把收入一部分消费、一部分储蓄，Y = C + S；企业的收入来自消费和投资，E = C + I。储蓄是漏出，投资是注入（金融部门把储蓄借给企业投资）。
均衡要求 Y = E，即 C + S = C + I，S = I：漏出等于注入，收入、产出、就业没有变动趋势。

Three-sector model: equilibrium when S = I

例 6（Tutorial 0 Q4） In the Three Sector model, what happens to the level of economic activity if savings are greater than investment?

S > I 表示漏出大于注入：从循环中流出的钱多于流回的钱。总支出 E 低于收入 Y，企业的商品卖不完，于是减产、少雇人。收入、产出、就业下降，循环收缩（contraction），失业上升，直到收入降到 S 重新等于 I 为止。

例 7（Tutorial 0 Q5） What is the effect on the Four Sector model if the government budgets for a deficit (G > T)?

四部门的均衡条件是 S + T = I + G。预算赤字 G > T 表示政府注入的支出多于从税收中取走的钱。若其他条件不变（S、I 不变），注入 I + G 大于漏出 S + T，总支出增加，企业扩大生产、多雇人，收入和就业上升，循环扩张；需求增长过快时可能带来通胀压力。

例 8（Tutorial 0 Q6） Identify all the injections and leakages in the Five Sector Model.

注入：投资（I）、政府支出（G）、出口（X）。
漏出：储蓄（S）、税收（T）、进口（M）。
均衡：S + T + M = I + G + X。

Five-sector model: leakages S + T + M (red), injections I + G + X (green)

例 9（Tutorial 0 Q7） In a Five Sector Model, how could unemployment occur and what strategies might be used to restore employment?

当漏出 S + T + M 大于注入 I + G + X 时（例如家庭储蓄增加、企业投资下降、出口减少或进口增加），总支出低于产出，企业减产裁员，出现失业。
恢复就业的办法是增加注入或减少漏出：①政府增加支出 G 或减税 T（扩张性财政政策）；②降低利率，鼓励借贷和投资 I、减少储蓄 S（扩张性货币政策）；③本币贬值或扩大出口市场，增加 X、减少 M。

例 10（Tutorial 0 Writing） Possible writing task: With the aid of a circular flow model explain the effect if the government budgets for a surplus.

预算盈余指政府税收 T 大于政府支出 G。在循环流量模型中，T 是漏出，G 是注入，所以盈余意味着政府从循环中取走的钱多于放回的钱。
若储蓄、投资、出口和进口不变，漏出 S + T + M 将大于注入 I + G + X，总支出 E 低于收入 Y。企业面对需求下降会减少产出、少雇工人，收入和就业下降，循环收缩（contraction）。
结论：预算盈余是收缩性的，会降低经济活动水平；在经济过热、通胀上升时，政府可以用盈余给经济降温。（答题时画出五部门循环流量图，标出 T 和 G 的方向并说明 T > G。）
