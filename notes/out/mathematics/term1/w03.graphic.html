顶点式抛物线（L7）

L07_Graphs_of_Parabolas_and_Hyperbolas.pdf · PDF p1–2

概念
y = x² 是最基本的抛物线：偶函数（关于 y 轴对称），定义域全体实数，值域 y ≥ 0，顶点 (0, 0)。
用上周的变换得到顶点式 y = a(x − h)² + k：先右移 h、再按 a 拉伸或翻折、最后上移 k。顶点 (h, k)；a > 0 开口向上（顶点是最低点，值域 y ≥ k），a < 0 开口向下（顶点是最高点，值域 y ≤ k）。
画图要标出：顶点、y 截距（令 x = 0）、x 截距（令 y = 0，可能没有）。
求方程：已知顶点 (h, k) 就先写 y = a(x − h)² + k，再代入图上另一个点解出 a。
y = a(x − h)² + k　顶点 (h, k)　a > 0 向上，a < 0 向下

例 1（L7 Ex 1） Using the graph of y = x² and transformation methods sketch each parabola, showing the main features: (a) y = x² + 1 (b) y = 3(x + 1)² (c) y = ½(x − 2)² (d) y = (x + 2)² − 1 (e) y = 9 − x² (f) y = 4 − (x − 2)²

看解答

每题先读出顶点和开口方向，再求截距。
(a) y = x² 上移 1：顶点 (0, 1)，开口向上，没有 x 截距，y 截距 1。
(b) 左移 1、纵向拉伸 3 倍：顶点 (−1, 0)（与 x 轴相切），y 截距 3(0 + 1)² = 3。
(c) 右移 2、压缩一半：顶点 (2, 0)，y 截距 ½ × 4 = 2。
(d) 左移 2、下移 1：顶点 (−2, −1)；令 y = 0：(x + 2)² = 1，x + 2 = ±1，x = −1 或 −3；y 截距 4 − 1 = 3。
(e) y = −x² + 9：开口向下，顶点 (0, 9) 是最高点；令 y = 0：x² = 9，x = ±3。
(f) 开口向下，顶点 (2, 4)；令 y = 0：(x − 2)² = 4，x = 0 或 4；y 截距 4 − 4 = 0（过原点）。
注：讲义 L07 p1「The General Parabola」处写的 Range: y ≥ 0 是从 y = x² 那一栏照抄的，对 y = a(x − h)² + k 应为 y ≥ k（a > 0）或 y ≤ k（a < 0）。

(a) y = x² + 1

(b) y = 3(x + 1)²

(c) y = ½(x − 2)²

(d) y = (x + 2)² − 1

(e) y = 9 − x²

(f) y = 4 − (x − 2)²

例 2（L7 Ex 2） Find the equation of each parabola: (a) vertex (2, 6), passing through (0, 4); (b) vertex (1, −2), x-intercepts 0 and 2.

看解答

顶点已知，先写顶点式，再代一个点求 a。
(a) y = a(x − 2)² + 6，代 (0, 4)：4 = 4a + 6，a = −½。y = −½(x − 2)² + 6。
(b) y = a(x − 1)² − 2，代 (0, 0)：0 = a − 2，a = 2。y = 2(x − 1)² − 2（展开得 y = 2x² − 4x），验证 x = 2 时 y = 0。
Answer: (a) y = −½(x − 2)² + 6 (b) y = 2(x − 1)² − 2

(a) y = −½(x − 2)² + 6

(b) y = 2(x − 1)² − 2

易错
① y = 3(x + 1)² 的顶点写成 (1, 0)：括号里是 + 就向左。
② y = 9 − x² 当成开口向上。
③ 求方程时忘了 a，直接写 y = (x − 2)² + 6：要用另一点解出 a。
常见疑惑
问：讲义说一般抛物线的值域是 y ≥ 0，对吗？ 不对。y = a(x − h)² + k 在 a > 0 时值域是 y ≥ k，a < 0 时是 y ≤ k；只有 k = 0、a > 0 时才是 y ≥ 0。见例 1 的注。

双曲线与渐近线（L7）

L07_Graphs_of_Parabolas_and_Hyperbolas.pdf · PDF p3–5

概念
基本双曲线 y = 1/x：两支，x ≠ 0、y ≠ 0；x 轴、y 轴是渐近线（曲线无限接近但不相交）。奇函数。
一般形式 y = ax − h + k：竖直渐近线 x = h（分母为 0），水平渐近线 y = k；定义域 x ≠ h，值域 y ≠ k。a > 0 两支在渐近线交点的右上、左下（讲义说「第 1、3 象限」）；a < 0 在左上、右下（第 2、4 象限）。
画图步骤：①画两条渐近线（虚线）；②求 y 截距（x = 0）和 x 截距（y = 0）；③按 a 的符号画两支。
求方程：从图读出两条渐近线，写 y = a/(x − h) + k，再代入一点求 a。
y = ax − h + k　渐近线 x = h、y = k

例 3（L7 Ex 3） Sketch, showing asymptotes and intercepts: (a) y = 2x − 1 (b) y = 1 − 1x (c) y = 1x + 1 + 2

看解答

(a) 分母 x − 1 = 0：竖直渐近线 x = 1；没有加常数，水平渐近线 y = 0。y 截距 2/(0 − 1) = −2；分子不为 0，没有 x 截距。
(b) 改写为 y = −1x + 1：a = −1，两支在左上、右下。渐近线 x = 0、y = 1。x 截距：1/x = 1，x = 1；x = 0 无定义，没有 y 截距。
(c) 渐近线 x = −1、y = 2。y 截距 1 + 2 = 3；x 截距：1/(x + 1) = −2，x + 1 = −½，x = −32。

(a) y = 2/(x − 1)

(b) y = 1 − 1/x

(c) y = 1/(x + 1) + 2

例 4（L7 Ex 4） Write down the equations of the asymptotes for the hyperbola y + 2 = 11 − x and hence sketch the graph.

看解答

先化成标准形式：y = 11 − x − 2 = −1x − 1 − 2，a = −1。
渐近线 x = 1、y = −2；两支在左上、右下。
y 截距：1/1 − 2 = −1；x 截距：1/(1 − x) = 2，1 − x = ½，x = ½。

y + 2 = 1/(1 − x)

例 5（L7 Ex 5） The graph shown is a transformation of f(x) = 1x (asymptotes x = 1 and y = −1, passing through the origin). Find its equation.

看解答

写 y = ax − 1 − 1，代 (0, 0)：0 = −a − 1，a = −1。
y = −1x − 1 − 1，也可以写成 y = 11 − x − 1。
Answer: y = 1/(1 − x) − 1

y = 1/(1 − x) − 1

例 6（L7 Ex 6） The graph shown has an equation of the form y = ax − h + k (asymptotes x = −2 and y = 3, passing through (0, 4)). Find its equation.

看解答

写 y = ax + 2 + 3，代 (0, 4)：4 = a/2 + 3，a = 2。y = 2x + 2 + 3。
Answer: y = 2/(x + 2) + 3

y = 2/(x + 2) + 3

易错
① 竖直渐近线符号读反：x + 1 = 0 得 x = −1。
② 把 y + 2 = … 的 +2 当成水平渐近线 y = 2：移项后是 y = … − 2。
③ 1/(1 − x) 与 1/(x − 1) 当成同一个：两者相差一个负号，两支位置相反。
常见疑惑
问：双曲线会穿过渐近线吗？ y = a/(x − h) + k 这种形式不会：x = h 处没有定义，而 a/(x − h) 永远不等于 0，所以 y 永远不等于 k。

一般式抛物线：顶点与最大最小值（L8）

L08_More_Parabolas_Max_Min_Quadratic_Inequalities.pdf · PDF p1–2

概念
一般式 y = ax² + bx + c：a > 0 开口向上，顶点处 y 取最小值；a < 0 开口向下，顶点处 y 取最大值。
求顶点的三种方法：①x = −b2a；②已知 x 截距 α、β 时，x = ½(α + β)（对称轴在两根正中间）；③配方。求出 x 后代回原式得到顶点的 y。
与 x 轴的交点个数：两个、一个（相切）或没有，就是 ax² + bx + c = 0 的实数解个数（判别式 b² − 4ac 大于、等于或小于 0）。
顶点 x = −b2a = ½(α + β)
Δ = b² − 4ac：> 0 两个交点，= 0 一个，< 0 没有

例 7（L8 Ex 1） Sketch the parabola y = x² − 2x − 3 showing the intercepts and the vertex. State the minimum value of the function.

看解答

因式分解：y = (x − 3)(x + 1)，x 截距 −1、3；y 截距 −3。
顶点 x = ½(−1 + 3) = 1（或 −b/2a = 2/2 = 1），y = 1 − 2 − 3 = −4，顶点 (1, −4)。
a = 1 > 0，最小值 −4。
Answer: 最小值 −4（x = 1 时）

y = x² − 2x − 3

例 8（L8 Ex 2） Sketch the parabola y = 9x − x². Find the maximum value of the function. State the equation of the axis of symmetry and show it on the sketch.

看解答

y = x(9 − x)，x 截距 0、9；a = −1 < 0，开口向下。
对称轴 x = ½(0 + 9) = 4½；最大值 y = 9 × 4.5 − 4.5² = 40.5 − 20.25 = 20¼。
Answer: 最大值 81/4 = 20¼；对称轴 x = 4½

y = 9x − x²

例 9（L8 Ex 3） Sketch the parabola y = x² − 3x + 7 showing the main features.

看解答

判别式 (−3)² − 4 × 1 × 7 = 9 − 28 = −19 < 0：没有 x 截距，整条曲线在 x 轴上方。
顶点 x = 3/2，y = 9/4 − 9/2 + 7 = 19/4，顶点 (1½, 4¾)；y 截距 7。
Answer: 顶点 (3/2, 19/4)，y 截距 7，无 x 截距

y = x² − 3x + 7

易错
① −b/2a 的负号漏掉：y = 9x − x² 中 a = −1、b = 9，x = −9/(−2) = 4.5。
② 求了顶点 x 不代回求 y。
③ 判别式为负时硬去「因式分解」。
常见疑惑
问：「最小值」要写 x 还是 y？ 最小值指 y 的值（如 −4）；「在 x = 1 处取到」是另外的信息，两者都写最稳。

二次不等式（L8）

L08_More_Parabolas_Max_Min_Quadratic_Inequalities.pdf · PDF p3–4

概念
解二次不等式：①把所有项移到一边，变成 ax² + bx + c > 0（或 <、≥、≤）；②求出 = 0 时的根；③画出抛物线，看曲线在 x 轴上方（> 0）还是下方（< 0）的部分，阴影标出对应的 x。
开口向上时：< 0 是两根之间，> 0 是两根之外。≤、≥ 包括端点（实心），<、> 不包括（空心）。
没有实根时，整条抛物线在 x 轴一侧：要么全体实数都满足，要么无解。

例 10（L8 Ex 4） Solve the quadratic inequality x² − 3x − 4 < 0.

看解答

(x − 4)(x + 1) < 0，根 −1、4。开口向上，曲线在两根之间位于 x 轴下方：−1 < x < 4。
Answer: −1 < x < 4

x² − 3x − 4 < 0: below the x-axis

例 11（L8 Ex 5） Solve the inequality (x + 2)(x + 3) ≤ (2x − 1)(x + 3).

看解答

不能两边同除以 (x + 3)：它可能是负数或 0。把所有项移到左边并提取公因式：
(x + 3)[(x + 2) − (2x − 1)] ≤ 0
(x + 3)(3 − x) ≤ 0，两边乘 −1 并变号：(x + 3)(x − 3) ≥ 0。
开口向上，两根之外（含端点）：x ≤ −3 或 x ≥ 3。
Answer: x ≤ −3 或 x ≥ 3

(x + 3)(x − 3) ≥ 0: on or above the x-axis

例 12（L8 Ex 6） Solve the inequality x² − 4x + 5 ≤ 0.

看解答

判别式 16 − 20 = −4 < 0，没有实根。配方 y = (x − 2)² + 1，最小值 1 > 0，曲线始终在 x 轴上方，所以 ≤ 0 无解。
Answer: 无实数解

y = x² − 4x + 5 never reaches y ≤ 0

例 13（L8 Ex 7） Solve the inequality 9 − 2x − x² > 0.

看解答

乘 −1 并变号：x² + 2x − 9 < 0。根 x = (−2 ± √(4 + 36))/2 = −1 ± √10。
y = 9 − 2x − x² 开口向下，在两根之间位于 x 轴上方：−1 − √10 < x < −1 + √10（约 −4.16 < x < 2.16）。
Answer: −1 − √10 < x < −1 + √10

9 − 2x − x² > 0: above the x-axis

易错
① 两边同除含 x 的式子（例 11），会丢掉 x ≤ −3 那一段。
② 乘 −1 后忘记变号。
③ 把 −1 < x < 4 写成 x < 4 且 x > −1 以外的形式，或端点虚实写错。
常见疑惑
问：为什么一定要画图？ 画图后「上方还是下方」一眼可见，不用死记「大于取两边、小于取中间」，开口向下时也不会弄反。

绝对值图像（L9）

L09_Absolute_Value_Graphs.pdf · PDF p1–3

概念
|x| = x（x ≥ 0），|x| = −x（x < 0）。y = |x| 是 V 形，顶点在原点，顶点处是尖角。
变换：y = |x − h| + k 的顶点在 (h, k)；前面加负号 y = k − |x − h| 是倒 V 形。
找顶点法：y = |f(x)| 的顶点 x 坐标是 f(x) = 0 的解；再求一个点（如 y 截距）就能画出。y = |mx + c| 两边的斜率是 ±m。
平行线组：|x| = 2 是两条竖线 x = ±2；|y| = 1 是两条横线 y = ±1；|x + y| = 1 是两条直线 x + y = 1 和 x + y = −1。

例 14（L9 Ex 1） Using the graph of y = |x| and transformation methods sketch each V shaped graph showing the main features: (a) y = |x| − 2 (b) y = |x − 1| (c) y = 3 − |x| (d) y = |x + 2| − 1

看解答

(a) 下移 2：顶点 (0, −2)；|x| = 2，x 截距 ±2。
(b) 右移 1：顶点 (1, 0)；y 截距 1。
(c) 翻折后上移 3：倒 V，顶点 (0, 3)；x 截距 ±3。
(d) 左移 2、下移 1：顶点 (−2, −1)；|x + 2| = 1，x = −1 或 −3；y 截距 2 − 1 = 1。

(a) y = |x| − 2

(b) y = |x − 1|

(c) y = 3 − |x|

(d) y = |x + 2| − 1

例 15（L9 Ex 2） First find the vertex of each absolute value graph and hence sketch: (a) y = |2x − 4| (b) y = |5 + 3x|

看解答

(a) 2x − 4 = 0，x = 2，顶点 (2, 0)；y 截距 |−4| = 4；两边斜率 ±2。
(b) 5 + 3x = 0，x = −53，顶点 (−5/3, 0)；y 截距 5；两边斜率 ±3。

(a) y = |2x − 4|

(b) y = |5 + 3x|

例 16（L9 Ex 3） In the following cases the graph is a pair of parallel lines. Sketch: (a) |x| = 2 (b) |y| = 1 (c) |x + y| = 1

看解答

去掉绝对值得到两种情况，每种是一条直线。
(a) x = 2 或 x = −2：两条竖线。
(b) y = 1 或 y = −1：两条横线。
(c) x + y = 1 或 x + y = −1，即 y = 1 − x 和 y = −1 − x：两条斜率 −1 的平行线，分别过 (1, 0)、(0, 1) 和 (−1, 0)、(0, −1)。

(a) |x| = 2: x = 2 or x = −2

(b) |y| = 1: y = 1 or y = −1

(c) |x + y| = 1: y = 1 − x or y = −1 − x

易错
① y = |x − 1| 的顶点写成 (−1, 0)。
② 画成 U 形曲线：绝对值图像在顶点是尖角，两边是直线。
③ |x + y| = 1 只画一条线。
常见疑惑
问：y = |2x − 4| 和 y = 2|x − 2| 一样吗？ 一样：|2x − 4| = |2(x − 2)| = 2|x − 2|，所以顶点 (2, 0)、斜率 ±2。
