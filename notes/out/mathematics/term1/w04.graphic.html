反函数：交换 x 和 y（L10）

L10_Inverse_Functions.pdf · PDF p1–3

概念
复习：函数是每个 x 只对应一个 y 的关系，能通过竖线检验。
反函数（逆关系）：把函数每个点的 x、y 坐标交换。所以逆关系的定义域是原函数的值域，逆关系的值域是原函数的定义域。
函数给成方程时，交换 x 和 y 再解出 y，就是逆关系的方程。
图像：原函数过 (a, b)，逆关系就过 (b, a)；两者关于直线 y = x 对称。原函数与 y = x 的交点，逆关系也经过。

例 1（L10 Ex 1） Given the function f: {(−3, −1), (−1, 2), (2, 5), (3, 9)} write down the inverse relation g.

看解答

每个点交换坐标：g: {(−1, −3), (2, −1), (5, 2), (9, 3)}。
Answer: g: {(−1, −3), (2, −1), (5, 2), (9, 3)}

例 2（L10 Ex 2） Given the function F: {(1, 5), (2, 5), (3, 7), (−1, 3)}: (a) write down the inverse relation G; (b) is the inverse a function? (c) state the domain and range of F and G.

看解答

(a) G: {(5, 1), (5, 2), (7, 3), (3, −1)}。
(b) 不是函数：x = 5 对应 1 和 2 两个 y。原因是 F 里 1 和 2 都对应 5，F 不是一一函数。
(c) 见下表：G 的定义域就是 F 的值域，G 的值域就是 F 的定义域。

DomainRange
F{−1, 1, 2, 3}{3, 5, 7}
G{3, 5, 7}{−1, 1, 2, 3}

例 3（L10 Ex 3） Find the inverse relations of: (a) y = 2x + 6 (b) f(x) = −12x + 3

看解答

(a) 交换：x = 2y + 6，解出 y = x − 62。
(b) 交换：x = −12y + 3，2y + 3 = −1x，2y = −1x − 3，y = −1 + 3x2x。
验证 (b)：f(1) = −1/5；代入逆关系 x = −1/5：−(1 − 3/5)/(−2/5) = 1，回到原来的 1。
Answer: (a) y = (x − 6)/2 (b) y = −(1 + 3x)/(2x)

例 4（L10 Ex 4） On the same axes, graph the relation from example 3(a) and its inverse.

看解答

y = 2x + 6 过 (0, 6)、(−3, 0)；逆关系 y = (x − 6)/2 过 (6, 0)、(0, −3)，正是交换后的点。两线关于 y = x 对称，交于 y = x 上：2x + 6 = x，x = −6，交点 (−6, −6)。

y = 2x + 6 and y = (x − 6)/2 meet on y = x at (−6, −6)

例 5（L10 Ex 5） Sketch the graphs of the inverse relations for each function shown: (a) a line with y-intercept 2 and x-intercept 8; (b) a curve through (1, 0) rising slowly, with the negative y-axis as asymptote; (c) the horizontal line y = 3; (d) a parabola with x-intercepts 0 and 4 and vertex (2, −2); (e) a quarter arc from the negative x-axis to (0, 2) followed by a line from (0, 2) to (2, 0); (f) a curve dipping below the x-axis on the left, passing through the origin and meeting y = x again in the first quadrant.

看解答

方法：把关键点 (a, b) 换成 (b, a)，再沿 y = x 翻折整条曲线（红线是逆关系）。
(a) 截距 (0, 2)、(8, 0) 变成 (2, 0)、(0, 8)：y = 8 − 4x。
(b) (1, 0) 变成 (0, 1)；竖直渐近线（负 y 轴）变成水平渐近线（负 x 轴）：形状像 y = eˣ。
(c) 水平线 y = 3 变成竖直线 x = 3，逆关系不是函数。
(d) (2, −2) 变成 (−2, 2)，截距 (4, 0) 变成 (0, 4)：开口向右的抛物线 x = ½y² − 2y，不是函数。
(e) 线段 y = 2 − x 关于 y = x 对称，翻折后不变；弧从 (−1.25, 0)…(0, 2) 变成 (0, −1.25)…(2, 0)。
(f) 原图左边先降后升，同一个 y 有两个 x，所以逆关系在左下方「侧着」打弯，不是函数；原图与 y = x 的两个交点（原点和第一象限那一点）逆关系也经过。
注：讲义 (b)、(e)、(f) 只画了曲线、没有方程：(b) 用 y = ln x 示意；(e) 的弧左端按图读在 x ≈ −1.25；(f) 按图读点连线。这些图只表示逆关系的位置和形状。

(a) f: y = 2 − x/4 → inverse y = 8 − 4x

(b) f like y = ln x → inverse like y = eˣ (sketch)

(c) y = 3 → inverse x = 3 (not a function)

(d) f = ½x² − 2x → inverse x = ½y² − 2y

(e) the line y = 2 − x is its own inverse

(f) inverse is not a function (sketch)

易错
① 逆关系的定义域、值域没有对调。
② 求逆时只交换不解出 y，或解 y 时符号出错（例 3(b)）。
③ 画逆关系时关于 x 轴或 y 轴翻折：应该关于 y = x。
常见疑惑
问：逆关系一定是函数吗？ 不一定。只有原函数是一一函数（下一节）时，逆关系才是函数，例如例 2、例 5(c)(d) 都不是。

一一函数、f⁻¹ 记号与限制定义域（L10）

L10_Inverse_Functions.pdf · PDF p4–7

概念
一一函数：每个 y 只对应一个 x，没有两个点的 y 坐标相同；能通过水平线检验。只有原函数是一一函数，它的逆才也是函数。
记号：一一函数 f(x) 的反函数记作 f⁻¹(x)。f⁻¹(x) 不是 1f(x)。f(f⁻¹(x)) = f⁻¹(f(x)) = x。
限制定义域：f(x) = x² − 1 不是一一函数，逆不是函数；只取 x ≥ 0（或只取 x ≤ 0）这一半，就变成一一函数，反函数存在。任何使函数变成一一函数的限制都可以。
f(f⁻¹(x)) = f⁻¹(f(x)) = x　　f⁻¹(x) ≠ 1/f(x)

例 6（L10 Ex 6） Given the function f(x) = √(x − 3): (a) state the domain and range and sketch the function; (b) sketch the inverse function f⁻¹(x) on the same axes and state the domain and range; (c) write down the equation of the inverse function; (d) show that f(f⁻¹(x)) = f⁻¹(f(x)) = x.

看解答

(a) 根号下 x − 3 ≥ 0：定义域 x ≥ 3；值域 y ≥ 0。图像是 √x 右移 3，起点 (3, 0)。
(b) 关于 y = x 翻折，起点变成 (0, 3)：f⁻¹ 的定义域 x ≥ 0，值域 y ≥ 3（与 f 对调）。
(c) 交换：x = √(y − 3)，平方得 y = x² + 3，并注明 x ≥ 0（否则会多出左半支，不是 f 的反函数）。
(d) f(f⁻¹(x)) = √(x² + 3 − 3) = √(x²) = x（因为 x ≥ 0）；f⁻¹(f(x)) = (√(x − 3))² + 3 = x − 3 + 3 = x。
Answer: f⁻¹(x) = x² + 3, x ≥ 0

f(x) = √(x − 3) and f⁻¹(x) = x² + 3 (x ≥ 0)

例 7（L10 Restrict） Consider f(x) = x² − 1. State its domain and range and explain why its inverse is not a function. Restrict the domain to x ≥ 0, then to x ≤ 0; in each case give the range, the domain and range of the inverse function and its equation.

看解答

f(x) = x² − 1：定义域全体实数，值域 y ≥ −1。它不是一一函数（如 f(2) = f(−2) = 3），逆关系 x = y² − 1 即 y = ±√(x + 1)，一个 x 对应两个 y，不是函数。
取 x ≥ 0：值域 y ≥ −1；反函数定义域 x ≥ −1，值域 y ≥ 0，方程 f⁻¹(x) = √(x + 1)。
取 x ≤ 0：值域 y ≥ −1；反函数定义域 x ≥ −1，值域 y ≤ 0，方程 f⁻¹(x) = −√(x + 1)。

x ≥ 0: f⁻¹(x) = √(x + 1)

x ≤ 0: f⁻¹(x) = −√(x + 1)

易错
① 把 f⁻¹(x) 写成 1/f(x)。
② 反函数方程不写定义域限制（例 6(c) 的 x ≥ 0）。
③ 限制定义域后值域照抄原来的：要重新看保留的那一半。
常见疑惑
问：为什么例 6 的反函数要写 x ≥ 0？ f 的值域是 y ≥ 0，所以 f⁻¹ 的定义域只能是 x ≥ 0；y = x² + 3 若不限制，左半支不是 f 的反函数。

对数的定义与 e（L11）

L11_Logarithms.pdf · PDF p1–4

概念
若 bk = N，则 k 叫做以 b 为底 N 的对数，记作 logb N = k。对数就是指数。要求 b > 0、b ≠ 1、N > 0（负数和 0 没有对数）。
由定义直接得到：logb 1 = 0（b⁰ = 1），logb b = 1，logb bˣ = x。
e 是无理数（欧拉数），e ≈ 2.718281828，计算器用 SHIFT ln 1 求。以 e 为底的对数叫自然对数，写作 logₑ 或 ln；以 10 为底的叫常用对数，计算器 log 键。
bᵏ = N ⇔ logb N = k　（b > 0，b ≠ 1，N > 0）

例 8（L11 Ex 1） Complete the table showing equivalent statements in exponential and logarithmic form: 14² = 196; log₅ 125 = 3; c² = 5; log_p r = q; 7ᵗ = N.

看解答

底数不变，指数就是对数的值：bᵏ = N ⇔ logb N = k。

例 9（L11 Ex 2） Find each logarithm without using a calculator: (a) log₁₀ 100 (b) log₂ 8 (c) log₃ 19 (d) log₁₆ 1 (e) log₃(−3) (f) log√3 3√3

看解答

问自己「底数的几次方等于真数」。
(a) 10² = 100：2。(b) 2³ = 8：3。(c) 3⁻² = 1/9：−2。(d) 16⁰ = 1：0。
(e) 3 的任何次方都是正数，log₃(−3) 无定义。
(f) √3 = 3½，3√3 = 33/2 = (3½)³：3。
Answer: (a) 2 (b) 3 (c) −2 (d) 0 (e) undefined (f) 3

例 10（L11 Ex 3） Evaluate without a calculator: (a) logₑ e = ln e (b) ln e² (c) logₑ 1e

看解答

ln 就是以 e 为底：(a) e¹ = e：1。(b) 2。(c) 1/e = e⁻¹：−1。
Answer: (a) 1 (b) 2 (c) −1

例 11（L11 Calculator） Use the calculator: e = e¹, log₁₀ 3 and ln 3.

看解答

e ≈ 2.718281828（SHIFT ln 1 =）；log₁₀ 3 用 log 键 ≈ 0.4771；ln 3 用 ln 键 ≈ 1.0986。

易错
① log₃(−3) 算成 −1：负数没有对数。
② logb 1 写成 1：应为 0。
③ 把 log 键当成 ln 键。
常见疑惑
问：为什么底数不能是 1？ 1 的任何次方都等于 1，log₁ 5 找不到指数，log₁ 1 又有无数个答案，所以规定 b ≠ 1。

对数运算法则与方程（L11）

L11_Logarithms.pdf · PDF p5–7

概念
由指数法则得到（M > 0，N > 0，b > 0 且 b ≠ 1）：
logb MN = logb M + logb N；logb MN = logb M − logb N；logb Mᵖ = p logb M；blogb x = x。
对数方程：先用法则合并成一个对数，再改写成指数形式；最后检查真数 > 0、底数 > 0 且 ≠ 1。
指数方程（未知数在指数上）：两边取对数（常用对数或 ln），把指数拉下来。
不等式两边除以负数（如 log 0.3 < 0）要变号。
log MN = log M + log N　log(M/N) = log M − log N　log Mᵖ = p log M

例 12（L11 Ex 4） Using the properties, simplify and then evaluate: (a) log₈ 4 + log₈ 2 (b) log₃ 54 − log₃ 2 (c) log₅ 20 + log₅ 10 − 3log₅ 2 (d) log_x √x + log_x x³ − (log_x x)²

看解答

先用法则把几个对数合并成一个，再求值。
(a) 同底相加变成真数相乘：log₈(4 × 2) = log₈ 8 = 1。
(b) log₃(54 ÷ 2) = log₃ 27 = 3。
(c) 3log₅ 2 = log₅ 8；log₅(20 × 10 ÷ 8) = log₅ 25 = 2。
(d) log_x x½ = ½，log_x x³ = 3，(log_x x)² = 1²：½ + 3 − 1 = 52。
Answer: (a) 1 (b) 3 (c) 2 (d) 5/2

例 13（L11 Ex 5） Solve: (a) log₇(5x − 1) = 2 (b) log_x 3 = 14 (c) logx−1(4x − 4) = 2 (d) log₅(x + 8) − log₅(x − 4) = 2

看解答

(a) 5x − 1 = 7² = 49，x = 10。
(b) x¼ = 3，x = 3⁴ = 81。
(c) (x − 1)² = 4x − 4 = 4(x − 1)。底数 x − 1 > 0 且 ≠ 1，可以两边除以 x − 1：x − 1 = 4，x = 5。（x = 1 会使底数为 0，舍去。）
(d) log₅ x + 8x − 4 = 2，(x + 8)/(x − 4) = 25，x + 8 = 25x − 100，24x = 108，x = 4.5。检查：x − 4 = 0.5 > 0，成立。
Answer: (a) 10 (b) 81 (c) 5 (d) 4.5

例 14（L11 Ex 6） Solve for x, correct to 4 decimal places: (a) 10ˣ = 85 (b) 4e−3x = 5

看解答

(a) x = log₁₀ 85 ≈ 1.9294。
(b) e−3x = 5/4，两边取 ln：−3x = ln 1.25，x = −ln 1.253 ≈ −0.0744。
Answer: (a) x ≈ 1.9294 (b) x ≈ −0.0744

例 15（L11 Ex 7） Solve log₂(log₅ x) = 1.

看解答

由外向内：log₅ x = 2¹ = 2，x = 5² = 25。
Answer: x = 25

例 16（L11 Ex 8） If log₁₀ 2 = a and log₁₀ 3 = b, express in terms of a and b: (a) log₁₀ 24 (b) log₁₀ 5 (c) log₁₀ √(2/3)

看解答

把真数拆成 2、3、10 的乘除和乘方，再用法则展开。
(a) 24 = 2³ × 3：3a + b。
(b) 5 = 10 ÷ 2：log 10 − log 2 = 1 − a。
(c) √(2/3) = (2/3)½：½(a − b)。
Answer: (a) 3a + b (b) 1 − a (c) ½(a − b)

例 17（L11 Ex 9） Find the smallest positive integer x such that: (a) 2ˣ > 7 (b) 10(0.3)ˣ < 0.1

看解答

(a) x log 2 > log 7，x > log 7log 2 ≈ 2.807，最小整数 x = 3（2³ = 8 > 7，2² = 4 不够）。
(b) 0.3ˣ < 0.01，x log 0.3 < log 0.01 = −2。log 0.3 ≈ −0.5229 是负数，两边除以它要变号：x > −2log 0.3 ≈ 3.825，最小整数 x = 4。
Answer: (a) 3 (b) 4

易错
① log(M + N) 拆成 log M + log N：法则只对乘积成立。
② 例 13(c) 两边除以 x − 1 前没说明 x − 1 ≠ 0。
③ 例 17(b) 除以负的 log 0.3 没变号。
④ 解出对数方程不检查真数是否为正。
常见疑惑
问：指数方程用 log 还是 ln？ 都可以，结果相同；底数是 e 时用 ln 最省事。

指数函数图像（L12）

L12 Graphs of Exponential Functions.pdf · PDF p1–4

概念
列表画 y = 2ˣ：x = −2, −1, 0, 1, 2, 3 时 y = ¼, ½, 1, 2, 4, 8。特征：x → ∞ 时 y → ∞；x → −∞ 时 y → 0（负 x 轴是渐近线）；y 永远 > 0。
y = kax（k > 1）：处处连续；定义域全体实数；值域 y > 0；水平渐近线 y = 0；y 截距 1。a > 0 处处递增，a < 0 处处递减。
一般形式 y = y₀kax + b：定义域全体实数；水平渐近线 y = b；y 截距 y₀ + b。画图：先画渐近线和 y 截距，再按增减画曲线；需要时求 x 截距（令 y = 0，取对数）。
y = y₀kax + b：渐近线 y = b，y 截距 y₀ + b

例 18（L12 Investigation） Use a table of values to plot y = 2ˣ for x = −2, −1, 0, 1, 2, 3, and complete the features of y = k^(ax).

看解答

表中 y 依次是 ¼、½、1、2、4、8。y = kax 的特征：定义域全体实数；值域 y > 0；水平渐近线 y = 0；y 截距 1；a > 0 递增，a < 0 递减。

y = 2ˣ: (−2, ¼), (−1, ½), (0, 1), (1, 2), (2, 4), (3, 8)

y = kᵃˣ (k > 1): increasing when a > 0, decreasing when a < 0

例 19（L12 Ex 1） Use transformation methods to sketch: (a) y = 2ˣ + 1 (b) y = 2ˣ − 3 (c) y = 3 × 2ˣ (d) y = 13 × 2ˣ

看解答

(a) 上移 1：渐近线 y = 1，y 截距 2。
(b) 下移 3：渐近线 y = −3，y 截距 −2；x 截距 2ˣ = 3，x = log₂ 3 ≈ 1.585。
(c) 纵向拉伸 3 倍：渐近线仍是 y = 0，y 截距 3。
(d) 纵向压缩成 ⅓：渐近线 y = 0，y 截距 ⅓。

(a) y = 2ˣ + 1

(b) y = 2ˣ − 3

(c) y = 3 × 2ˣ and (d) y = ⅓ × 2ˣ

例 20（L12 Ex 2） Sketch the graphs of: (a) y = 1 − 2ˣ (b) y = 3 + 2e⁻ˣ (c) y = 2e⁻³ˣ − 4

看解答

(a) y = −2ˣ + 1：2ˣ 关于 x 轴翻折后上移 1。渐近线 y = 1（从下方靠近），y 截距 0（过原点），处处递减。
(b) y₀ = 2、a = −1、b = 3：渐近线 y = 3（x → ∞ 时从上方靠近），y 截距 2 + 3 = 5，递减。
(c) 渐近线 y = −4，y 截距 2 − 4 = −2，递减；x 截距：e⁻³ˣ = 2，x = −ln 23 ≈ −0.231。

(a) y = 1 − 2ˣ

(b) y = 3 + 2e⁻ˣ

(c) y = 2e⁻³ˣ − 4

易错
① 渐近线写成 y = 0 而忘了加上的常数 b。
② y 截距只写 y₀，忘了加 b。
③ y = 1 − 2ˣ 画成递增。
常见疑惑
问：指数函数的图像会碰到渐近线吗？ 不会。kax 永远大于 0，所以 y₀kax + b 永远不等于 b。
