对数积分（L34）

L34_Log_Functions_Integration.pdf · PDF p1–3

概念
ddx ln x = 1x（x > 0），ddx ln(−x) = 1x（x < 0），合起来：∫1x dx = ln|x| + c。这正好补上了幂法则 n = −1 的空缺。
链式法则推广：∫f′(x)f(x) dx = ln|f(x)| + c：分子是分母的导数（差常数倍可以补）时用它。
讲义说明：定积分题目只出在正数范围内，所以计算定积分时可以直接写 ln。
∫1x dx = ln|x| + c　　∫f′(x)f(x) dx = ln|f(x)| + c

例 1（L34 Intro） Explain why ∫1x dx = ln|x| + c.

看解答

ln x 只在 x > 0 有定义，导数 1/x；ln(−x) 只在 x < 0 有定义，导数 −1−x = 1x。两种情况都对，用绝对值合并：∫1x dx = ln|x| + c。

例 2（L34 Ex 1） Find: (a) ∫3x dx (b) ∫13x dx (c) ∫(3x − 52x) dx (d) ∫22x + 5 dx (e) ∫x2x² − 3 dx (f) ∫eˣ1 + eˣ dx

看解答

常数提出来，再看分子是不是分母的导数。
(a) 3ln|x| + c。(b) ⅓ln|x| + c。(c) 3x²2 − 52ln|x| + c。
(d) 分母导数正好是 2：ln|2x + 5| + c。
(e) 分母导数 4x，分子只有 x，补 ¼：¼ln|2x² − 3| + c。
(f) 分母导数 eˣ 正好是分子：ln(1 + eˣ) + c（1 + eˣ > 0，不用绝对值）。
注：讲义第 1 题的第五小题印成 (b)，应为 (e)，笔记按 (e) 处理。
Answer: 见解答

例 3（L34 Ex 2） Evaluate: (a) ∫₂⁸ 5x dx (b) ∫₁³ x + 1x² + 2x + 5 dx

看解答

(a) [5ln x]₂⁸ = 5(ln 8 − ln 2) = 5ln 4 ≈ 6.931。
(b) 分母导数 2x + 2 = 2(x + 1)，补 ½：[½ln(x² + 2x + 5)]₁³ = ½(ln 20 − ln 8) = ½ln 2.5 ≈ 0.458。
Answer: (a) 5 ln 4 (b) ½ ln(5/2)

例 4（L34 Ex 3） A curve y = f(x) has gradient dydx = 3x − 4x and passes through (1, −1). Find its equation.

看解答

y = 3x²2 − 4ln|x| + c。代 (1, −1)：32 − 0 + c = −1，c = −52。
y = 3x²2 − 4ln|x| − 52。
Answer: y = 3x²/2 − 4ln|x| − 5/2

例 5（L34 Ex 4） (a) Sketch x + y = 4 and xy = 3 and shade the region bounded by the curves. (b) Find its area.

看解答

交点：y = 4 − x 代入 xy = 3，x(4 − x) = 3，x² − 4x + 3 = 0，x = 1 或 3，交点 (1, 3)、(3, 1)。
(b) 在 1 < x < 3 上直线在上：面积 = ∫₁³ (4 − x − 3x) dx = [4x − x²2 − 3ln x]₁³ = (12 − 4.5 − 3ln 3) − (4 − 0.5) = 4 − 3ln 3 ≈ 0.704 平方单位。
Answer: 4 − 3 ln 3 ≈ 0.704

Region between the line and the hyperbola from x = 1 to 3: area 4 − 3 ln 3

易错
① ∫1/x dx 用幂法则写成 x⁰/0。
② ∫x/(2x² − 3) dx 忘了补 ¼。
③ ln|x| 的绝对值漏写（不定积分）。
常见疑惑
问：什么时候能用 ln|f(x)|？ 分子是分母的导数，或只差一个常数倍时。分子次数比分母高时不能直接用。

例 6（L35 Ex 1） Solve |2x − 3| < 5.

看解答

去掉绝对值：−5 < 2x − 3 < 5，各加 3：−2 < 2x < 8，−1 < x < 4。
Answer: −1 < x < 4

例 7（L35 Ex 2） Solve 4y + y = 5.

看解答

两边乘 y（y ≠ 0）：4 + y² = 5y，y² − 5y + 4 = (y − 1)(y − 4) = 0，y = 1 或 4。
Answer: y = 1 or 4

例 8（L35 Ex 3） If f(x) = 7x + 1, find f(x + a) − f(x).

看解答

f(x + a) = 7x + 7a + 1，减去 7x + 1 得 7a。
Answer: 7a

例 9（L35 Ex 4） If log₄ 7 = n, express in terms of n: (a) log₄ 17 (b) log₇ 4

看解答

(a) log₄ 7⁻¹ = −log₄ 7 = −n。
(b) 4ⁿ = 7，两边开 n 次方：4 = 71/n，所以 log₇ 4 = 1n。
Answer: (a) −n (b) 1/n

例 10（L35 Ex 4 (parabola)） (a) Express y = −3x² + 6x + 9 in the form y = a(x − h)² + k. (b) Sketch the graph, showing all essential features.

看解答

(a) y = −3(x² − 2x) + 9 = −3[(x − 1)² − 1] + 9 = −3(x − 1)² + 12。
(b) 开口向下，顶点 (1, 12)；y 截距 9；令 y = 0：−3(x² − 2x − 3) = −3(x − 3)(x + 1) = 0，x 截距 −1、3。
注：讲义这一页的题号又是「4」（与上一题重复），笔记按出现顺序处理。
Answer: y = −3(x − 1)² + 12

Vertex (1, 12), x-intercepts −1 and 3, y-intercept 9

例 11（L35 Ex 5） Sketch, showing all essential features: (a) y = 3ln(x − 1) (b) y = 1 − 2x + 2

看解答

(a) 定义域 x > 1，竖直渐近线 x = 1；x 截距：ln(x − 1) = 0，x = 2；再取一点 x = 1 + e，y = 3。
(b) 竖直渐近线 x = −2，水平渐近线 y = 1；y 截距 1 − 1 = 0，x 截距也是 0（过原点）；a = −2 < 0，两支在渐近线交点的左上和右下。

(a) asymptote x = 1, x-intercept 2, through (1 + e, 3)

(b) asymptotes x = −2 and y = 1, passes through the origin

例 12（L35 Ex 6） f(x) = −√(25 − x²) (the lower semicircle). (a) Explain why f⁻¹(x) does not exist. (b) g(x) = −√(25 − x²), 0 ≤ x ≤ 5; given g⁻¹ exists, find its domain and range. (c) Sketch y = g(x) and y = g⁻¹(x) on the same axes.

看解答

(a) f 不是一一函数：如 f(−3) = f(3) = −4，水平线 y = −4 与图像交两次，所以它的逆不是函数，f⁻¹ 不存在。
(b) g 的定义域 0 ≤ x ≤ 5，值域 −5 ≤ y ≤ 0。反函数对调：g⁻¹ 的定义域 −5 ≤ x ≤ 0，值域 0 ≤ y ≤ 5。
(c) g 是从 (0, −5) 到 (5, 0) 的四分之一圆；关于 y = x 翻折得到从 (−5, 0) 到 (0, 5) 的四分之一圆，即 g⁻¹(x) = √(25 − x²)，−5 ≤ x ≤ 0。
Answer: g⁻¹: domain −5 ≤ x ≤ 0, range 0 ≤ y ≤ 5

(a) the line y = −4 meets the graph twice: f is not one-to-one

g on 0 ≤ x ≤ 5 and its inverse g⁻¹(x) = √(25 − x²), −5 ≤ x ≤ 0

例 13（L35 Ex 7） Weekly sales S(x) = 65 000 − 40 000e−0.0005x, where x is weekly advertising. (a) Find the sales if advertising is $450. (b) Find the advertising needed for sales of $50 000. (c) With unlimited advertising, find the greatest possible weekly sales. (d) Sketch y = S(x).

看解答

(a) S(450) = 65 000 − 40 000e−0.225 ≈ 65 000 − 31 940.65 = $33 059.35。
(b) 50 000 = 65 000 − 40 000e−0.0005x，e−0.0005x = 0.375，x = ln 0.375−0.0005 ≈ $1961.66。
(c) x → ∞ 时 e−0.0005x → 0，S → 65 000：销售额趋近但达不到 $65 000（这是上限）。
(d) S(0) = 25 000，递增，水平渐近线 S = 65 000。
Answer: (a) $33 059.35 (b) $1961.66 (c) approaches $65 000

S(0) = 25 000, approaching 65 000 as advertising grows

易错
① |2x − 3| < 5 只解 2x − 3 < 5。
② log₇ 4 写成 −n：换底后是倒数。
③ 说 f 没有反函数只说「是半圆」：要指出不是一一函数（水平线检验）。
④ (c) 写「最大销售额 65 000」：它是取不到的上限。
常见疑惑
问：复习课的题考试会怎么考？ 题型和这两讲基本一致：每道题都要写出关键步骤（求导、令导数为 0、判断类型、检查定义域），图要标截距、渐近线、驻点。

例 14（L36 Ex 1） Differentiate: (a) y = 3x² − 1x (b) y = (3x + 1)⁵ (c) f(x) = √x(x − 2)² (d) f(x) = 2x − 5x² + 1 (e) f(x) = (eˣ + 2)⁴ (f) y = ln(3x − 52x − 7)

看解答

(a) 6x + 1x²。
(b) 15(3x + 1)⁴。
(c) 乘积法则：12√x(x − 2)² + 2√x(x − 2) = (x − 2)[(x − 2) + 4x]2√x = (x − 2)(5x − 2)2√x。
(d) 2(x² + 1) − 2x(2x − 5)(x² + 1)² = −2x² + 10x + 2(x² + 1)²。
(e) 4eˣ(eˣ + 2)³。
(f) 先拆：ln(3x − 5) − ln(2x − 7)，导数 33x − 5 − 22x − 7。
Answer: 见解答

例 15（L36 Ex 2） Find: (a) ∫(x⁴ − 7x) dx (b) ∫(x − 4)(x² − 8x)⁵ dx (c) ∫₁³ (3x − 2x³) dx (d) ∫₋₁⁴ (e3x − 5 − 7) dx

看解答

(a) x⁵5 − 7x²2 + c。
(b) 里层 x² − 8x 的导数 2(x − 4)，补 ½：½ × (x² − 8x)⁶6 + c = (x² − 8x)⁶12 + c。
(c) [3x²2 + x⁻²]₁³ = (272 + 19) − (32 + 1) = 1009 ≈ 11.11。
(d) [⅓e3x − 5 − 7x]₋₁⁴ = (⅓e⁷ − 28) − (⅓e⁻⁸ + 7) = ⅓(e⁷ − e⁻⁸) − 35 ≈ 330.54。
Answer: (a) x⁵/5 − 7x²/2 + c (b) (x² − 8x)⁶/12 + c (c) 100/9 (d) ⅓(e⁷ − e⁻⁸) − 35 ≈ 330.54

例 16（L36 Ex 3） Find the equation of the normal to y = ∛x + 1 at the point where x = 0.

看解答

x = 0 时 y = 1。y′ = ⅓x−2/3 = 13∛(x²)，x = 0 时分母为 0，导数不存在：曲线在 (0, 1) 处的切线是竖直线 x = 0。法线与它垂直，是水平线：y = 1。
Answer: y = 1

At x = 0 the tangent is vertical (x = 0), so the normal is horizontal: y = 1

例 17（L36 Ex 4） A cone has volume V = 6πh²7 cm³ where h is its height. Find the rate of change of volume with respect to height when V = 42π cm³.

看解答

先求 h：6πh²7 = 42π，h² = 49，h = 7。
dVdh = 12πh7，h = 7 时 = 12π ≈ 37.70 cm³/cm。
Answer: 12π cm³ per cm

例 18（L36 Ex 5） Consider y = x³ − 3x² + 7. (a) Find the stationary points and their nature. (b) Find any points of inflection. (c) Sketch the curve. (d) Find the values of x for which the curve is both decreasing and concave up.

看解答

(a) y′ = 3x² − 6x = 3x(x − 2) = 0，x = 0 或 2：(0, 7)、(2, 3)。y″ = 6x − 6：x = 0 时 −6 < 0，(0, 7) 极大；x = 2 时 6 > 0，(2, 3) 极小。
(b) y″ = 0，x = 1，两侧 y″ 变号；y = 1 − 3 + 7 = 5，拐点 (1, 5)。
(c) 见图。
(d) 递减：0 < x < 2；下凸（concave up）：x > 1。同时成立：1 < x < 2。
Answer: MAX (0, 7), MIN (2, 3), POI (1, 5); 1 < x < 2

MAX (0, 7), MIN (2, 3), POI (1, 5); decreasing and concave up for 1 < x < 2

例 19（L36 Ex 6） A streaming service has 4800 subscribers paying $18 a month. It gains 150 subscribers for each 50-cent decrease in the fee. Find the fee which maximises monthly revenue.

看解答

设降价 n 次（每次 $0.50）：月费 18 − 0.5n，用户 4800 + 150n。
R(n) = (18 − 0.5n)(4800 + 150n) = 86 400 + 300n − 75n²。
R′(n) = 300 − 150n = 0，n = 2；R″ = −150 < 0，是最大值。月费 18 − 1 = $17，用户 5100，月收入 $86 700。
Answer: $17 per month

Revenue is greatest after n = 2 decreases: fee $17

例 20（L36 Ex 7） Revenue from x toothbrushes is R(x) = 800ln(1 + x200); cost is C(x) = 300 + x. (a) Write the profit P(x). (b) Find the number of toothbrushes for maximum profit.

看解答

(a) P(x) = 800ln(1 + x200) − 300 − x。
(b) P′(x) = 800 × 1/2001 + x/200 − 1 = 41 + x/200 − 1 = 0，1 + x200 = 4，x = 600。P″(x) = −4/200(1 + x/200)² < 0，是最大值。最大利润 P(600) = 800ln 4 − 900 ≈ $209。
Answer: (a) P = 800 ln(1 + x/200) − 300 − x (b) 600

Profit is greatest at x = 600 toothbrushes

例 21（L36 Ex 8） (a) Sketch y = e⁻ˣ − 3 and shade the region bounded by the curve, the line y = −3, the line x = ln 3 and the y-axis. (b) Find its area.

看解答

(a) y = e⁻ˣ 下移 3：y 截距 −2，水平渐近线 y = −3，曲线在 y = −3 上方。
(b) 面积 = ∫₀ln 3 [(e⁻ˣ − 3) − (−3)] dx = ∫₀ln 3 e⁻ˣ dx = [−e⁻ˣ]₀ln 3 = −13 + 1 = 23 平方单位。
Answer: 2/3

Region between the curve and y = −3 from x = 0 to ln 3: area 2/3

易错
① 求导结果不化简就停下，考试常要求化简（例 14(c)(d)）。
② 导数不存在时不知道怎么写切线、法线（例 16）。
③ 最优化题只求出 n，忘了回答题目问的月费。
④ 求面积时用了曲线下到 x 轴的面积，而不是到 y = −3（例 21）。
常见疑惑
问：复习题怎么用？ 先遮住解答自己完整做一遍，按「步骤是否齐全」对照，再看易错点。
