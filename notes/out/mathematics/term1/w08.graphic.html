切线与法线方程（L22）

L22_Tangents_Normals.pdf · PDF p1–4

概念
切线是直线，有斜率和一个点就能用点斜式 y − y₁ = m(x − x₁) 写方程。曲线在某点的斜率就是切线的斜率，所以：
①如果没给 y，把 x = a 代入曲线求 y；②求导得 f′(x)；③代 x = a 得切线斜率 mT = f′(a)；④代入点斜式。
法线：过该点、与切线垂直的直线。m₁ × m₂ = −1，所以 mN = −1mT。切线水平（mT = 0）时，法线是竖直线 x = a。
mT = f′(a)　　mN = −1mT　　y − y₁ = m(x − x₁)

例 1（L22 Ex 1） Find the equation of the tangent to the curve y = 2x² + 7 at the point (1, 9).

看解答

y′ = 4x，x = 1 时 mT = 4。y − 9 = 4(x − 1)，y = 4x + 5。
Answer: y = 4x + 5

例 2（L22 Ex 2） Find the equations of the tangents to the curve y = x² + 4x − 12 at the points where the curve crosses the x-axis.

看解答

先求与 x 轴的交点：x² + 4x − 12 = (x + 6)(x − 2) = 0，x = −6 或 2。
y′ = 2x + 4。
x = 2：m = 8，y − 0 = 8(x − 2)，y = 8x − 16。
x = −6：m = −8，y = −8(x + 6)，y = −8x − 48。
Answer: y = 8x − 16 and y = −8x − 48

Tangents where the curve crosses the x-axis

例 3（L22 Ex 3） Find the equation of the normal to the curve y = 2x² + 7 at the point (1, 9).

看解答

例 1 中切线斜率 4，法线斜率 −¼。y − 9 = −¼(x − 1)，两边乘 4：4y − 36 = −x + 1，即 x + 4y − 37 = 0（或 y = −¼x + 37/4）。
Answer: x + 4y − 37 = 0

Tangent and normal at (1, 9)

例 4（L22 Ex 4） Find the equations of the tangent and normal to the curve y = xx² + 9 at the point where x = 3.

看解答

y = 3/18 = 1/6。商法则：y′ = (x² + 9) − x × 2x(x² + 9)² = 9 − x²(x² + 9)²；x = 3 时 y′ = 0。
切线水平：y = 16；法线竖直：x = 3。
Answer: tangent y = 1/6, normal x = 3

At x = 3 the tangent is horizontal, so the normal is the vertical line x = 3

例 5（L22 Ex 5） (a) Sketch y = √x and mark P(4, 2); sketch the tangent and normal at P. (b) Find the equations of the tangent and normal at P. (c) The tangent and normal meet the x-axis at A and B respectively. Find the area of triangle APB.

看解答

(a) 见图。
(b) y′ = 12√x，x = 4 时 mT = ¼。切线：y − 2 = ¼(x − 4)，y = ¼x + 1（x − 4y + 4 = 0）。法线斜率 −4：y − 2 = −4(x − 4)，y = −4x + 18。
(c) 切线令 y = 0：x = −4，A(−4, 0)；法线令 y = 0：x = 4.5，B(4.5, 0)。底 AB = 8.5，高是 P 的 y 坐标 2：面积 = ½ × 8.5 × 2 = 8.5 平方单位。
Answer: tangent y = x/4 + 1, normal y = −4x + 18, area 8.5

Triangle APB: A(−4, 0), P(4, 2), B(4½, 0); area 8½

易错
① 用 f(a) 当斜率：斜率是 f′(a)。
② 法线斜率只取倒数不变号。
③ 三角形面积的底用了两点的 x 坐标之和：底是 A、B 之间的距离。
常见疑惑
问：切线水平时法线怎么写？ 切线斜率 0 时 −1/0 无意义，法线是竖直线 x = a（例 4）。

一阶导数的符号：增减与驻点（L23）

L23_Sign_of_First_Derivative.pdf · PDF p1–4

概念
曲线上升处斜率为正，函数递增；下降处斜率为负，函数递减：f′(x) > 0 ⇒ 递增，f′(x) < 0 ⇒ 递减。
驻点（stationary point）：f′(x) = 0 的点，切线水平。三种类型：极小值点（MIN，导数符号 − 0 +）、极大值点（MAX，+ 0 −）、水平拐点（HPI，+ 0 + 或 − 0 −）。
判断类型：在驻点左右各取一个 x 代入 f′，看符号，画「斜线示意图」（stick diagram）。

MIN: − 0 +

MAX: + 0 −

HPI: + 0 + (or − 0 −)

例 6（L23 Intro） For the graph shown (A and C on rising parts, B on a falling part), describe the gradient and the function at A, B and C.

看解答

A、C 处斜率为正，函数递增；B 处斜率为负，函数递减。所以导数的符号告诉我们函数在增还是在减。
Answer: A, C: positive, increasing; B: negative, decreasing

例 7（L23 Ex 1） Find the values of x for which y = x² − 4x + 7 is increasing.

看解答

递增就是导数大于 0：y′ = 2x − 4 > 0，解得 x > 2。顶点 (2, 3) 左边递减、右边递增。
Answer: x > 2

Decreasing for x < 2, increasing for x > 2

例 8（L23 Ex 2） Find the values of x for which y = x³ − 9x² − 24x + 7 is decreasing.

看解答

y′ = 3x² − 18x − 24 = 3(x² − 6x − 8) < 0。x² − 6x − 8 = 0 的根 x = 3 ± √17（约 −1.12 和 7.12）。开口向上的抛物线在两根之间为负：3 − √17 < x < 3 + √17。
注：讲义印的是 −24x，根不是整数；如果原意是 y = x³ − 9x² + 24x + 7，导数 3(x − 2)(x − 4)，答案会是 2 < x < 4。笔记按讲义印的式子解。
Answer: 3 − √17 < x < 3 + √17

Decreasing between the stationary points x = 3 ± √17

例 9（L23 Ex 3） Find the stationary points on the curve y = x³ − 3x² + 2.

看解答

y′ = 3x² − 6x = 3x(x − 2) = 0，x = 0 或 2。x = 0 时 y = 2；x = 2 时 y = 8 − 12 + 2 = −2。驻点 (0, 2)、(2, −2)。
Answer: (0, 2) and (2, −2)

Stationary points (0, 2) and (2, −2)

例 10（L23 Ex 4） Show that the curve y = x − 1x + 1 has no stationary points.

看解答

商法则：y′ = (x + 1) − (x − 1)(x + 1)² = 2(x + 1)²。分子是 2，永远不等于 0，所以 y′ ≠ 0，没有驻点（而且 y′ > 0，函数在每一段上都递增）。

Always increasing: y′ = 2/(x + 1)² > 0, never 0

例 11（L23 Ex 5） Show that the curve y = x⁴ − 3x³ has a horizontal point of inflection at the origin.

看解答

y′ = 4x³ − 9x² = x²(4x − 9)。x = 0 时 y′ = 0，y = 0，原点是驻点。
左边 x = −1：y′ = −4 − 9 = −13 < 0；右边 x = 1：y′ = 4 − 9 = −5 < 0。符号 − 0 −，两边都在下降，所以是水平拐点。

例 12（L23 Ex 6） Find the stationary points on the curve y = 2x³ − 9x² + 12x + 8 and determine their nature.

看解答

y′ = 6x² − 18x + 12 = 6(x − 1)(x − 2) = 0，x = 1 或 2。y(1) = 2 − 9 + 12 + 8 = 13；y(2) = 16 − 36 + 24 + 8 = 12。
用符号表判断：x = 0 时 y′ = 12 > 0；x = 1.5 时 y′ = −1.5 < 0；x = 3 时 y′ = 12 > 0。
(1, 13)：+ 0 −，极大值点；(2, 12)：− 0 +，极小值点。
Answer: MAX (1, 13), MIN (2, 12)

易错
① 驻点只求 x 不求 y。
② 判断类型时代入的是 f 而不是 f′。
③ 把 HPI 当成极值点：导数两边同号就不是极值。
常见疑惑
问：符号表里的 x 怎么选？ 选驻点之间、容易算的数，比如整数或中点；不能选到另一个驻点的另一侧。

二阶导数、凹凸性与拐点（L24）

L24_Sign_of_Second_Derivative.pdf · PDF p1–5

概念
再求一次导就是二阶导数：d²ydx²、f″(x) 或 y″。
f′ 说明 f 在增还是在减，f″ 说明 f′（斜率）在增还是在减：
f″(x) > 0：斜率越来越大，曲线下凸（concave up），开口朝上；f″(x) < 0：斜率越来越小，曲线上凸（concave down）。
二阶导数判别法：驻点处 f″ > 0 是极小值，f″ < 0 是极大值，f″ = 0 则看不出，回到一阶导数符号表。
拐点：凹凸性改变的点。两个条件同时成立：①f″(x) = 0；②f″(x) 在该点两侧变号。水平拐点是同时满足 f′ = 0 的特例。
f″ > 0：下凸（开口向上）　f″ < 0：上凸（开口向下）
拐点：f″ = 0 且 f″ 变号

例 13（L24 Ex 1） Find the second derivative of: (a) y = x³ + 7x − 7 (b) y = (x³ − 3)⁴

看解答

(a) y′ = 3x² + 7，y″ = 6x。
(b) 链式法则：y′ = 4(x³ − 3)³ × 3x² = 12x²(x³ − 3)³。
再用乘积法则：y″ = 24x(x³ − 3)³ + 12x² × 3(x³ − 3)² × 3x² = 24x(x³ − 3)³ + 108x⁴(x³ − 3)²。
提公因式 12x(x³ − 3)²：y″ = 12x(x³ − 3)²[2(x³ − 3) + 9x³] = 12x(x³ − 3)²(11x³ − 6)。
Answer: (a) 6x (b) 12x(x³ − 3)²(11x³ − 6)

例 14（L24 Ex 2） Find the values of x for which the curve y = x³ − 3x² + 5x − 1 is concave down.

看解答

上凸（concave down）就是二阶导数小于 0：y′ = 3x² − 6x + 5，y″ = 6x − 6 < 0，解得 x < 1。
Answer: x < 1

例 15（L24 Ex 3） Find the stationary points on the curve y = x³ − 3x² − 9x − 1 and determine their nature.

看解答

y′ = 3x² − 6x − 9 = 3(x − 3)(x + 1) = 0，x = 3 或 −1。y(3) = 27 − 27 − 27 − 1 = −28；y(−1) = −1 − 3 + 9 − 1 = 4。
y″ = 6x − 6：x = 3 时 y″ = 12 > 0，(3, −28) 是极小值点；x = −1 时 y″ = −12 < 0，(−1, 4) 是极大值点。
Answer: MIN (3, −28), MAX (−1, 4)

y″ < 0 at x = −1 (MAX), y″ > 0 at x = 3 (MIN); inflection at x = 1

例 16（L24 Ex 4） Find the point of inflection for the curve y = x³ − 3x² − 9x − 18.

看解答

y″ = 6x − 6 = 0，x = 1。检查变号：x = 0 时 y″ = −6 < 0，x = 2 时 y″ = 6 > 0，变号成立。y(1) = 1 − 3 − 9 − 18 = −29。拐点 (1, −29)。
Answer: (1, −29)

Point of inflection (1, −29): concave down to the left, up to the right

例 17（L24 Ex 5） Show that the curve y = x⁴ + 4x has no point of inflection.

看解答

y′ = 4x³ + 4，y″ = 12x²。y″ = 0 只在 x = 0，但两侧 y″ = 12x² 都 > 0，不变号，所以 x = 0 不是拐点；曲线处处下凸，没有拐点。

y″ = 12x² ≥ 0: concave up everywhere, no point of inflection

易错
① 只要 f″ = 0 就说是拐点：必须检查变号（例 17）。
② 二阶导数判别法遇到 f″ = 0 就下结论：这时要回到一阶导数符号表。
③ 把「concave down」和「递减」混为一谈：凹凸说的是斜率的变化，不是函数本身。
常见疑惑
问：一阶导数法和二阶导数法哪个好？ 二阶导数好求时用二阶导数法更快；f″ = 0 或二阶导数很难求时用一阶导数符号表。
