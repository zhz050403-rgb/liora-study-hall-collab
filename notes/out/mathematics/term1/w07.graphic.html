变化率、切线与导函数（L19）

L19_Intro_Calculus.pdf · PDF p1–4

概念
微积分分为微分和积分。微分研究量变化得多快：变化率。
两点连线的斜率是平均变化率，只看起点和终点，看不出中间是越来越快还是越来越慢。要描述每一点的情况，需要瞬时变化率：曲线在某点的斜率，定义为该点切线的斜率。
斜率随点而变，所以斜率本身是 x 的函数，叫导函数（derivative），记作 f′(x)、dydx 或 y′；求导数叫求导（differentiation）。
由 f 的图像画 f′ 的草图：①f 的转折点（切线水平）处 f′ = 0；②f 上升处 f′ > 0，下降处 f′ < 0；③看 f 的陡峭程度判断 f′ 在增大还是减小。

例 1（L19 Rate of Change） Subscribers N (1000s) to a streaming service were 100 at t = 0 and 220 after 6 months. At what rate are people signing up?

看解答

平均变化率 = 两点连线的斜率：m = 220 − 1006 − 0 = 20，即平均每月新增 20 000 名用户。
但两条都经过这两点的曲线可以完全不同：一条斜率先小后大，一条先大后小。平均变化率看不出这种差别，所以需要每一点的瞬时变化率。
Answer: 平均 20（千人/月）

Both curves fit (0, 100) and (6, 220); the average rate is the chord gradient 20

例 2（L19 Ex 1） Consider the graph shown (a curve through (2, 4) with its tangent drawn). Find the gradient of the curve at the marked point.

看解答

曲线在 (2, 4) 的斜率就是那条切线的斜率。在切线上读两个点：大约 (0, 2) 和 (8, 10)，m = (10 − 2)/(8 − 0) = 1。
注：讲义图没有给方程；按图上的点 (2, 4)、(8, 8) 用 y = √(8x) 重画，切线 y = x + 2 与讲义的红线一致。
Answer: gradient ≈ 1

Tangent at (2, 4) rises 1 for every 1 across: gradient 1

例 3（L19 Ex 2） Sketch a tangent line and estimate the gradient of the curve at each of the points A, B and C (A(−1, 4), B the lowest point (1.5, −2.25), C(3, 0)).

看解答

在每点画一条只「擦过」曲线的直线，读出斜率。
A(−1, 4)：切线很陡、向下，约 −5。
B（最低点）：切线水平，斜率 0。
C(3, 0)：切线向上，约 3。
（曲线正是 y = x² − 3x，下周学的公式给出 f′(x) = 2x − 3，恰好得到 −5、0、3。）
Answer: A ≈ −5, B = 0, C ≈ 3

Tangents at A(−1, 4), B(1.5, −2.25), C(3, 0)

例 4（L19 Ex 3） The graph shows y = f(x) and the tangent at (−1, 5); the tangent cuts the y-axis at −4. Find (a) f(−1) (b) f′(−1) (c) f(2) (d) f′(2).

看解答

(a) 点在曲线上：f(−1) = 5。
(b) 切线过 (−1, 5) 和 (0, −4)：f′(−1) = (−4 − 5)/(0 − (−1)) = −9。
(c) 从图上读 x = 2 处是局部最高点，f(2) = 5。
(d) 最高点切线水平：f′(2) = 0。
注：讲义图只标了 (−1, 5) 和 −4；这里用经过这些点、在 x = 2 处取最高点的 f(x) = −x³ + 3x² + 1 重画，f(2) = 5 是按这条曲线读出的，讲义原图的最高点也在同一高度。
Answer: (a) 5 (b) −9 (c) 5 (d) 0

f(−1) = 5, f′(−1) = −9; f(2) = 5, f′(2) = 0

例 5（L19 Ex 4） Sketch the graph of y = f′(x) for each given graph of y = f(x): (a) an upward parabola with its minimum on the y-axis; (b) a curve rising from the left down to a minimum, up through the origin to a maximum, then falling.

看解答

(a) 左边下降（f′ < 0），x = 0 处最低（f′ = 0），右边上升（f′ > 0），而且越来越陡：f′ 是一条过原点、向上的直线。
(b) 两个转折点（x ≈ ±1）处 f′ = 0；两点之间曲线上升，f′ > 0；两侧下降，f′ < 0；中间原点附近最陡：f′ 是开口向下的抛物线，顶点在 x = 0。
注：讲义图只有形状；这里用 y = x² − 1 和 y = 3x − x³ 示意，红色虚线是对应的 f′。

(a) f has a minimum at x = 0 → f′ is a line crossing zero there

(b) turning points at x = ±1 → f′ = 0 there; f′ > 0 between them

易错
① 把平均变化率（弦的斜率）当成某一点的斜率。
② 读切线斜率时用了曲线上的点而不是切线上的点。
③ 画 f′ 时照抄 f 的形状：f′ 的零点在 f 的转折点，不在 f 的零点。
常见疑惑
问：切线只能碰曲线一个点吗？ 切线在切点附近只「擦过」曲线，但离开切点后可以再和曲线相交（例 4 的切线在右边又和曲线相交），这不影响它是切线。

基本求导法则（L20）

L20_Basic_Differentiation.pdf · PDF p1–3

概念
c 是常数：
• y = c（水平线）：dydx = 0。
• y = cx（直线）：dydx = c。
• 常数倍：y = c × f(x) ⇒ y′ = c × f′(x)。
• 和差：y = f(x) ± g(x) ⇒ y′ = f′(x) ± g′(x)。
• 幂法则：f(x) = xⁿ ⇒ f′(x) = nxⁿ⁻¹（乘以指数，指数减 1）。对负指数、分数指数同样成立：先把 1x³ 写成 x⁻³，√x 写成 x½。
乘积要先展开（如 (x + 2)(2x − 1)），本周后面还有乘积法则。
ddx xⁿ = nxⁿ⁻¹　　ddx c = 0　　ddx [cf(x)] = cf′(x)

例 6（L20 Ex 1） Differentiate: (a) f(x) = x⁷ (b) f(x) = 8 (c) f(x) = 3x (d) f(x) = 4x⁶ (e) y = 1x³ (f) y = √x (g) y = 2x³ + 7x + 9 (h) y = (x + 2)(2x − 1)

看解答

(a) 7x⁶。(b) 常数：0。(c) 3。(d) 4 × 6x⁵ = 24x⁵。
(e) y = x⁻³，y′ = −3x⁻⁴ = −3x⁴。
(f) y = x½，y′ = ½x−½ = 12√x。
(g) 6x² + 7（常数 9 的导数是 0）。
(h) 先展开：y = 2x² + 3x − 2，y′ = 4x + 3。
Answer: (a) 7x⁶ (b) 0 (c) 3 (d) 24x⁵ (e) −3/x⁴ (f) 1/(2√x) (g) 6x² + 7 (h) 4x + 3

例 7（L20 Ex 2） Find: (a) ddt(7t² − 11) (b) ddM(13M²) (c) ddy(1∛y) (d) ddr(4πr²)

看解答

变量换了字母，法则不变。
(a) 14t。
(b) 13M⁻² 的导数：13 × (−2)M⁻³ = −23M³。
(c) y−⅓ 的导数：−⅓y−4/3 = −13y∛y。
(d) 4π 是常数：8πr。
Answer: (a) 14t (b) −2/(3M³) (c) −⅓y^(−4/3) (d) 8πr

例 8（L20 Ex 3） (a) Find the gradient of the tangent to y = 2√x at x = 4. (b) Find the points on y = 2x² − x³ where the tangent is horizontal.

看解答

(a) y = 2x½，y′ = x−½ = 1√x；x = 4 时斜率 = ½。
(b) 水平切线 ⇔ y′ = 0：y′ = 4x − 3x² = x(4 − 3x) = 0，x = 0 或 43。代回：x = 0 时 y = 0；x = 4/3 时 y = 2 × 16/9 − 64/27 = 96/27 − 64/27 = 3227。点 (0, 0) 和 (4/3, 32/27)。
Answer: (a) ½ (b) (0, 0) and (4/3, 32/27)

Horizontal tangents at (0, 0) and (4/3, 32/27)

易错
① √x 求导写成 ½√x：先写成 x^½，指数减 1 得 x^(−½)。
② 1/x³ 求导写成 1/(3x²)：要先化成 x⁻³。
③ (x + 2)(2x − 1) 分别求导再相乘：乘积不能这样做。
④ 求出 x 后忘了代回求 y（例 8(b) 问的是点）。
常见疑惑
问：dy/dx 是分数吗？ 它是一个整体记号，表示「y 对 x 的导数」，不能随便约分；但很多性质（如链式法则）看起来像分数相乘，方便记忆。

链式法则（L20）

L20_Basic_Differentiation.pdf · PDF p4

概念
一个函数套在另一个函数里，例如 y = √(3 − 4x²) 是 3 − 4x² 套在 √ 里面。
链式法则：y = f(g(x)) ⇒ dydx = f′(g(x)) × g′(x)。即先对外层求导（里面原样不动），再乘以里层的导数。
常用形式：ddx[g(x)]ⁿ = n[g(x)]ⁿ⁻¹ × g′(x)。
ddx f(g(x)) = f′(g(x)) × g′(x)

例 9（L20 Ex 4） Differentiate: (a) f(x) = (5x − 1)⁷ (b) f(x) = √(2x + 7) (c) y = (x² + 2x + 5)³ (d) y = 1√(3 − 4x²)

看解答

每题先认出里层，外层求导后乘以里层的导数。
(a) 里层 5x − 1，导数 5：7(5x − 1)⁶ × 5 = 35(5x − 1)⁶。
(b) (2x + 7)½：½(2x + 7)−½ × 2 = 1√(2x + 7)。
(c) 3(x² + 2x + 5)² × (2x + 2) = 6(x + 1)(x² + 2x + 5)²。
(d) (3 − 4x²)−½：−½(3 − 4x²)−3/2 × (−8x) = 4x(3 − 4x²)3/2。
Answer: (a) 35(5x − 1)⁶ (b) 1/√(2x + 7) (c) 6(x + 1)(x² + 2x + 5)² (d) 4x/(3 − 4x²)^(3/2)

例 10（L20 Ex 5） Find the point on the curve y = √(x − 3) where the gradient of the tangent is 1.

看解答

y′ = ½(x − 3)−½ = 12√(x − 3)。令其等于 1：√(x − 3) = ½，x − 3 = ¼，x = 3¼；y = ½。点 (3¼, ½)。
Answer: (13/4, 1/2)

Gradient 1 at (3¼, ½)

易错
① 只对外层求导，忘了乘里层的导数。
② 对外层求导时把里层也改了：外层求导时里面原样保留。
常见疑惑
问：怎么判断要不要用链式法则？ 看括号或根号里面是不是只有单独一个 x。里面是 5x − 1、x² + 2x + 5 这样的式子，就要乘里层导数。

乘积法则与商法则（L21）

L21_Further_Differentiation.pdf · PDF p1–4

概念
和差可以分别求导，但乘积、商不行：ddx(f × g) ≠ f′ × g′，ddx(f/g) ≠ f′/g′。
乘积法则：ddx(uV) = u′V + uV′。
商法则：ddx(uV) = u′V − uV′V²（分子里是减号，顺序不能反）。讲义由 y = uV⁻¹ 用乘积法则和链式法则推出。
结果尽量提公因式、化简。求水平切线：令导数 = 0，商的导数为 0 只需分子为 0。
(uV)′ = u′V + uV′　　(u/V)′ = u′V − uV′V²

例 11（L21 Ex 1） (a) Use the product rule to differentiate y = (x² + 7)(2x − 3). (b) By expanding and then using basic differentiation, find the derivative of the same function.

看解答

(a) u = x² + 7，u′ = 2x；V = 2x − 3，V′ = 2。y′ = 2x(2x − 3) + 2(x² + 7) = 4x² − 6x + 2x² + 14 = 6x² − 6x + 14。
(b) 展开：y = 2x³ − 3x² + 14x − 21，y′ = 6x² − 6x + 14。两种方法结果相同。
Answer: 6x² − 6x + 14

例 12（L21 Ex 2） Differentiate: (a) y = (3x − 4)³(4x + 1)⁵ (b) f(x) = (x² + 7)√(3 − 4x)

看解答

(a) u = (3x − 4)³，u′ = 9(3x − 4)²；V = (4x + 1)⁵，V′ = 20(4x + 1)⁴（都用了链式法则）。
y′ = 9(3x − 4)²(4x + 1)⁵ + 20(3x − 4)³(4x + 1)⁴，提公因式 (3x − 4)²(4x + 1)⁴：
y′ = (3x − 4)²(4x + 1)⁴[9(4x + 1) + 20(3x − 4)] = (3x − 4)²(4x + 1)⁴(96x − 71)。
(b) u = x² + 7，u′ = 2x；V = (3 − 4x)½，V′ = ½(3 − 4x)−½ × (−4) = −2√(3 − 4x)。
f′ = 2x√(3 − 4x) − 2(x² + 7)√(3 − 4x)，通分：2x(3 − 4x) − 2(x² + 7)√(3 − 4x) = −10x² + 6x − 14√(3 − 4x) = −2(5x² − 3x + 7)√(3 − 4x)。
Answer: (a) (3x − 4)²(4x + 1)⁴(96x − 71) (b) −2(5x² − 3x + 7)/√(3 − 4x)

例 13（L21 Ex 3） Differentiate: (a) y = 3x − 2x + 1 (b) y = x² + 3x² − 5

看解答

分子、分母分别求导，代入商法则，分子展开合并。
(a) u = 3x − 2，u′ = 3；V = x + 1，V′ = 1。y′ = 3(x + 1) − (3x − 2)(x + 1)² = 5(x + 1)²。
(b) u = x² + 3，u′ = 2x；V = x² − 5，V′ = 2x。y′ = 2x(x² − 5) − 2x(x² + 3)(x² − 5)² = −16x(x² − 5)²。
Answer: (a) 5/(x + 1)² (b) −16x/(x² − 5)²

例 14（L21 Ex 4） For f(x) = x²x + 1, find the points on y = f(x) where the tangent is horizontal.

看解答

商法则：f′(x) = 2x(x + 1) − x² × 1(x + 1)² = x² + 2x(x + 1)² = x(x + 2)(x + 1)²。
令分子为 0：x = 0 或 x = −2。f(0) = 0，f(−2) = 4/(−1) = −4。点 (0, 0) 和 (−2, −4)。
Answer: (0, 0) and (−2, −4)

Horizontal tangents at (0, 0) and (−2, −4); vertical asymptote x = −1

易错
① 商法则分子写成 uV′ − u′V：符号反了。
② 乘积法则中 (3x − 4)³ 的导数忘了乘 3（链式法则）。
③ 化简时提公因式出错：先找两项共同的最低次幂。
常见疑惑
问：能展开时还要用乘积法则吗？ 都可以，结果一样（例 11）。式子简单时展开更快；有高次幂或根号时用乘积法则更方便。
