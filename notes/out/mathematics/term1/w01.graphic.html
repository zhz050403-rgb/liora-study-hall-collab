代入、合并同类项、展开（L1 Simplifying & Expanding）

L01_Basic_Algebra.pdf · PDF p1

概念
代入求值：负数代入时加括号，先算乘方再算乘除。合并同类项：字母和指数完全相同的项才能合并（3y² 和 y² 是同类项，x 和 y² 不是）。展开：括号前是负号时，括号内每一项都变号。

例 1（L1 Ex 1） If x = 8, y = −4, z = −3, evaluate: (a) −3z² (b) xy + 22z

看解答

(a) z² = (−3)² = 9，所以 −3z² = −27（先平方再乘 −3，不是 (−3z)²）。
(b) xy + 2 = 8 × (−4) + 2 = −30，2z = −6，结果 (−30) ÷ (−6) = 5。
Answer: (a) −27 (b) 5

例 2（L1 Ex 2） Simplify: (a) 3a + 5a − a + 4a (b) 2x + 3y² − 5x + y²

看解答

(a) 3 + 5 − 1 + 4 = 11，结果 11a。
(b) x 项：2x − 5x = −3x；y² 项：3y² + y² = 4y²。结果 −3x + 4y²。
Answer: (a) 11a (b) 4y² − 3x

例 3（L1 Ex 3） Expand and simplify: (a) 2(2x + 3) − (x − 5) (b) (a + 3b)(2a − 3b)

看解答

(a) 4x + 6 − x + 5 = 3x + 11（−(x − 5) = −x + 5）。
(b) 逐项相乘：2a² − 3ab + 6ab − 9b² = 2a² + 3ab − 9b²。
Answer: (a) 3x + 11 (b) 2a² + 3ab − 9b²

易错
① −3z² 算成 (−3z)²。
② −(x − 5) 写成 −x − 5。
常见疑惑
问：怎么检查化简对不对？ 随便代一个数进原式和结果，两边相等就基本没错（本页的核对就是这样做的）。

因式分解与代数分式（L1 Factorisation & Algebraic Fractions）

L01_Basic_Algebra.pdf · PDF p2–5

概念
四种因式分解：①提公因式 ab + ac = a(b + c)；②平方差 a² − b² = (a − b)(a + b)；③分组 ax + ay + bx + by = (a + b)(x + y)；④二次三项式 x² + (m + n)x + mn = (x + m)(x + n)，首项系数不是 1 时用十字相乘。
检查顺序：①先找公因式；②两项看平方差；③三项看二次三项式；④四项及以上用分组。常要连用两种以上。
代数分式：化简时先把分子分母分解，再约去公因式；加减时先通分（公分母）。
a² − b² = (a − b)(a + b)　　x² + (m + n)x + mn = (x + m)(x + n)

例 4（L1 Ex 4） Factorise: (a) 2x² + 6x (b) 8b − 80c − b² + 10bc (c) 9y² − 16 (d) x² − 4x − 12 (e) 2x² − 5x − 12 (f) x² + 2x + 1 − y²

看解答

(a) 公因式 2x：2x(x + 3)。
(b) 四项用分组：(8b − b²) + (10bc − 80c) = b(8 − b) − 10c(8 − b) = (8 − b)(b − 10c)。
(c) 平方差：(3y)² − 4² = (3y − 4)(3y + 4)。
(d) 找积为 −12、和为 −4 的两数：−6 和 2，(x − 6)(x + 2)。
(e) 十字相乘：2x² − 5x − 12 = (2x + 3)(x − 4)，检查 2x·(−4) + 3·x = −5x。
(f) 前三项是完全平方：(x + 1)² − y² = (x + 1 − y)(x + 1 + y)。
Answer: (a) 2x(x+3) (b) (8−b)(b−10c) (c) (3y−4)(3y+4) (d) (x−6)(x+2) (e) (2x+3)(x−4) (f) (x+1−y)(x+1+y)

例 5（L1 Ex 5） Simplify: (a) 5a²15ab (b) 5a − 15a² − 9 (c) x² + 3x + 2x² + 5x + 6 (d) 3m − 64 × 8m2m − m² (e) 53y² ÷ 23y

看解答

(a) 约去 5a：a3b。
(b) 5(a − 3) ÷ [(a − 3)(a + 3)] = 5a + 3。
(c) (x + 1)(x + 2) ÷ [(x + 2)(x + 3)] = x + 1x + 3。
(d) 3(m − 2)/4 × 8m/[m(2 − m)]：m − 2 = −(2 − m)，约分得 3 × 8 × (−1)/4 = −6。
(e) 除以分式等于乘倒数：53y² × 3y2 = 52y。
Answer: (a) a/(3b) (b) 5/(a+3) (c) (x+1)/(x+3) (d) −6 (e) 5/(2y)

例 6（L1 Ex 6） Simplify: (a) x + 34 − x − 17 (b) 5y18 − y28 + y52 (c) 2x²3x + 3y − 2x³x² + xy (d) 2x² − 1 − 1x² − x + x − 1x² + x

看解答

(a) 公分母 28：[7(x + 3) − 4(x − 1)]/28 = 3x + 2528。
(b) 18 = 2·3²，28 = 2²·7，52 = 2²·13，最小公分母 2²·3²·7·13 = 3 276：(910y − 117y + 63y)/3 276 = 856y/3 276 = 214y819。
(c) 第二项约分：2x³/[x(x + y)] = 2x²/(x + y)；通分：[2x² − 6x²]/[3(x + y)] = −4x²3(x + y)。
(d) 分母分解为 (x − 1)(x + 1)、x(x − 1)、x(x + 1)，公分母 x(x − 1)(x + 1)：分子 2x − (x + 1) + (x − 1)² = x² − x = x(x − 1)，约分得 1x + 1。
Answer: (a) (3x+25)/28 (b) 214y/819 (c) −4x²/(3(x+y)) (d) 1/(x+1)

易错
① 分式化简时约去「项」而不是「因式」：(x + 2)/(x + 3) 不能约。
② 2m − m² 分解成 m(2 − m) 后忘了与 (m − 2) 差一个负号。
③ 通分时只乘分母不乘分子。
常见疑惑
问：十字相乘找不到怎么办？ 用二次公式求出两根 r₁、r₂，ax² + bx + c = a(x − r₁)(x − r₂)。

根式与分母有理化（L2 Surds）

L02_Surds_and_Indices.pdf · PDF p1–2

概念
a ≥ 0、b ≥ 0 时：(√a)² = √(a²) = a；√a × √b = √(ab)；√a ÷ √b = √(a/b)；√(a²b) = a√b。
化简根式：把被开方数里最大的完全平方因数开出来（√20 = 2√5）。只有同类根式才能加减。
分母有理化：分母是 √b 时上下乘 √b；分母是 a + √b 时上下乘共轭 a − √b，利用 (a + √b)(a − √b) = a² − b。

例 7（L2 Ex 1） Simplify: (a) √8 − √2 (b) √20 − 2√45 (c) 3√242 (d) √3 − √9 − √27 + √81 (e) (√3 − √2)² (f) (√5 + 2√2)(√5 − 3√2)

看解答

先把每个根式化成最简（开出平方因数），再合并同类根式。
(a) 2√2 − √2 = √2。
(b) 2√5 − 2 × 3√5 = −4√5。
(c) 242 = 121 × 2，3 × 11√2 = 33√2。
(d) √3 − 3 − 3√3 + 9 = 6 − 2√3。
(e) 3 − 2√6 + 2 = 5 − 2√6。
(f) 5 − 3√10 + 2√10 − 6 × 2 = −7 − √10。
Answer: (a) √2 (b) −4√5 (c) 33√2 (d) 6 − 2√3 (e) 5 − 2√6 (f) −7 − √10

例 8（L2 Ex 2） Rationalise the denominator: (a) 52√3 (b) 1√3 + 5 (c) √2 + 1√2 − 1

看解答

(a) 上下乘 √3：5√36。
(b) 上下乘 5 − √3：(5 − √3)/(25 − 3) = 5 − √322。
(c) 上下乘 √2 + 1：(√2 + 1)²/(2 − 1) = 3 + 2√2。
Answer: (a) 5√3/6 (b) (5 − √3)/22 (c) 3 + 2√2

例 9（L2 Ex 3） Find integers p and q if p − √q = (5√2 − 4√3)(3√2 − 2√3).

看解答

展开：5√2 × 3√2 = 30；5√2 × (−2√3) = −10√6；−4√3 × 3√2 = −12√6；−4√3 × (−2√3) = 24。合计 54 − 22√6 = 54 − √(484 × 6) = 54 − √2 904。所以 p = 54，q = 2 904。
Answer: p = 54, q = 2904

易错
① √a + √b 写成 √(a + b)。
② 有理化时只乘分母。
③ (√3 − √2)² 漏掉中间项 −2√6。
常见疑惑
问：为什么要把 22√6 写成 √2 904？ 题目要求 p − √q 的形式，q 必须是根号里的整数：22√6 = √(22² × 6)。

指数律与指数方程（L2 Indices）

L02_Surds_and_Indices.pdf · PDF p3–5

概念
aⁿ 中 a 是底数，n 是指数。指数律：aᵐ × aⁿ = aᵐ⁺ⁿ；aᵐ ÷ aⁿ = aᵐ⁻ⁿ；(aᵐ)ⁿ = aᵐⁿ；(ab)ᵐ = aᵐbᵐ；(a/b)ᵐ = aᵐ/bᵐ；a⁰ = 1；a−m = 1/aᵐ；a1/n = ⁿ√a；am/n = (ⁿ√a)ᵐ = ⁿ√(aᵐ)。
指数方程：如果 aᵐ = aⁿ（a > 0，a ≠ 1），那么 m = n——先把两边化成同一个底数。

例 10（L2 Ex 4） Simplify: (a) x⁶ × x⁷ ÷ x³ (b) (x⁸)³ (c) 8y × (2y²)³16y³ × y⁵ (d) 12m+1 × 22m18m

看解答

(a) x6+7−3 = x¹⁰。
(b) x²⁴。
(c) 分子 8y × 8y⁶ = 64y⁷，分母 16y⁸，结果 4/y。
(d) 化成质数底：12 = 2²·3，18 = 2·3²。分子 22m+2·3m+1·22m = 24m+2·3m+1，分母 2m·32m，结果 23m+2·31−m。
Answer: (a) x¹⁰ (b) x²⁴ (c) 4/y (d) 2^(3m+2)·3^(1−m)

例 11（L2 Ex 5） Write without negative indices: (a) 2x⁻³ (b) (2x)⁻³ (c) (x + yx − y)⁻¹

看解答

(a) 只有 x 带负指数：2x³。
(b) 整个 2x 带负指数：18x³。
(c) 倒数：x − yx + y。
Answer: (a) 2/x³ (b) 1/(8x³) (c) (x − y)/(x + y)

例 12（L2 Ex 6） Simplify: (a) √(9x⁸y²) (b) ⁴√((9x¹⁰)²) × 5x⁴√(49x¹⁶)

看解答

(a) 3x⁴y（取 y ≥ 0；一般写 3x⁴|y|）。
(b) (9x¹⁰)² = 81x²⁰，四次方根是 3x⁵；乘 5x⁴ 得 15x⁹；√(49x¹⁶) = 7x⁸；结果 15x7。
Answer: (a) 3x⁴y (b) 15x/7

例 13（L2 Ex 7） Solve: (a) 7x−3 = 49 (b) 27x = 13√3

看解答

(a) 49 = 7²，所以 x − 3 = 2，x = 5。
(b) 27ˣ = 33x；3√3 = 31.5，所以右边 = 3−3/2。3x = −3/2，x = −12。
Answer: (a) x = 5 (b) x = −1/2

例 14（L2 Ex 8） Solve: (a) x⁴ = 81 (b) x1/3 = 2 (c) x−2/3 = 16

看解答

(a) x = ±3（偶次方有正负两根）。
(b) 两边立方：x = 8。
(c) x2/3 = 1/16，所以 (x1/3)² = 1/16，x1/3 = ±1/4，x = ±164。
Answer: (a) ±3 (b) 8 (c) ±1/64

易错
① (2x)⁻³ 写成 2/x³。
② x⁴ = 81 只写 x = 3。
③ 27ˣ 没有化成以 3 为底。
常见疑惑
问：负数的分数指数怎么处理？ 本课程一般限定底数为正；像 x−2/3 = 16 这类偶数次根，要考虑 ± 两种情况。

一次方程与不等式；变换主项（L3 Linear）

L03_Equations.pdf · PDF p1

概念
解一次方程：去括号、去分母（两边乘最小公分母）、移项、合并、系数化为 1。不等式的运算与方程相同，只有一点不同：两边乘或除以负数时不等号反向。解集画在数轴上：含等号用实心点，不含用空心点。

例 15（L3 Ex 1） Solve: (a) 4x − 3(2x + 5) = 3(x − 2) (b) x + 13 + 2x7 = 9

看解答

(a) 4x − 6x − 15 = 3x − 6 → −2x − 15 = 3x − 6 → −5x = 9 → x = −95。
(b) 两边乘 21：7(x + 1) + 6x = 189 → 13x = 182 → x = 14。
Answer: (a) x = −9/5 (b) x = 14

例 16（L3 Ex 2） Change the subject: (a) y = 7 − 3x (x) (b) T = 2π√(l/g) (g)

看解答

(a) 3x = 7 − y，x = 7 − y3。
(b) T/(2π) = √(l/g)，两边平方：T²/(4π²) = l/g，所以 g = 4π²lT²。
Answer: (a) x = (7 − y)/3 (b) g = 4π²l/T²

例 17（L3 Ex 3） Solve and graph on a number line: (a) 2x + 1 > 2 + x (b) x − 13 ≤ 1 + 2x4

看解答

(a) x > 1（空心点）。
(b) 两边乘 12：4x − 4 ≤ 3 + 6x → −2x ≤ 7 → 除以 −2 时不等号反向：x ≥ −72（实心点）。
Answer: (a) x > 1 (b) x ≥ −7/2

(a) x > 1

(b) x ≥ −7/2

易错
① 除以负数忘了变号。
② 去分母时漏乘不带分母的项。
常见疑惑
问：为什么乘负数要变号？ 例如 2 < 3，乘 −1 后 −2 > −3，大小关系反过来了。

二次方程、联立方程、绝对值（L3）

L03_Equations.pdf · PDF p2–6

概念
二次方程的四种解法：①开平方（形如 (ax + b)² = c）；②因式分解；③配方（x² + bx = c → (x + b/2)² = c + (b/2)²，首项系数先化为 1）；④公式 x = −b ± √(b² − 4ac)2a。
联立方程：代入法或消元法；一线一曲时用代入。
绝对值：|x| = x（x ≥ 0），= −x（x < 0）。方程 |ax + b| = c → ax + b = ±c；|ax + b| = |cx + d| 或 = cx + d → ax + b = cx + d 或 ax + b = −(cx + d)，第二种情况要检验（右边不能为负）。不等式：|ax + b| < c → −c < ax + b < c；|ax + b| > c → ax + b > c 或 ax + b < −c。
x = −b ± √(b² − 4ac)2a

例 18（L3 Ex 4） Solve by the square root method: (a) x² − 16 = 0 (b) (2x − 1)² = 25

看解答

(a) x² = 16，x = ±4。
(b) 2x − 1 = ±5，x = 3 或 x = −2。
Answer: (a) ±4 (b) 3, −2

例 19（L3 Ex 5） Solve by factorising: (a) x² + 8x − 9 = 0 (b) 2x² + 5x − 12 = 0

看解答

(a) (x + 9)(x − 1) = 0，x = −9 或 1。
(b) (2x − 3)(x + 4) = 0，x = 32 或 −4。
Answer: (a) −9, 1 (b) 3/2, −4

例 20（L3 Ex 6） Solve by completing the square: (a) x² + 4x − 12 = 0 (b) 2x² − 4x + 1 = 0

看解答

(a) x² + 4x = 12 → x² + 4x + 4 = 16 → (x + 2)² = 16 → x + 2 = ±4 → x = 2 或 −6。
(b) 先除以 2：x² − 2x = −1/2 → (x − 1)² = 1/2 → x = 1 ± 1√2 = 2 ± √22。
Answer: (a) 2, −6 (b) (2 ± √2)/2

例 21（L3 Ex 7） Use the quadratic formula: (a) 2x² − 2x − 3 = 0, in simplest surd form (b) x² + x = 5, correct to 3 significant figures.

看解答

(a) a = 2，b = −2，c = −3：x = [2 ± √(4 + 24)]/4 = (2 ± 2√7)/4 = 1 ± √72。
(b) 先移项 x² + x − 5 = 0：x = (−1 ± √21)/2，√21 ≈ 4.583，x ≈ 1.79 或 −2.79。
Answer: (a) (1 ± √7)/2 (b) 1.79, −2.79

例 22（L3 Ex 8） Solve simultaneously: (a) x − 2y = −3, 2x − 3y = 2 (b) x² + y² = 10, y = −3x

看解答

(a) 由第一式 x = 2y − 3，代入：2(2y − 3) − 3y = 2 → y = 8，x = 13。
(b) 代入：x² + 9x² = 10 → x² = 1 → x = ±1；y = −3x。解为 (1, −3) 和 (−1, 3)。
Answer: (a) x = 13, y = 8 (b) (1, −3), (−1, 3)

例 23（L3 Ex 9） Solve: (a) |x + 3| = 8 (b) |5 − 3x| = |x + 3| (c) |x + 7| = 2x − 1

看解答

(a) x + 3 = 8 或 −8：x = 5 或 −11。
(b) 5 − 3x = x + 3 → x = 1/2；5 − 3x = −(x + 3) → x = 4。两个都成立。
(c) 右边必须 ≥ 0，即 x ≥ 1/2。x + 7 = 2x − 1 → x = 8 ✓；x + 7 = −(2x − 1) → x = −2，此时右边 2x − 1 = −5 < 0，舍去。只有 x = 8。
Answer: (a) 5, −11 (b) 1/2, 4 (c) 8

例 24（L3 Ex 10） Solve: (a) |3 − x| ≤ 7 (b) |3x| ≥ 12 (c) |7 − 2x| > 8

看解答

(a) −7 ≤ 3 − x ≤ 7 → −10 ≤ −x ≤ 4 → −4 ≤ x ≤ 10。
(b) 3x ≥ 12 或 3x ≤ −12：x ≥ 4 或 x ≤ −4。
(c) 7 − 2x > 8 → x < −1/2；或 7 − 2x < −8 → x > 15/2。
Answer: (a) −4 ≤ x ≤ 10 (b) x ≤ −4 or x ≥ 4 (c) x < −1/2 or x > 15/2

(a) −4 ≤ x ≤ 10

(b) x ≤ −4 or x ≥ 4

(c) x < −1/2 or x > 15/2

易错
① 配方前没有把首项系数化为 1。
② 绝对值方程第二种情况不检验。
③ |x| > c 的解写成 −c < x < c：大于号是「两边分开」。
常见疑惑
问：什么时候用公式法？ 分解不出来、或题目要求精确的根式答案或小数近似时。
