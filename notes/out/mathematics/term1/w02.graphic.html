坐标几何：距离、中点、斜率、直线方程（L4）

L04_Coordinate_Geometry.pdf · PDF p1–5

概念
A(x₁, y₁)、B(x₂, y₂)：距离 d = √[(x₂ − x₁)² + (y₂ − y₁)²]；中点 M = (x₁ + x₂2, y₁ + y₂2)；斜率 m = y₂ − y₁x₂ − x₁（RISE/RUN）。斜率可正、可负、为零（水平线）或不存在（竖直线）。
平行：m₁ = m₂；垂直：m₁ × m₂ = −1，即 m₂ = −1/m₁；共线：mAB = mBC。
直线方程：水平线 y = c；竖直线 x = c；斜截式 y = mx + b；一般式 ax + by + c = 0；点斜式 y − y₁ = m(x − x₁)。点在直线上 ⇔ 坐标满足方程；两直线交点用联立方程求。垂直平分线：过 AB 中点且垂直于 AB 的直线。
d = √[(x₂ − x₁)² + (y₂ − y₁)²]　　M = (x₁ + x₂2, y₁ + y₂2)　　m = y₂ − y₁x₂ − x₁
y − y₁ = m(x − x₁)　　m₁m₂ = −1（垂直）

例 1（L4 Ex 1） A line passes through P(2, −1) and Q(−3, 5). Find (a) the gradient of PQ; (b) the gradient of a line parallel to PQ; (c) the gradient of a line perpendicular to PQ.

看解答

(a) m = (5 − (−1)) ÷ (−3 − 2) = 6 ÷ (−5) = −65。
(b) 平行线斜率相同：−6/5。
(c) 垂直：取负倒数，56。
Answer: (a) −6/5 (b) −6/5 (c) 5/6

例 2（L4 Ex 2） For A(3, 4) and B(9, −6) find (a) the distance AB; (b) the midpoint of AB.

看解答

用距离公式和中点公式。
(a) d = √[(9 − 3)² + (−6 − 4)²] = √(36 + 100) = √136 = 2√34 ≈ 11.66。
(b) M = ((3 + 9)/2, (4 − 6)/2) = (6, −1)。
Answer: (a) 2√34 (b) (6, −1)

例 3（L4 Ex 3） Find the equation of a line with gradient −3 and y-intercept 2.

看解答

斜截式：y = −3x + 2。
Answer: y = −3x + 2

例 4（L4 Ex 4） Find the gradient of the line 2x − 3y = 7.

看解答

化成 y = mx + b：3y = 2x − 7，y = 23x − 73，斜率 2/3。
Answer: m = 2/3

例 5（L4 Ex 5） Find the equation of a line through (−6, 2) with gradient 3.

看解答

点斜式：y − 2 = 3(x + 6)，y = 3x + 20。
Answer: y = 3x + 20

例 6（L4 Ex 6） Find the equation of a line through (−2, 5) perpendicular to 3x − 2y + 8 = 0, in general form.

看解答

已知直线 y = 32x + 4，斜率 3/2；垂线斜率 −23。y − 5 = −23(x + 2)，两边乘 3：3y − 15 = −2x − 4，一般式 2x + 3y − 11 = 0。
Answer: 2x + 3y − 11 = 0

例 7（L4 Ex 7） Find the equation of a line through (−1, 6) parallel to the x-axis.

看解答

平行于 x 轴的直线是水平线，y 坐标处处相同：y = 6。
Answer: y = 6

例 8（L4 Ex 8） If M(−1, 2), N(2, 5) and P(2 + 3k, 3 − 4k) are collinear, find k.

看解答

共线 ⇒ mMN = mNP。mMN = (5 − 2)/(2 + 1) = 1。mNP = (3 − 4k − 5)/(2 + 3k − 2) = (−2 − 4k)/(3k)。令其等于 1：−2 − 4k = 3k，k = −27。
Answer: k = −2/7

例 9（L4 Ex 9） Given A = (2, 7) and B = (−1, 3), find the equation of the perpendicular bisector of AB.

看解答

中点 M = (0.5, 5)；mAB = (3 − 7)/(−1 − 2) = 4/3；垂直平分线斜率 −3/4。y − 5 = −34(x − 0.5)，两边乘 8：8y − 40 = −6x + 3，即 6x + 8y − 43 = 0。
Answer: 6x + 8y − 43 = 0

易错
① 斜率分子分母顺序不一致（一个用 y₂ − y₁，一个用 x₁ − x₂）。
② 垂直斜率只取倒数忘了变号。
③ 一般式写成 2x + 3y = 11 而题目要求 ax + by + c = 0。
常见疑惑
问：竖直线的斜率是多少？ 不存在（分母为 0），方程写成 x = c。

关系、函数、定义域与值域（L5）

L05_Relations_and_Functions.pdf · PDF p1–4

概念
关系：有序数对的集合。函数：没有两个点的 x 坐标相同的关系（每个 x 只对应一个 y）。竖线检验：任一竖直线与图像最多交一点，图像才是函数。
定义域：所有 x 坐标的集合；值域：所有 y 坐标的集合。由方程求定义域：找出所有能代入的 x（分母不为 0、偶次根号下 ≥ 0），叫最大可能定义域或自然定义域。
函数记号 f(x)（读作「f of x」）：x 是自变量，y 是因变量。复合 f(g(x))：先算 g，再把结果代入 f。

例 10（L5 Relation） Is {(1, 2), (3, 4), (3, 5), (−1, 5)} a relation or a function? What about {(1, 2), (3, 4), (4, 5), (−1, 5)}?

看解答

第一个集合中 x = 3 对应 4 和 5 两个 y，只是关系，不是函数。第二个集合每个 x 只对应一个 y（不同的 x 可以对应同一个 y，如 5），是函数。

例 11（L5 Ex 1） Use the vertical line test to decide which graphs are functions: (a) an upward parabola; (b) a sideways parabola opening right; (c) a horizontal line; (e) a circle; (f) two horizontal rays — y > 0 for x < 0 ending in an open circle on the y-axis, y < 0 for x ≥ 0 starting with a closed circle; (g) two vertical lines.

看解答

(a) 是函数。(b) 不是：竖线与它交两点。(c) 是函数（常数函数）。(e) 不是：圆。(f) 是函数：在 x = 0 处空心点不算，只有实心点那一个值。(g) 不是：竖线本身就与图像有无数交点。
注：讲义这一组图的标签是 (a)(b)(c)(e)(f) 和一个没有标签的第六幅（缺 (d)），这里把第六幅记作 (g)。

(a) function

(b) x = y²: not a function

(f) function (open/closed ends at x = 0)

例 12（L5 Ex 2） Find the domain and range: (a) {(1, 2), (3, 1), (4, 2), (5, 6), (7, −3)}; (b) an upward parabola through the origin; (c) a semicircle to the right of the y-axis from (0, 3) to (0, −3); (d) a straight line through (−1, 0) and (0, 1); (e) the hyperbola y = 1/x; (f) a circle with centre (3, 2) touching the x-axis; (g) y = −1 for −2 ≤ x < 0 and y = 2 for 0 < x < 3 (open circles at x = 0 and x = 3).

看解答

(a) 定义域 {1, 3, 4, 5, 7}，值域 {−3, 1, 2, 6}。
(b) 定义域全体实数，值域 y ≥ 0。
(c) 半径 3 的右半圆：定义域 0 ≤ x ≤ 3，值域 −3 ≤ y ≤ 3。
(d) 直线：定义域、值域都是全体实数。
(e) 定义域 x ≠ 0，值域 y ≠ 0。
(f) 圆心 (3, 2) 且与 x 轴相切，半径 2：定义域 1 ≤ x ≤ 5，值域 0 ≤ y ≤ 4。
(g) 定义域 −2 ≤ x < 0 或 0 < x < 3（x = 0 处两端都是空心）；值域 {−1, 2}。
注：(g) 右段的终点按图读在 x = 3（空心）。

例 13（L5 Ex 3） Find the largest possible domain: (a) y = 2x + 4 (b) y = 2x (c) y = √x

看解答

(a) 任何 x 都可以代入：全体实数。
(b) 分母不能为 0：x ≠ 0。
(c) 根号下不能为负：x ≥ 0。

例 14（L5 Ex 4） Given f(x) = 2x² − 7x: (i) find (a) f(−3) (b) f(t) (c) f(x²); (ii) solve f(x) = 4.

看解答

(i)(a) 2 × 9 + 21 = 39。(b) 2t² − 7t。(c) 2x⁴ − 7x²。
(ii) 2x² − 7x − 4 = 0 → (2x + 1)(x − 4) = 0 → x = 4 或 −12。
Answer: (a) 39 (b) 2t² − 7t (c) 2x⁴ − 7x²; x = 4 or −1/2

例 15（L5 Ex 5） If f(x) = 2x − 3 and g(x) = 3xx − 1, find (a) f(g(3)) (b) g(f(3)).

看解答

(a) g(3) = 9/2，f(9/2) = 9 − 3 = 6。
(b) f(3) = 3，g(3) = 9/2。先算里面的函数。
Answer: (a) 6 (b) 9/2

例 16（L5 Ex 6） From the graph of y = f(x) (zeros at x = −3, 0, 4, 8; maximum (2, 2); minimum (6, −3)): (a) f(6); (b) f(−3); (c) the x values with f(x) = 2; (d) the range for −3 < x < 6.

看解答

(a) f(6) = −3（最低点）。
(b) f(−3) = 0（与 x 轴的交点）。
(c) y = 2 的水平线与图像相交：最高点 x = 2；另外在左右两端外侧的上升段上也各有一点，读图约为 x ≈ −3.3 和 x ≈ 8.8。
(d) −3 < x < 6 上，最高值 2（x = 2），最低值趋近 −3 但 x = 6 不包括在内：值域 −3 < y ≤ 2。
注：(c) 两端的交点只能读图估计；如果题目只考虑图中「中间部分」，答案是 x = 2。

易错
① 把定义域、值域写反。
② 看到 (b) 侧放的抛物线只说「是曲线」：要用竖线检验说明。
③ 复合函数先算外面。
常见疑惑
问：不同的 x 对应同一个 y 是函数吗？ 是。函数只要求每个 x 只有一个 y。

奇函数与偶函数（L5）

L05_Relations_and_Functions.pdf · PDF p5–6

概念
偶函数：关于 y 轴对称，f(−x) = f(x)。奇函数：关于原点对称（旋转 180° 不变），f(−x) = −f(x)。很多函数既不是奇函数也不是偶函数。判断方法：把 −x 代入，化简后与 f(x)、−f(x) 比较。奇函数如果在 x = 0 有定义，必然 f(0) = 0。

例 17（L5 Ex 7） Even, odd or neither: (a) h(x) = 2x³ + x (b) g(x) = (2 − x)² (c) f(x) = 11 + x² (d) F(x) = x(4 − x²)

看解答

(a) h(−x) = −2x³ − x = −h(x)：奇函数。
(b) g(−x) = (2 + x)²，既不等于 g(x) 也不等于 −g(x)：既不奇也不偶（例如 g(1) = 1，g(−1) = 9）。
(c) f(−x) = 1/(1 + x²) = f(x)：偶函数。
(d) F(−x) = −x(4 − x²) = −F(x)：奇函数。

例 18（L5 Ex 8） Complete each graph so that f(x) is even: (a) an arc from (0, 0) rising and returning to the x-axis on the right; (b) an increasing curve for x ≥ 0 starting from a positive y-intercept; (c) a curve from the origin dipping below the axis then rising.

看解答

偶函数：把右半部分沿 y 轴翻折到左边（虚线是补出的部分）。

(a) even

(b) even

(c) even

例 19（L5 Ex 9） Complete each of the same three graphs so that f(x) is odd.

看解答

奇函数：把右半部分绕原点旋转 180°（先沿 y 轴翻折，再沿 x 轴翻折）。(a)、(c) 可以完成。(b) 的曲线在 y 轴上的截距是正数，而奇函数必须满足 f(0) = 0，所以 (b) 不能补成奇函数（除非去掉 x = 0 这一点，左边补 −f(−x) 后在 x = 0 处断开）。

(a) odd

(c) odd

易错
① f(−x) 代入时只改了部分 x。
② 以为「有对称就是奇或偶」：只有关于 y 轴或原点对称才算。
常见疑惑
问：f(x) = 0 是奇函数还是偶函数？ 两者都是，它是唯一既奇又偶的函数。

七个基本图像与图像变换（L6）

L06_Basic_Graphs_and_Transformations.pdf · PDF p1–5

概念
要熟记的七个基本图像：y = x，y = x²，y = x³，y = √x，y = |x|，y = ∛x，y = 1/x。
变换（c > 0）：①y = f(x) + c 向上平移 c，y = f(x) − c 向下；②y = f(x − c) 向右平移 c，y = f(x + c) 向左；③y = −f(x) 关于 x 轴翻折；④y = f(−x) 关于 y 轴翻折；⑤y = |f(x)|：x 轴下方的部分翻到上方；⑥y = cf(x)：每个 y 值乘 c，c > 1 拉伸（变陡），0 < c < 1 压缩（变平）。

例 20（L6 Basic Graphs） Sketch the seven basic graphs that should be memorised.

看解答

见下面七幅图：直线、抛物线、立方曲线、根号曲线（只有 x ≥ 0）、V 形绝对值、立方根曲线（定义在全体实数，奇函数）、双曲线（两支，x ≠ 0）。

1. y = x

2. y = x²

3. y = x³

4. y = √x

5. y = |x|

6. y = ∛x

7. y = 1/x

例 21（L6 Sketches） Using the given y = f(x) (passing through (−2, 0), (−1, 1), (1, −1), (2, 0)) sketch y = f(x) + 1, y = f(x − 1), y = −f(x), y = |f(x)|; and sketch y = x³ − 1, y = |x + 3|, y = 4 − x², y = 2−x from y = 2x, y = √(−x), y = |x² − 4|; compare y = x², 2x², ½x² at P(2, ·); sketch y = 3|x| and y = ½x³.

看解答

f(x) + 1：整体上移 1，点 (−1, 1) → (−1, 2)。f(x − 1)：右移 1，零点 −2、2 变成 −1、3。−f(x)：关于 x 轴翻折，(−1, 1) → (−1, −1)。|f(x)|：x 轴下方部分翻上去，(1, −1) → (1, 1)。
y = x³ − 1：x³ 下移 1；y = |x + 3|：V 形左移 3，顶点 (−3, 0)；y = 4 − x²：x² 翻折后上移 4，与 x 轴交于 ±2；y = 2−x：2ˣ 关于 y 轴翻折，仍过 (0, 1)；y = √(−x)：√x 关于 y 轴翻折，只在 x ≤ 0；y = |x² − 4|：把 −2 < x < 2 之间 x 轴下方的部分翻上去，顶点 (0, 4)。
P(2, ·)：y = x² 时 P(2, 4)，y = 2x² 时 P(2, 8)（拉伸），y = ½x² 时 P(2, 2)（压缩）。y = 3|x|：V 形变陡；y = ½x³：立方曲线变平。
注：讲义的 f(x) 只画了曲线并标出 (−2, 0)、(−1, 1)、(1, −1)、(2, 0)；这里用 f(x) = (x³ − 4x)/3 作示意（真正的转折点在 x ≈ ±1.15），只为显示变换的方向。

y = f(x) + 1 (shift up 1)

y = f(x − 1) (shift right 1)

y = −f(x) (reflect in x-axis)

y = |f(x)|

y = x³ − 1

y = |x + 3|

y = 4 − x²

y = 2⁻ˣ is y = 2ˣ reflected in the y-axis

y = √(−x)

y = |x² − 4|

Stretch and compress: P(2, 4), P(2, 8), P(2, 2)

y = 3|x| (steeper)

y = ½x³ (flatter)

例 22（L6 Ex 1） Find the equation of the function formed by: (a) shifting y = x² three units to the right; (b) reflecting y = |x| in the x-axis and shifting it 3 units up; (c) reflecting y = f(x) over the y-axis and then doubling all y values.

看解答

(a) 向右是 x − 3：y = (x − 3)²。
(b) 翻折得 y = −|x|，再上移 3：y = 3 − |x|。
(c) 关于 y 轴翻折得 f(−x)，再把 y 值翻倍：y = 2f(−x)。

例 23（L6 Ex 2） The point (2, 3) is on y = f(x). Find a point on: (a) y = −f(x) (b) y = f(x − 2) (c) y = 3 − f(x + 1).

看解答

(a) y 值变号：(2, −3)。
(b) 向右平移 2：(4, 3)。验证：x = 4 时 f(4 − 2) = f(2) = 3。
(c) f(x + 1) 左移 1 得 (1, 3)；−f 翻折得 (1, −3)；再加 3 得 (1, 0)。验证：x = 1 时 3 − f(2) = 0。
Answer: (a) (2, −3) (b) (4, 3) (c) (1, 0)

易错
① f(x − c) 以为向左移：减号向右。
② y = 3 − f(x + 1) 的步骤顺序乱：先水平平移，再翻折，最后上下平移。
③ y = √(−x) 画在 x ≥ 0。
常见疑惑
问：为什么 f(x − 2) 是向右移？ 要得到原来 x = 2 处的值，现在需要 x − 2 = 2，即 x = 4，所以图像整体右移 2。
