指数函数求导（L31）

L31_Exponential_Functions_Differentiation.pdf · PDF p1–5

概念
在 y = aˣ 上各点画切线，得到的导函数形状和原函数一样，只是乘了一个倍数，这个倍数是 ln a（证明超出课程范围）：ddx aˣ = aˣ ln a。
特例 a = e：ln e = 1，所以 ddx eˣ = eˣ，导数就是它自己。
配合链式法则：ddx ef(x) = f′(x)ef(x)（指数原样保留，乘以指数的导数）。
ddx aˣ = aˣ ln a　　ddx eˣ = eˣ　　ddx ef(x) = f′(x)ef(x)

例 1（L31 Intro） Consider y = aˣ. By considering tangents at several points, sketch the derivative function.

看解答

曲线越往右越陡，斜率始终为正且和 y 值成正比，所以导函数的形状与 aˣ 相同，只差一个倍数 ln a。图中 a = 2：y′ = 2ˣ ln 2，红色虚线在原曲线下方（ln 2 < 1）。

The derivative of aˣ has the same shape, scaled by ln a (here ln 2 ≈ 0.69)

例 2（L31 Ex 1） Differentiate: (a) y = 3ˣ (b) y = 10ˣ (c) y = eˣ

看解答

直接套公式 ddx aˣ = aˣ ln a。
(a) 3ˣ ln 3。(b) 10ˣ ln 10。(c) eˣ ln e = eˣ（ln e = 1，导数等于自己）。
Answer: (a) 3ˣ ln 3 (b) 10ˣ ln 10 (c) eˣ

例 3（L31 Ex 2） Differentiate: (a) y = e⁹ˣ (b) f(x) = e⁻ˣ (c) y = eˣ + 5x² (d) y = e3x² − x + 1 (e) y = (e⁵ˣ − 2x)³ (f) y = 1e²ˣ (g) y = x⁴e²ˣ (h) f(x) = e²ˣ1 − eˣ

看解答

(a) 9e⁹ˣ。(b) −e⁻ˣ。(c) eˣ + 10x。
(d) 指数的导数 6x − 1：(6x − 1)e3x² − x + 1。
(e) 链式法则：3(e⁵ˣ − 2x)²(5e⁵ˣ − 2)。
(f) 先写成 e⁻²ˣ：−2e⁻²ˣ = −2e²ˣ。
(g) 乘积法则：4x³e²ˣ + 2x⁴e²ˣ = 2x³e²ˣ(2 + x)。
(h) 商法则：2e²ˣ(1 − eˣ) − e²ˣ(−eˣ)(1 − eˣ)² = 2e²ˣ − e³ˣ(1 − eˣ)² = e²ˣ(2 − eˣ)(1 − eˣ)²。
Answer: 见解答

例 4（L31 Ex 3） (a) Sketch y = eˣ. (b) Show that the tangent to y = eˣ at (1, e) passes through the origin.

看解答

(a) 过 (0, 1)，x 轴是渐近线，处处递增。
(b) y′ = eˣ，x = 1 时斜率 e。切线 y − e = e(x − 1)，即 y = ex。x = 0 时 y = 0，所以切线过原点。

Tangent at (1, e) is y = ex, which passes through the origin

例 5（L31 Ex 4） The concentration of a drug (mg/mL) is C(t) = 5e−0.3t, t hours after injection. Find the rate at which the concentration is changing 4 hours after the injection.

看解答

C′(t) = 5 × (−0.3)e−0.3t = −1.5e−0.3t。t = 4：C′(4) = −1.5e−1.2 ≈ −0.452。浓度每小时下降约 0.452 mg/mL。
Answer: ≈ −0.452 mg/mL per hour

Concentration falling at about 0.45 mg/mL per hour when t = 4

例 6（L31 Ex 5） Find the stationary point on y = ex² + x² and determine its nature.

看解答

y′ = 2xex² + 2x = 2x(ex² + 1) = 0。ex² + 1 > 0，所以 x = 0，y = 1。
y″ = 2(ex² + 1) + 4x²ex²，x = 0 时 y″ = 4 > 0：(0, 1) 是极小值点。
Answer: MIN (0, 1)

Minimum turning point (0, 1)

易错
① ddx 3ˣ 写成 x·3ˣ⁻¹：幂法则只用于 xⁿ（底数是变量），aˣ 是指数是变量。
② ef(x) 求导时把指数也求导了：指数原样保留，只是前面乘 f′(x)。
③ 1/e²ˣ 用商法则硬算：先写成 e⁻²ˣ 更快。
常见疑惑
问：除了 eˣ，还有什么函数的导数等于自己？ y = 0（以及 ceˣ，c 为常数）。讲义脚注里的问题，答案是 y = 0。

指数函数积分（L32）

L32_Exponential_Functions_Integration.pdf · PDF p1–4

概念
把求导公式反过来：
∫aˣ dx = 1ln aaˣ + c；∫eˣ dx = eˣ + c；∫f′(x)ef(x) dx = ef(x) + c。
常用：∫ekx + b dx = 1kekx + b + c（除以指数里 x 的系数）。
应用：已知 f″ 和两个条件，积分两次求 f；已知变化率和初值，求某时刻的量；两曲线之间的面积。
∫ekx dx = 1kekx + c　　∫aˣ dx = aˣln a + c　　∫f′(x)ef(x) dx = ef(x) + c

例 7（L32 Ex 1） Find: (a) ∫e²ˣ dx (b) ∫ex/2 dx (c) ∫1e³ˣ dx (d) ∫e3x − 8 dx (e) ∫7ˣ dx

看解答

除以指数里 x 的系数。
(a) ½e²ˣ + c。(b) 系数 ½，除以 ½ 即乘 2：2ex/2 + c。(c) ∫e⁻³ˣ dx = −⅓e⁻³ˣ + c。(d) ⅓e3x − 8 + c。(e) 7ˣln 7 + c。
Answer: (a) ½e²ˣ + c (b) 2e^(x/2) + c (c) −⅓e⁻³ˣ + c (d) ⅓e^(3x−8) + c (e) 7ˣ/ln 7 + c

例 8（L32 Ex 2） Evaluate: (a) ∫₋₁² 2e²ˣ dx (b) ∫₀⁵ (eˣ − x²) dx

看解答

先求原函数，再代上限减下限。
(a) [e²ˣ]₋₁² = e⁴ − e⁻² ≈ 54.598 − 0.135 = 54.463。
(b) [eˣ − x³3]₀⁵ = (e⁵ − 1253) − (1 − 0) ≈ 148.413 − 41.667 − 1 = 105.746。
Answer: (a) e⁴ − e⁻² ≈ 54.46 (b) e⁵ − 128/3 ≈ 105.75

例 9（L32 Ex 3） Find: (a) ∫3x²ex³ dx (b) ∫₃⁴ (x + 1)ex² + 2x − 3 dx

看解答

(a) 3x² 正是 x³ 的导数：ex³ + c。
(b) 指数 x² + 2x − 3 的导数是 2(x + 1)，前面只有 (x + 1)，补 ½：原函数 ½ex² + 2x − 3。x = 4 时指数 21，x = 3 时指数 12：
½(e²¹ − e¹²) ≈ 6.594 × 10⁸（数值很大，保留精确形式 ½(e²¹ − e¹²) 最好）。
Answer: (a) e^(x³) + c (b) ½(e²¹ − e¹²)

例 10（L32 Ex 4） A curve has gradient function dydx = e3x − 2 and passes through (1, e). Find its equation.

看解答

y = ⅓e3x − 2 + c。代 (1, e)：⅓e¹ + c = e，c = ⅔e。y = ⅓e3x − 2 + ⅔e。
Answer: y = ⅓e^(3x−2) + ⅔e

例 11（L32 Ex 5） Given f″(x) = 2eˣ − 3e⁻ˣ, f′(0) = 5 and f(0) = 6, find f(ln 2).

看解答

积分一次：f′(x) = 2eˣ + 3e⁻ˣ + c₁；f′(0) = 2 + 3 + c₁ = 5，c₁ = 0。
再积分：f(x) = 2eˣ − 3e⁻ˣ + c₂；f(0) = 2 − 3 + c₂ = 6，c₂ = 7。
f(ln 2) = 2 × 2 − 3 × ½ + 7 = 9.5。
Answer: f(ln 2) = 19/2

例 12（L32 Ex 6） Find the area enclosed by y = eˣ and y = e⁻ˣ between x = 1 and x = 2.

看解答

在 1 ≤ x ≤ 2 上 eˣ > e⁻ˣ：面积 = ∫₁² (eˣ − e⁻ˣ) dx = [eˣ + e⁻ˣ]₁² = (e² + e⁻²) − (e + e⁻¹) ≈ 7.524 − 3.086 = 4.438 平方单位。
Answer: e² + e⁻² − e − e⁻¹ ≈ 4.44

Area between the curves from x = 1 to 2 ≈ 4.44

例 13（L32 Ex 7） The area of a wound t days after it is incurred decreases at the rate A′(t) = −0.9e−0.1t. The original area is 9 cm². Find the area after 5 days.

看解答

先对变化率积分得到面积函数，再用初始面积求常数。
A(t) = ∫−0.9e−0.1t dt = −0.9−0.1e−0.1t + c = 9e−0.1t + c。A(0) = 9 + c = 9，c = 0。
A(5) = 9e−0.5 ≈ 5.46 cm²。
Answer: ≈ 5.46 cm²

Wound area after 5 days ≈ 5.46 cm²

易错
① ∫e²ˣ dx 写成 2e²ˣ：积分是除以系数，不是乘。
② 二次积分时两个常数用同一个 c。
③ ∫aˣ dx 写成 aˣ⁺¹/(x + 1)：底数是常数时不能用幂法则。
常见疑惑
问：例 9(b) 的结果为什么这么大？ e²¹ 约为 13 亿，题目数值本来就大；考试写精确形式 ½(e²¹ − e¹²) 即可。

对数函数求导（L33）

L33_Log_Functions_Differentiation.pdf · PDF p1–3

概念
y = ln x ⇔ x = eʸ。dxdy = eʸ = x，所以 dydx = 1x：ddx ln x = 1x。
链式法则：ddx ln f(x) = f′(x)f(x)（里层的导数除以里层）。
先用对数性质化简再求导往往省很多事：ln AB = ln A + ln B，ln AB = ln A − ln B，ln Aᴮ = B ln A，ln eᴬ = A，eln A = A。例如 lnx + 1x − 1 = ln(x + 1) − ln(x − 1)，导数 1x + 1 − 1x − 1，不用商法则套链式法则。
商业应用：边际成本 = C′(x)；平均成本 A(x) = C(x)x。
ddx ln x = 1x　　ddx ln f(x) = f′(x)f(x)

例 14（L33 Derivation） Find the derivative of y = ln x, and generalise using the chain rule.

看解答

y = ln x 即 x = eʸ，dxdy = eʸ = x，所以 dydx = 1dx/dy = 1x。链式法则：ddx ln f(x) = 1f(x) × f′(x)。

例 15（L33 Ex 1） Differentiate: (a) y = ln(2x + 1) (b) f(x) = ln(3x² − 5) (c) f(x) = (2x + 3)ln(3x − 2) (d) y = ln xx

看解答

(a) 22x + 1。
(b) 6x3x² − 5。
(c) 乘积法则：2ln(3x − 2) + (2x + 3) × 33x − 2 = 2ln(3x − 2) + 3(2x + 3)3x − 2。
(d) 商法则：(1/x) × x − ln xx² = 1 − ln xx²。
Answer: (a) 2/(2x + 1) (b) 6x/(3x² − 5) (c) 2ln(3x − 2) + 3(2x + 3)/(3x − 2) (d) (1 − ln x)/x²

例 16（L33 Ex 2） Differentiate: (a) y = ln x² (b) f(x) = ln√(x + 4) (c) f(x) = ln(2x − 3x² + 1) (d) y = e5 ln x

看解答

先用对数性质化简。
(a) y = 2ln x，y′ = 2x。
(b) f(x) = ½ln(x + 4)，f′ = 12(x + 4)。
(c) f(x) = ln(2x − 3) − ln(x² + 1)，f′ = 22x − 3 − 2xx² + 1。
(d) e5 ln x = eln x⁵ = x⁵，y′ = 5x⁴。
Answer: (a) 2/x (b) 1/(2(x + 4)) (c) 2/(2x − 3) − 2x/(x² + 1) (d) 5x⁴

例 17（L33 Ex 3） Show that the tangent to y = ln x at the point where x = e passes through the origin.

看解答

x = e 时 y = ln e = 1；y′ = 1x，斜率 1e。切线 y − 1 = 1e(x − e)，即 y = xe。x = 0 时 y = 0，过原点。

Tangent at (e, 1) is y = x/e, through the origin

例 18（L33 Ex 4） The cost of producing x items is C(x) = 1000 + 200x − 200 ln x, x ≥ 1. (a) The marginal cost is C′(x); find it at x = 20. (b) Find the average cost A(x). (c) Find the minimum average cost.

看解答

(a) C′(x) = 200 − 200x；C′(20) = 200 − 10 = $190（生产第 20 件左右时，每多生产一件约多花 $190）。
(b) A(x) = C(x)x = 1000x + 200 − 200 ln xx。
(c) A′(x) = −1000x² − 200 × 1 − ln xx² = 200 ln x − 1200x² = 0，ln x = 6，x = e⁶ ≈ 403.4。x < e⁶ 时 A′ < 0，x > e⁶ 时 A′ > 0，是最小值。
A(e⁶) = 1000 − 1200e⁶ + 200 = 200 − 200e⁶ ≈ $199.50。
Answer: (a) $190 (b) A = 1000/x + 200 − 200 ln x / x (c) ≈ $199.50 at x = e⁶ ≈ 403

Average cost is least at x = e⁶ ≈ 403 items (≈ $199.50)

易错
① ln(2x + 1) 求导写成 1/(2x + 1)：要乘里层导数 2。
② ln x² 写成 (ln x)²：ln x² = 2ln x，(ln x)² 是另一回事。
③ 平均成本的最小值答成 x：题目问「minimum average cost」，答 A 的值。
常见疑惑
问：为什么 ln(A/B) 先拆开更好？ 拆成 ln A − ln B 后两项都只需要 f′/f，避免商法则套在链式法则里，算错的机会少很多。
