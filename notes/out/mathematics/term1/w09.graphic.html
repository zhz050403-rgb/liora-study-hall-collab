曲线作图与绝对最值（L25）

L25_Curve_Sketching.pdf · PDF p1–5

概念
画曲线的完整步骤：①截距；②驻点及类型；③拐点；④端点或渐近线；⑤把信息标在图上连成光滑曲线。下表汇总上两周的结论。
绝对最大值：给定定义域上 y 的最大值，可能出现在极大值点（局部最大），也可能在定义域的端点，也可能不存在。绝对最小值同理。所以求绝对最值要比较：所有驻点的 y 和两个端点的 y。

例 1（L25 Summary） Complete the summary of calculus results for graphs: stationary point, point of inflection, increasing, concave up, decreasing, concave down, nature of a stationary point using y′ and using y″.

看解答

见本节表格：驻点 y′ = 0；拐点 y″ = 0 且变号；递增 y′ > 0、递减 y′ < 0；下凸 y″ > 0、上凸 y″ < 0；驻点类型用 y′ 的符号表或 y″ 的符号判断。

例 2（L25 Ex 1） Consider y = 6x² − x³. (a) Find the y-intercept. (b) Find any stationary points and determine their nature. (c) Find any points of inflection. (d) Sketch the curve showing this information. (e) State the values of x for which the function is increasing. (f) State the values of k for which f(x) = k has one solution.

看解答

(a) x = 0：y = 0，y 截距 0（另外 x²(6 − x) = 0，x 截距 0 和 6）。
(b) y′ = 12x − 3x² = 3x(4 − x) = 0，x = 0 或 4；y(0) = 0，y(4) = 96 − 64 = 32。y″ = 12 − 6x：x = 0 时 12 > 0，(0, 0) 是极小值点；x = 4 时 −12 < 0，(4, 32) 是极大值点。
(c) y″ = 0，x = 2；x = 1 时 y″ = 6 > 0，x = 3 时 y″ = −6 < 0，变号。y(2) = 24 − 8 = 16，拐点 (2, 16)。
(d) 见图。
(e) 两驻点之间上升：0 < x < 4。
(f) 水平线 y = k 与曲线只交一次：k 低于极小值或高于极大值，即 k < 0 或 k > 32。（k = 0 或 32 时有两个交点，0 < k < 32 时有三个。）
Answer: (a) 0 (b) MIN (0, 0), MAX (4, 32) (c) (2, 16) (e) 0 < x < 4 (f) k < 0 or k > 32

MIN (0, 0), MAX (4, 32), inflection (2, 16); x-intercepts 0 and 6

例 3（L25 Ex 2） Consider y = 5x⁴ − x⁵. (a) Find the stationary points and determine their nature. (b) Sketch the function for −1 ≤ x ≤ 6. (c) State the absolute maximum and minimum values for this domain.

看解答

(a) y′ = 20x³ − 5x⁴ = 5x³(4 − x) = 0，x = 0 或 4；y(0) = 0，y(4) = 5 × 256 − 1024 = 256。
这里 x = 0 处 y″ = 60x² − 20x³ = 0，二阶导数判断不了，改用符号表：x = −1 时 y′ = −25 < 0，x = 1 时 y′ = 15 > 0，x = 5 时 y′ = −625 < 0。(0, 0)：− 0 +，极小值点；(4, 256)：+ 0 −，极大值点。
(b) 端点：y(−1) = 5 + 1 = 6；y(6) = 6480 − 7776 = −1296。
(c) 比较 y(−1) = 6、y(0) = 0、y(4) = 256、y(6) = −1296：绝对最大值 256（x = 4），绝对最小值 −1296（x = 6，在端点，不在驻点）。
Answer: MIN (0, 0), MAX (4, 256); absolute max 256, absolute min −1296

易错
① 绝对最值只看驻点，不看端点（例 3 的最小值在端点 x = 6）。
② y″ = 0 时直接说是拐点或没有极值：要回到一阶导数符号表。
③ (f) 把 k = 0 或 k = 32 也算成「一个解」：那时水平线与曲线相切，有两个交点。
常见疑惑
问：「局部最大」和「绝对最大」有什么区别？ 局部最大只比附近的点高；绝对最大是整个定义域里最高的。端点可能比所有驻点更高或更低。

最优化问题（L26）

L26_Max_Min_Problems.pdf · PDF p1–4

概念
步骤：①确定要最大化或最小化的量；②把它写成只含一个变量的函数（可能题目给出，也可能要自己列）；③写出定义域的限制；④求驻点并判断类型；⑤检查最优点是否在定义域内，不在的话最优值在端点。
常用关系：收入 = 价格 × 数量；利润 = 收入 − 成本；平均成本 = 总成本 ÷ 数量；总成本 = 每小时成本 × 时间。

例 4（L26 Ex 1） A company sells x transformers a week. The weekly cost is $(5000 + 2x) and the selling price is $(10 − 0.001x) each, 0 < x ≤ 10 000. (a) Find the weekly profit P(x). (b) Determine the selling price which maximises the weekly profit.

看解答

(a) 收入 = x(10 − 0.001x) = 10x − 0.001x²。P(x) = 10x − 0.001x² − (5000 + 2x) = −0.001x² + 8x − 5000。
(b) P′(x) = 8 − 0.002x = 0，x = 4000（在定义域内）；P″ = −0.002 < 0，是最大值。售价 = 10 − 0.001 × 4000 = $6，此时周利润 P(4000) = $11 000。
Answer: (a) P = −0.001x² + 8x − 5000 (b) $6

Profit is greatest at x = 4000 (price $6)

例 5（L26 Ex 2） An office printer costs $3200. Maintenance is $300 in the first year and rises by $100 each year, so the total cost for n years is C(n) = 3200 + 250n + 50n². (a) Find the average yearly cost A(n). (c) Find the length of contract for which the average cost is a minimum.

看解答

(a) A(n) = C(n)n = 3200n + 250 + 50n。
(c) A′(n) = −3200n² + 50 = 0，n² = 64，n = 8（n > 0）。A″(n) = 6400n³ > 0，是最小值。合同 8 年，平均每年 $1050。
（总成本公式的来历：维护费是首项 300、公差 100 的等差数列，n 年合计 300n + 100 × n(n − 1)/2 = 250n + 50n²。）
注：讲义的小题编号是 (a)、(c)，没有 (b)。
Answer: (a) A = 3200/n + 250 + 50n (c) 8 years

Average yearly cost is least at n = 8 years ($1050)

例 6（L26 Ex 3） With no toll 6000 vehicles use a tunnel each day; each $1 of toll reduces this by 475. (a) If the toll is d dollars, find the daily income I(d). (b) Find the toll which maximises the daily income.

看解答

(a) 车辆数 6000 − 475d，收入 I(d) = d(6000 − 475d) = 6000d − 475d²。
(b) I′(d) = 6000 − 950d = 0，d = 6000950 ≈ 6.32；I″ = −950 < 0，是最大值。收费约 $6.32，每天收入约 $18 947。（若只能收整数美元：d = 6 时 $18 900，d = 7 时 $18 725，取 $6。）
Answer: (a) I = 6000d − 475d² (b) d ≈ $6.32

Income is greatest at d ≈ 6.32

例 7（L26 Ex 4） A ship travels 1000 km at a constant v km/h; the cost per hour is 160 + 1100v³ dollars. (a) Show that the journey costs 160 000v + 10v² dollars. (b) Find the most economical speed. (c) If the maximum speed is 16 km/h, find the minimum cost.

看解答

(a) 时间 = 1000v 小时，总成本 = (160 + v³100) × 1000v = 160 000v + 10v²。
(b) C′(v) = −160 000v² + 20v = 0，v³ = 8000，v = 20 km/h；C″ = 320 000v³ + 20 > 0，是最小值。C(20) = 8000 + 4000 = $12 000。
(c) 最优速度 20 不在 0 < v ≤ 16 内。v < 20 时 C′ < 0，成本一直在下降，所以最小值在端点 v = 16：C(16) = 10 000 + 2560 = $12 560。
Answer: (b) 20 km/h (c) $12 560

Unrestricted minimum at v = 20; with v ≤ 16 the minimum is at v = 16

易错
① 利润函数里漏减固定成本。
② 求出的驻点不在定义域内仍当作答案（例 7(c)）。
③ 问「售价」却答了数量 x（例 4）。
常见疑惑
问：怎么确认驻点是最大还是最小？ 用二阶导数判别（最常用），或在驻点两侧代入一阶导数看符号；只有一个驻点时，判断出类型就是绝对最值。

不定积分（L27）

L27_Indefinite_Integrals.pdf · PDF p1–4

概念
已知导数，求原来的函数：ddx(x³ + c) = 3x²，所以 x³ + c 是 3x² 的原函数（primitive function）。常数 c 求导后消失，所以要加上任意常数 c。
原函数也叫不定积分：∫f′(x) dx = f(x) + c。求不定积分叫积分，是求导的逆运算。
幂法则：∫xⁿ dx = xⁿ⁺¹n + 1 + c（n ≠ −1）：指数加 1，再除以新指数。特例：∫m dx = mx + c，∫0 dx = c。
链式法则的逆：∫f′(x)[f(x)]ⁿ dx = [f(x)]ⁿ⁺¹n + 1 + c。被积式里要有里层的导数 f′(x)（差常数倍可以补）。
给出曲线上一点，就能求出 c。
∫xⁿ dx = xⁿ⁺¹n + 1 + c（n ≠ −1）
∫f′(x)[f(x)]ⁿ dx = [f(x)]ⁿ⁺¹n + 1 + c

例 8（L27 Intro） Given f′(x) = 3x², what is f(x)? Find d/dx of x³, x³ + 7, x³ + 100 and x³ − 25.

看解答

四个导数都是 3x²：常数求导后都变成 0。所以 f(x) = x³ + c，c 是任意常数。
Answer: f(x) = x³ + c

例 9（L27 Ex 1） Find the primitive function of: (a) 4x³ (b) 5x⁴ (c) 12x¹¹

看解答

nxⁿ⁻¹ 的原函数是 xⁿ + c：(a) x⁴ + c (b) x⁵ + c (c) x¹² + c。
Answer: (a) x⁴ + c (b) x⁵ + c (c) x¹² + c

例 10（L27 Ex 2） Find: (a) ∫x² dx (b) ∫(x⁴ − 5x²) dx (c) ∫1x⁴ dx (d) ∫√x dx

看解答

指数加 1，除以新指数，别忘了 + c。
(a) x³3 + c。
(b) x⁵5 − 5x³3 + c。
(c) ∫x⁻⁴ dx = x⁻³−3 + c = −13x³ + c。
(d) ∫x½ dx = x3/23/2 + c = ⅔x3/2 + c。
Answer: (a) x³/3 + c (b) x⁵/5 − 5x³/3 + c (c) −1/(3x³) + c (d) ⅔x^(3/2) + c

例 11（L27 Ex 3） Find: (a) ∫6 dx (b) ∫0 dx

看解答

(a) 6x 的导数是 6：6x + c。(b) 常数的导数是 0：结果是 c。
Answer: (a) 6x + c (b) c

例 12（L27 Ex 4） Find: (a) ∫3x²(x³ + 7)⁵ dx (b) ∫(x − 1)√(x² − 2x + 7) dx

看解答

(a) 里层 f(x) = x³ + 7，f′(x) = 3x² 正好在前面：(x³ + 7)⁶6 + c。
(b) 里层 f(x) = x² − 2x + 7，f′(x) = 2x − 2 = 2(x − 1)，前面只有 (x − 1)，差一个 2：
∫(x − 1)(x² − 2x + 7)½ dx = ½∫(2x − 2)(x² − 2x + 7)½ dx = ½ × (x² − 2x + 7)3/23/2 + c = ⅓(x² − 2x + 7)3/2 + c。
Answer: (a) (x³ + 7)⁶/6 + c (b) ⅓(x² − 2x + 7)^(3/2) + c

例 13（L27 Ex 5） Find the equation of a curve with gradient function dydx = 2(3x − 7)² which passes through (2, 5).

看解答

y = ∫2(3x − 7)⁻² dx。里层导数是 3，补上：y = 23 × (3x − 7)⁻¹−1 + c = −23(3x − 7) + c。
代 (2, 5)：3x − 7 = −1，5 = −2/(−3) + c = ⅔ + c，c = 133。
y = 133 − 23(3x − 7)。
Answer: y = 13/3 − 2/(3(3x − 7))

易错
① 忘了 + c。
② ∫1/x⁴ dx 写成 1/x⁵ 或 ln：先化成 x⁻⁴ 再用幂法则。
③ 链式法则的逆运算忘了除以里层导数的常数（例 12(b)、例 13）。
常见疑惑
问：为什么 n = −1 不行？ ∫x⁻¹ dx 用公式会除以 0。它的答案是 ln|x| + c，讲义后面（第 12 周）讲。
