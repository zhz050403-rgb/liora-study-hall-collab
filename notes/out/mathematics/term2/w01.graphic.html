数列、级数与 Σ 记号（L1）

L01_Seq_and_Series.pdf · PDF p1–5

概念
数列：按某种规律排列的一列数，每个数叫项。第 n 项（通项）记作 Tₙ，n 只能取正整数 1, 2, 3, …；数列常用 Tₙ 关于 n 的式子表示。
级数：数列各项的和。前 n 项和记作 Sₙ = T₁ + T₂ + … + Tₙ（progression 一词既可指数列也可指级数）。
重要结论：S₁ = T₁；n ≥ 2 时 Tₙ = Sₙ − Sₙ₋₁。
Σ 记号：Sₙ = Σk=1n Tk。下标不必从 1 开始；Σ 从 k = a 到 k = b 共有 b − a + 1 项。
Tₙ = Sₙ − Sₙ₋₁（n ≥ 2），S₁ = T₁
Σ 从 k = a 到 b 共 b − a + 1 项

例 1（L1 Ex 1） Generate the next three terms: (a) 2, 4, 6, 8, 10, … (b) 2, 4, 8, 16, 32, … (c) 3, 1½, 0, −1½, … (d) 1, 4, 9, 16, 25, … (e) ½, ¾, ⅚, … (f) 1, 1, 2, 3, 5, 8, …

看解答

先找规律。
(a) 每次加 2：12, 14, 16。
(b) 每次乘 2：64, 128, 256。
(c) 每次减 1½：−3, −4½, −6。
(d) 平方数：36, 49, 64。
(e) 分子是奇数、分母比分子大 1：78, 910, 1112。
(f) 每项是前两项之和（斐波那契数列）：13, 21, 34。

例 2（L1 Ex 2） Write down T₁ and T₂₀: (a) Tₙ = 3n + 7 (b) Tₙ = (−1)ⁿ × 3n

看解答

把 n 代入。
(a) T₁ = 10，T₂₀ = 67。
(b) T₁ = (−1) × 3 = −3，T₂₀ = (+1) × 60 = 60（n 为偶数时为正）。
Answer: (a) 10, 67 (b) −3, 60

例 3（L1 Ex 3） Write Tₙ as a function of n: (a) 1, 4, 9, 16, … (b) ½, ⅓, ¼, …

看解答

(a) 第 n 项是 n 的平方：Tₙ = n²。
(b) 分母比项数大 1：Tₙ = 1n + 1。
Answer: (a) n² (b) 1/(n + 1)

例 4（L1 Ex 4） Tₙ = 5n − 23. (a) Which term is 477? (b) Is 333 a term?

看解答

(a) 5n − 23 = 477，5n = 500，n = 100：第 100 项。
(b) 5n − 23 = 333，5n = 356，n = 71.2，不是正整数，所以 333 不是这个数列的项。
Answer: (a) T₁₀₀ (b) No

例 5（L1 Ex 5） For the series 1 + 3 + 5 + …: (a) Find T₄, T₅ and T₆. (b) Find S₆ − S₅.

看解答

(a) 奇数：T₄ = 7，T₅ = 9，T₆ = 11。
(b) S₆ − S₅ 就是第 6 项：11（S₆ = 36，S₅ = 25）。
Answer: (a) 7, 9, 11 (b) 11

例 6（L1 Ex 6） Sₙ = 2n + 3n². (a) Find S₄ and S₅. (b) Hence calculate T₅. (c) Find a formula for Tₙ and verify it with (b).

看解答

(a) S₄ = 8 + 48 = 56；S₅ = 10 + 75 = 85。
(b) T₅ = S₅ − S₄ = 29。
(c) Tₙ = Sₙ − Sₙ₋₁ = [2n + 3n²] − [2(n − 1) + 3(n − 1)²] = 2 + 3(2n − 1) = 6n − 1。验证：T₅ = 30 − 1 = 29 ✓。（n = 1 时 6 − 1 = 5 = S₁，也成立。）
Answer: (a) 56, 85 (b) 29 (c) Tₙ = 6n − 1

例 7（L1 Ex 7） Expand and evaluate Σk=15 (5k − 2).

看解答

k = 1, 2, 3, 4, 5 依次代入：3 + 8 + 13 + 18 + 23 = 65。
Answer: 65

例 8（L1 Ex 8） Complete: 2³ + 2⁴ + 2⁵ + 2⁶ + 2⁷ = Σk=1? 2? = Σk=3? 2?. How many terms does each series have?

看解答

从 k = 1 开始：Σk=15 2k + 2；从 k = 3 开始：Σk=37 2k。两种写法都是 5 项（7 − 3 + 1 = 5），和为 8 + 16 + 32 + 64 + 128 = 248。
Answer: Σ(k=1..5) 2^(k+2) = Σ(k=3..7) 2^k, 5 terms, sum 248

易错
① 把 Sₙ 当成 Tₙ（例 6）。
② Tₙ = Sₙ − Sₙ₋₁ 展开 (n − 1)² 出错。
③ Σ 的项数写成 b − a（漏了 +1）。
常见疑惑
问：为什么 n 必须是正整数？ n 表示「第几项」，只能是第 1、2、3…项；所以例 4(b) 解出 71.2 说明 333 不在数列中。

等差数列 AP（L2）

L02_Arithmetic_Progressions.pdf · PDF p1–5

概念
相邻两项的差为常数（公差 d，可正可负）的数列叫等差数列（AP）。首项 a：a, a + d, a + 2d, …
通项：Tₙ = a + (n − 1)d。
求和（高斯配对法：首尾相加都相等）：Sₙ = n2[2a + (n − 1)d] = n2(a + l)，l 是最后一项。
判断 AP：检查 T₂ − T₁ = T₃ − T₂ = …；三个数 x、y、z 成 AP 当且仅当 y − x = z − y。
Tₙ = a + (n − 1)d
Sₙ = n2[2a + (n − 1)d] = n2(a + l)

例 9（L2 Ex 1） Test whether these form an AP: (a) −5, −1, −4, … (b) √3, √12, √27, …

看解答

(a) 差：−1 − (−5) = 4，−4 − (−1) = −3，不相等，不是 AP。
(b) √12 = 2√3，√27 = 3√3，数列是 √3, 2√3, 3√3，公差都是 √3，是 AP。

例 10（L2 Ex 2） Find the 20th term of 5, 8, 11, 14, …

看解答

这是等差数列，首项 a = 5，公差 d = 3，代入通项公式：T₂₀ = 5 + 19 × 3 = 62。
Answer: 62

例 11（L2 Ex 3） Which term of the AP 15, 11, 7, … is −33?

看解答

首项 a = 15，公差 d = −4。令通项等于 −33：15 − 4(n − 1) = −33，4(n − 1) = 48，n = 13，是第 13 项。
Answer: T₁₃

例 12（L2 Ex 4） The fifth term of an AP is 31 and the twelfth term is 73. Find a and d.

看解答

a + 4d = 31，a + 11d = 73。相减：7d = 42，d = 6；a = 31 − 24 = 7。
Answer: a = 7, d = 6

例 13（L2 Ex 5） 2x − 1, 5x − 4 and 7x − 2 form an AP. Find x.

看解答

公差相等：(5x − 4) − (2x − 1) = (7x − 2) − (5x − 4)，3x − 3 = 2x + 2，x = 5。三项为 9、21、33，公差 12。
Answer: x = 5

例 14（L2 Gauss） Find 1 + 2 + 3 + … + 100 by pairing terms, and derive the formula for the sum of an AP.

看解答

把和正着写一遍、倒着写一遍再相加：每一对都是 101，共 100 对，所以 2S₁₀₀ = 100 × 101，S₁₀₀ = 5050。
一般地，Sₙ = a + (a + d) + … + l，倒写后相加，每对都是 a + l，共 n 对：2Sₙ = n(a + l)，Sₙ = n2(a + l)；代入 l = a + (n − 1)d 得 Sₙ = n2[2a + (n − 1)d]。
Answer: 5050

例 15（L2 Ex 6） Find the sum of the first 20 terms of 5 + 8 + 11 + 14 + …

看解答

首项 5、公差 3，用求和公式：S₂₀ = 202[2 × 5 + 19 × 3] = 10 × 67 = 670。
Answer: 670

例 16（L2 Ex 7） Find the value of −15 − 8 − 1 + 6 + … + 188.

看解答

a = −15，d = 7，最后一项 l = 188。先求项数：−15 + 7(n − 1) = 188，7(n − 1) = 203，n = 30。
S₃₀ = 302(−15 + 188) = 15 × 173 = 2595。
Answer: 2595

例 17（L2 Ex 8） How many terms of 40 + 35 + 30 + … are needed to give a sum of 150?

看解答

a = 40，d = −5：n2[80 − 5(n − 1)] = 150，n(85 − 5n) = 300，5n² − 85n + 300 = 0，n² − 17n + 60 = 0，(n − 5)(n − 12) = 0。
n = 5 或 12。两个都对：前 5 项 40 + 35 + 30 + 25 + 20 = 150；第 6 到第 12 项是 15, 10, 5, 0, −5, −10, −15，和为 0，所以 S₁₂ 也是 150。
Answer: 5 or 12 terms

例 18（L2 Ex 9） Rows of cabbages: 35 in the first row, 39 in the second, each row 4 more than the previous. (a) How many cabbages in row 12? (b) Which is the first row with more than 200 cabbages? (c) Exactly 945 cabbages are planted. How many rows?

看解答

AP：a = 35，d = 4。
(a) T₁₂ = 35 + 11 × 4 = 79。
(b) 35 + 4(n − 1) > 200，n − 1 > 41.25，n > 42.25：第 43 行（T₄₂ = 199，T₄₃ = 203）。
(c) n2[70 + 4(n − 1)] = 945，n(33 + 2n) = 945，2n² + 33n − 945 = 0，n = −33 + √(1089 + 7560)4 = −33 + 934 = 15（负根舍去）：15 行。
Answer: (a) 79 (b) row 43 (c) 15 rows

Cabbages per row: 35, 39, 43, …, row 12 has 79

易错
① Tₙ = a + nd（应为 n − 1）。
② 求和前没先算出项数（例 16）。
③ 二次方程两个正根只取一个（例 17）。
常见疑惑
问：什么时候用 n/2(a + l)？ 知道最后一项 l 时最方便（例 16）；不知道最后一项时用 n/2[2a + (n − 1)d]。

等比数列 GP（L3）

L03_Geometric_Progressions.pdf · PDF p1–4

概念
相邻两项的比为常数（公比 r，可正可负、可大于或小于 1）的数列叫等比数列（GP）：a, ar, ar², …
通项：Tₙ = arⁿ⁻¹。
求和（乘 r 再相减）：Sₙ = a(rⁿ − 1)r − 1，或 Sₙ = a(1 − rⁿ)1 − r（r < 1 时用后者更方便）。
三个数 x、y、z 成 GP 当且仅当 y/x = z/y，即 y² = xz。
Tₙ = arⁿ⁻¹
Sₙ = a(rⁿ − 1)r − 1 = a(1 − rⁿ)1 − r

例 19（L3 Ex 1） Test whether these form a GP: (a) 2, 4, 8, 16, … (b) ¼, −½, 1, −2, … (c) √3, √12, √27, …

看解答

(a) 比都是 2：是 GP。
(b) (−½) ÷ ¼ = −2，1 ÷ (−½) = −2，−2 ÷ 1 = −2：是 GP，r = −2。
(c) 2√3 ÷ √3 = 2，3√3 ÷ 2√3 = 1.5：不是 GP（它是 AP）。

例 20（L3 Ex 2） Find T₇ of 5, 5/2, 5/4, …

看解答

后一项是前一项的一半，所以首项 a = 5，公比 r = ½：T₇ = 5 × (½)⁶ = 564。
Answer: 5/64

例 21（L3 Ex 3） Which term of 24, 12, 6, … equals 332?

看解答

首项 24、公比 ½，令通项等于 3/32：24 × (½)ⁿ⁻¹ = 3/32，(½)ⁿ⁻¹ = 332 × 24 = 1256 = (½)⁸，n − 1 = 8，n = 9。
Answer: T₉

例 22（L3 Ex 4） (k − 2), (k − 6) and (2k + 3) are consecutive terms of a GP. Find the possible values of k.

看解答

中间项的平方等于两边之积：(k − 6)² = (k − 2)(2k + 3)，k² − 12k + 36 = 2k² − k − 6，k² + 11k − 42 = 0，(k + 14)(k − 3) = 0。
k = 3：1, −3, 9（r = −3）；k = −14：−16, −20, −25（r = 1.25）。两个都成立。
Answer: k = 3 or −14

例 23（L3 Ex 5） T₅ = −8729 and T₈ = 827. Find the common ratio.

看解答

两项相除可以消去首项 a：T₈ ÷ T₅ = ar⁷ ÷ ar⁴ = r³ = 827 ÷ (−8729) = −27，r = −3。
Answer: r = −3

例 24（L3 Ex 6） Find the sum of the first 10 terms of 3 + 6 + 12 + …

看解答

首项 a = 3，公比 r = 2（大于 1，用第一种形式）：S₁₀ = 3(2¹⁰ − 1)2 − 1 = 3 × 1023 = 3069。
Answer: 3069

例 25（L3 Ex 7） For 4 + 2 + 1 + …, find the least number of terms needed for a sum greater than 7.99.

看解答

a = 4，r = ½：Sₙ = 4(1 − 0.5ⁿ)1 − 0.5 = 8(1 − 0.5ⁿ) > 7.99，0.5ⁿ < 0.00125。两边取对数，log 0.5 < 0，除以它要变号：n > log 0.00125log 0.5 ≈ 9.64，所以至少 10 项（S₉ = 7.984，S₁₀ = 7.992）。
Answer: 10 terms

Partial sums of 4 + 2 + 1 + … approach 8; Sₙ > 7.99 first at n = 10

例 26（L3 Ex 8） 20 opal rings: the weights form an AP and the values a GP. The first and third weigh 200 mg and 300 mg and are valued at $300 and $432. Find (a) which opal weighs 900 mg (b) the value of the 8th ring (c) the total value of the display.

看解答

重量（AP）：a = 200，a + 2d = 300，d = 50。价值（GP）：a = 300，ar² = 432，r² = 1.44，r = 1.2（价值为正）。
(a) 200 + 50(n − 1) = 900，n − 1 = 14，第 15 颗。
(b) T₈ = 300 × 1.2⁷ ≈ $1074.95。
(c) S₂₀ = 300(1.2²⁰ − 1)1.2 − 1 ≈ $56 006.40。
Answer: (a) 15th (b) $1074.95 (c) $56 006.40

易错
① Tₙ = arⁿ（指数应为 n − 1）。
② r < 1 时用 a(rⁿ − 1)/(r − 1) 也对，但正负号容易出错，用 a(1 − rⁿ)/(1 − r)。
③ 取对数解不等式时除以负数忘了变号（例 25）。
常见疑惑
问：例 22 为什么用「中间项平方 = 两边之积」？ 成 GP 意味着 (k − 6)/(k − 2) = (2k + 3)/(k − 6)，交叉相乘就得到 (k − 6)² = (k − 2)(2k + 3)。
