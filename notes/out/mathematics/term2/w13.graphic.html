正态分布与查表（L33）

L33_Normal_Distribution_Tables_Areas.pdf · PDF p1–5

概念
身高、考试分数等受很多因素影响的变量常近似服从正态分布，PDF 是对称的「钟形曲线」，均值、中位数、众数相等。X ~ N(μ, σ²)：注意括号里第二个是方差，题目通常给标准差 σ。
正态 PDF 无法直接积分，所以先换成标准正态 z ~ N(0, 1)，再查表。讲义的表给出 P(0 < z < z₀)，即 0 到 z₀ 之间的面积；曲线对称，左右各占 0.5。
其他正态分布用 z = x − μσ 换成标准正态。
反查：已知面积求 z：先把面积换成「0 到 z」的面积，在表中间找最接近的值，读出 z，再用 x = μ + zσ 换回实际值。
X ~ N(μ, σ²)，z = (x − μ)/σ
P(z < −a) = P(z > a) = 0.5 − P(0 < z < a)

例 1（L33 Ex 1） Sketch and find (a) P(0 < z < 1) (b) P(−2 < z < 2) (c) P(z < 1.7) (d) P(z > 0.95).

看解答

每一问先画图，再把阴影拆成「0 到 z」的表面积和 0.5。
(a) 直接查表：0.3413。
(b) 左右对称：2 × 0.4772 = 0.9544。
(c) 左半边 0.5 加上 0 到 1.7：0.5 + 0.4554 = 0.9554。
(d) 右半边 0.5 减去 0 到 0.95：0.5 − 0.3289 = 0.1711。
Answer: (a) 0.3413 (b) 0.9544 (c) 0.9554 (d) 0.1711

(a) P(0 < z < 1)

(b) P(−2 < z < 2)

(c) P(z < 1.7)

(d) P(z > 0.95)

例 2（L33 Ex 2） X is normally distributed with mean 9 and standard deviation 0.3. Find (a) P(9 < X < 9.3) (b) P(8.7 < X < 9.5) (c) P(X ≤ 8).

看解答

先把每个 x 换成 z = x − 90.3。
(a) 9 → 0，9.3 → 1：P(0 < z < 1) = 0.3413。
(b) 8.7 → −1，9.5 → 0.50.3 ≈ 1.67：0.3413 + 0.4525 = 0.7938。
(c) 8 → −10.3 ≈ −3.33：P(z ≤ −3.33) = 0.5 − 0.4996 = 0.0004（几乎不可能）。
Answer: (a) 0.3413 (b) 0.7938 (c) 0.0004

(b) P(−1 < z < 1.67)

例 3（L33 Ex 3） Find the z-scores cutting off the areas shown: (a) area 0.2995 between 0 and z (b) area 0.2981 in the left tail below z.

看解答

(a) 阴影就是表的口径「0 到 z」：在表中间找 0.2995，对应 z = 0.84。
(b) 左尾面积 0.2981 小于 0.5，z 在 0 的左边。0 到 z 的面积 = 0.5 − 0.2981 = 0.2019，表中对应 0.53，所以 z = −0.53。
Answer: (a) 0.84 (b) −0.53

(a) area 0.2995 from 0 to z = 0.84

(b) left tail 0.2981 below z = −0.53

例 4（L33 Ex 4） X ~ N with μ = 20 and σ = 8. (a) Find a such that P(X < a) = 0.8. (b) Find b such that P(X < b) = 0.271.

看解答

(a) 0.8 > 0.5，a 在均值右边，0 到 z 的面积 = 0.3，表中最接近的是 0.2995 → z = 0.84。a = 20 + 0.84 × 8 = 26.72。
(b) 0.271 < 0.5，b 在左边，0 到 z 的面积 = 0.5 − 0.271 = 0.229，表中 0.2291 → z = −0.61。b = 20 − 0.61 × 8 = 15.12。
Answer: (a) 26.72 (b) 15.12

(a) P(z < 0.84) ≈ 0.8

易错
① 把 N(μ, σ²) 里的方差当成标准差代入 z 公式。
② 表给的是 0 到 z 的面积，直接当成 P(z < z₀)，漏加 0.5。
③ 反查时忘了先把面积换成「0 到 z」的口径，或忘了 z 的正负号。
常见疑惑
问：为什么一定要画草图？ 所有题都要把阴影拆成「0.5」和「0 到 z」两类面积。草图让你一眼看出是加、减还是乘 2，也能检查答案是否合理（比如尾部概率必须小于 0.5）。

正态分布的应用（L34）

L34_Normal_Distribution_Applications.pdf · PDF p1–3

概念
求概率：① 用不等式写出所求概率，如 P(a < X < b)；② 把分数换成 z 分数，写成 P(c < z < d)；③ 画标准正态曲线并涂阴影；④ 用表求阴影面积（表给 0 到 z 的面积，用对称性拼出所求）。
反查：① 画图并涂阴影；② 用表找临界 z；③ 用 x = μ + zσ 换回实际分数。
P(a < X < b) = P((a − μ)/σ < z < (b − μ)/σ)
x = μ + zσ

例 5（L34 Ex 1） Adult elephant weights ~ N with μ = 20 t, σ = 2 t. Find the probability that a randomly chosen baby elephant will grow to an adult weight of more than 18 t.

看解答

P(X > 18)：z = 18 − 202 = −1。阴影从 −1 一直到右边：0.3413 + 0.5 = 0.8413。
Answer: 0.8413

P(z > −1)

例 6（L34 Ex 2） Heights of adult Australian males ~ N with μ = 170 cm, σ = 7 cm. Find P(160 < X < 175).

看解答

z₁ = 160 − 1707 ≈ −1.43，z₂ = 175 − 1707 ≈ 0.71。阴影跨过 0，两边分别查表相加：0.4236 + 0.2611 = 0.6847。
Answer: 0.6847

P(−1.43 < z < 0.71)

例 7（L34 Ex 3） Sandstone block weights ~ N with μ = 92 kg, σ = 16 kg. (a) Find P(60 < X < 84). (b) Find the weight exceeded by 95% of the blocks.

看解答

(a) z₁ = 60 − 9216 = −2，z₂ = 84 − 9216 = −0.5。两端都在 0 左边，大面积减小面积：0.4772 − 0.1915 = 0.2857。
(b) 要找 w 使 P(X > w) = 0.95，w 在均值左边，0 到 z 的面积 = 0.45。表中 0.4495（z = 1.64）和 0.4505（z = 1.65）正好夹住 0.45，取 z = −1.645。w = 92 − 1.645 × 16 ≈ 65.7 kg。
Answer: (a) 0.2857 (b) ≈ 65.7 kg

(a) P(−2 < z < −0.5)

(b) 95% lies above z = −1.645

例 8（L34 Ex 4） Yearly service cost ~ N with μ = $150, σ = $25. The contract charges $200. Find the probability that the company makes a loss on one contract.

看解答

服务成本超过收费 200 元就亏损：P(X > 200)。z = 200 − 15025 = 2，右尾：0.5 − 0.4772 = 0.0228（约 2.3%）。
Answer: 0.0228

P(z > 2)

例 9（L34 Ex 5） Fault-free life of plasma TVs ~ N with μ = 8.7 years, σ = 2 years. (a) With a 4-year warranty, find the probability that a set must be replaced free. (b) At most 1% may be replaced: find the warranty period.

看解答

(a) 4 年内出故障：P(X < 4)，z = 4 − 8.72 = −2.35，左尾 0.5 − 0.4906 = 0.0094（约 0.94%）。
(b) 要 P(X < w) = 0.01，0 到 z 的面积 = 0.49，表中最接近的是 0.4901 → z = −2.33。w = 8.7 − 2.33 × 2 = 4.04 年，即保修期最多约 4 年。
Answer: (a) 0.0094 (b) ≈ 4.04 years

(a) P(z < −2.35)

易错
① 「被 95% 超过的重量」误找右边 5% 的临界值：被 95% 超过意味着它在下方，z 为负。
② 两个 z 都在同一侧时还把面积相加：同侧要相减。
③ 算出 z 后忘了用 x = μ + zσ 换回实际单位。
常见疑惑
问：表里找不到正好的面积怎么办？ 取最接近的表值（例 4、例 9）；如果正好在两个值中间（例 7(b) 的 0.45），取两个 z 的平均 1.645。答案在小数点后第二位上的细小差别是正常的。
