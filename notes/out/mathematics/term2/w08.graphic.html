极差、四分位距与箱线图（L22）

L22_Measures_of_Spread_I.pdf · PDF p1–5

概念
极差 = 最大值 − 最小值，最简单，但只用了两个数，看不出其余数据的分布（Sets A–D 的极差都是 9，分布却完全不同）。
四分位数：Q₀ 最小值，Q₂ 中位数，Q₁ 是 Q₀ 到 Q₂ 这一半的中位数（下四分位数），Q₃ 是 Q₂ 到 Q₄ 这一半的中位数（上四分位数），Q₄ 最大值，合称五数概括。
四分位距 IQR = Q₃ − Q₁：中间一半数据的范围（去掉最高和最低各 25%）。计算器：SHIFT 1 5 3 = 得 Q₁，SHIFT 1 5 5 = 得 Q₃。
箱线图：箱子从 Q₁ 到 Q₃（长度就是 IQR），箱中画中位数线，两端的「须」伸到最小值和最大值。
Range = 最大 − 最小　　IQR = Q₃ − Q₁

Box-and-whisker plots of Sets A–D (range 9 for all)

例 1（L22 Ex 1） Find the range: (a) 2, 1, 2, 1, 1, 5, 1, 9, 4 (b) scores 10, 12, 13, 14 with frequencies 3, 5, 11, 7.

看解答

极差只看最大和最小值（频数不影响）。
(a) 9 − 1 = 8。(b) 14 − 10 = 4。
Answer: (a) 8 (b) 4

例 2（L22 Sets） Sets A: 1,1,1,1,1,10,10,10,10,10; B: 1,5,…,5,10; C: 1,2,…,10; D: 1,10,…,10. All have range 9. Compare their IQRs.

看解答

Set C：Q₁ = 3，Q₂ = 5.5，Q₃ = 8，IQR = 5（均匀分布，中等）。Set A：Q₁ = 1，Q₃ = 10，IQR = 9（集中在两端，最大）。Set B：Q₁ = Q₃ = 5，IQR = 0；Set D：Q₁ = Q₃ = 10，IQR = 0（数据扎堆）。IQR 反映了极差反映不出的差别。

例 3（L22 Ex 2） Find the IQR: (a) 2, 1, 2, 1, 1, 5, 1, 9, 4 (b) scores 10, 12, 13, 14 with frequencies 3, 5, 11, 7.

看解答

(a) 排序：1, 1, 1, 1, 2, 2, 4, 5, 9。中位数是第 5 个 = 2；下半部分 1, 1, 1, 1 → Q₁ = 1；上半部分 2, 4, 5, 9 → Q₃ = 4 + 52 = 4.5。IQR = 4.5 − 1 = 3.5。
(b) n = 26，下半部分是前 13 个，Q₁ = 第 7 个；上半部分是后 13 个，Q₃ = 第 20 个。累积频数 3、8、19、26：第 7 个是 12，第 20 个是 14。IQR = 14 − 12 = 2。
Answer: (a) 3.5 (b) 2

例 4（L22 Ex 3） Draw a box-and-whisker plot for scores 10, 12, 13, 14, 16 with frequencies 3, 5, 11, 7, 2.

看解答

n = 28，累积频数 3、8、19、26、28。中位数 = 第 14、15 个的平均 = 13；Q₁ = 前 14 个的中位数 = 第 7、8 个的平均 = 12；Q₃ = 后 14 个的中位数 = 第 21、22 个的平均 = 14；Q₀ = 10，Q₄ = 16。

Q0 = 10, Q1 = 12, Q2 = 13, Q3 = 14, Q4 = 16

易错
① 求四分位数前没排序。
② n 为奇数时把中位数也算进上下两半（讲义和计算器都不算）。
③ 箱线图的箱子画到最小、最大值。
常见疑惑
问：为什么 Set B 的箱子只有一条线？ Q₁ = Q₂ = Q₃ = 5，箱子长度（IQR）为 0，只剩中位数线。

方差、标准差与 z 分数（L23）

L23_Measures_of_Spread_II.pdf · PDF p1–6

概念
IQR 只用了排序信息，三组极差和 IQR 都相同的数据（Sets A、B、C）分布仍可能不同，需要用到所有数据的度量。
方差 σₙ² = Σ(x − x̄)²n：每个数减去平均数、平方（变正，并加大远离平均数的数的权重）、求和、除以 n。
标准差 σₙ = √方差，与数据同单位。（讲义用总体方差 σₙ²；样本方差用 n − 1。）计算器：SHIFT 1 4 3 = 得 σₙ。
z 分数 z = x − x̄σₙ：这个数比平均数高几个标准差；高于平均为正，低于平均为负。用来比较不同数据集的数。
比较：极差易算但信息少；IQR 不受极端值影响但忽略一半数据；方差 / 标准差用到全部数据、用于很多公式，但受极端值影响、手算麻烦。
σₙ² = Σ(x − x̄)²n　σₙ = √σₙ²
z = x − x̄σₙ

例 5（L23 Sets） Set A: 1,1,3,5,5,5,5,8,10,10; Set B: 1,2,3,4,5,5,7,8,9,10; Set C: 1,3,3,3,5,5,8,8,8,10. All have range 9 and IQR 5. Find σₙ and σₙ² for each.

看解答

用计算器：Set A σₙ = 3.0676，σₙ² = 9.41；Set B σₙ = 2.8705，σₙ² = 8.24；Set C σₙ = 2.8，σₙ² = 7.84。Set A 最大：十个数中有四个在两个极端值上，离平均数远的数对方差影响更大。
注：讲义写 Set B 的 σₙ = 2.872281323、σₙ² = 8.25；按列出的数据计算 σₙ² = 37.4 − 5.4² = 8.24，σₙ ≈ 2.8705，差别很小，结论不变。

例 6（L23 Ex 1） Find σₙ and σₙ²: (a) 1, 1, 3, 4, 5, 6, 8, 8 (b) 3, 3, 3, 4, 4, 5

看解答

(a) x̄ = 36 ÷ 8 = 4.5；离差平方：12.25, 12.25, 2.25, 0.25, 0.25, 2.25, 12.25, 12.25，和为 54；σₙ² = 54 ÷ 8 = 6.75，σₙ ≈ 2.598。
(b) x̄ = 22 ÷ 6 ≈ 3.667；Σx² = 84，σₙ² = 84 ÷ 6 − 3.667² ≈ 0.556，σₙ ≈ 0.745。
Answer: (a) 2.598, 6.75 (b) 0.745, 0.556

例 7（L23 Ex 2） Scores 10, 12, 13, 14, 15. Set A frequencies 3, 5, 11, 7, 4; Set B frequencies 9, 3, 6, 7, 7. Find the mean and variance of each and comment.

看解答

Set A：n = 30，Σfx = 391，x̄ ≈ 13.03；σₙ ≈ 1.354，σₙ² ≈ 1.83。
Set B：n = 32，Σfx = 407，x̄ ≈ 12.72；σₙ ≈ 1.908，σₙ² ≈ 3.64。
两组平均数接近（A 略高），但 B 的方差约为 A 的两倍：A 的数据集中在 13 附近，B 有很多 10 分，分布更分散。
Answer: A: 13.03, 1.83; B: 12.72, 3.64

例 8（L23 Ex 3） A set of scores has mean 83 and σ = 15. Find the z-score for (a) 105 (b) 37.

看解答

(a) z = 105 − 8315 ≈ 1.47（高于平均 1.47 个标准差）。
(b) z = 37 − 8315 ≈ −3.07（低于平均 3.07 个标准差）。
注：讲义第 5 页两条注释都写「If the score is above the mean」，第二条应为「below the mean」时 z 为负。
Answer: (a) 1.47 (b) −3.07

例 9（L23 Strengths） Compare the strengths and weaknesses of the range, IQR and standard deviation.

看解答

极差：易算；只用两个值，信息少。IQR：不受极端值影响；忽略了一半数据。方差 / 标准差：用到全部数据，很多公式要用；受极端值影响，手算麻烦。

易错
① 方差忘了平方或忘了除以 n。
② 标准差和方差混用：标准差是方差的平方根。
③ 计算器选了 sx（样本）而不是 σx（总体）。
常见疑惑
问：为什么要平方而不是直接加离差？ 离差有正有负，直接相加总是 0；平方后都为正，而且离平均越远的数影响越大。

应用：比较、预测与异常值（L24）

L24_Applications_Central_Tendency_and_Spread.pdf · PDF p1–4

概念
平均数比较「水平」，标准差比较「稳定性」（越小越一致）。
平移和缩放：每个数加常数 c，中位数、平均数都加 c，IQR 和标准差不变；每个数乘 k（k > 0），四个量都乘 k。
z 分数比较：不同数据集的成绩，z 越大相对表现越好。预测：假设同一个人在同类测试中 z 分数相同，x = x̄ + zσ。
异常值：|z| > 3（有时用 2）；或 x < Q₁ − 1.5 × IQR、x > Q₃ + 1.5 × IQR。异常值会扭曲平均数，对中位数影响小。
异常值：|z| > 3 或 x < Q₁ − 1.5 IQR、x > Q₃ + 1.5 IQR

例 12（L24 Ex 3） Ten swimmers' 50 m times (s): 24.5, 24.7, 25.2, 24.9, 25.0, 26.1, 24.8, 24.2, 25.1, 27.3. (a) Find the mean and σₙ. (b) Swimmers more than one standard deviation above the mean are eliminated. How many?

看解答

(a) x̄ = 25.18 秒，σₙ ≈ 0.852 秒。
(b) 淘汰线 = 25.18 + 0.852 ≈ 26.03 秒：26.1 和 27.3 超过，淘汰 2 人。
Answer: (a) 25.18, 0.852 (b) 2

例 13（L24 Ex 4） Scores 10, 12, 13, 14, 15 with frequencies 3, 5, 11, 7, 4. (a) Find the median, mean, IQR and σₙ. (b) Add 5 to each score: effect? (c) Multiply each original score by 3: effect?

看解答

(a) n = 30，累积频数 3、8、19、26、30。中位数 = 第 15、16 个的平均 = 13；平均数 = 391 ÷ 30 ≈ 13.03；Q₁ = 前 15 个的中位数 = 第 8 个 = 12，Q₃ = 后 15 个的中位数 = 第 23 个 = 14，IQR = 2；σₙ ≈ 1.354。
(b) 加 5：中位数 18，平均数 18.03（都加 5）；IQR 2、σₙ 1.354 不变（整体平移，离散程度不变）。
(c) 乘 3：中位数 39，平均数 39.1，IQR 6，σₙ ≈ 4.061（都乘 3）。
Answer: (a) 13, 13.03, 2, 1.354

例 15（L24 Ex 6） Esti missed another Mathematics test. Use her previous Mathematics result to estimate her mark.

看解答

假设她在新测试中的相对位置不变，z = 1.67（上一次数学）。估计分数 = 新测试的平均数 + 1.67 × 新测试的标准差。例如新测试平均 60、标准差 12，估计约 60 + 1.67 × 12 = 80 分（这组数字只是示例）。
注：讲义第 6 题没有给出新数学测试的平均数和标准差，笔记给出方法，并用示例数字演示；Tutorial 中以老师给出的数据为准。

例 16（L24 Ex 7） Data: 63, 10, 32, 19, 22, 29, 36, 24, 41, 3. (a) Find any outliers using (i) the standard deviation (ii) the IQR. (b) Find the mean and median with outliers included and excluded.

看解答

排序：3, 10, 19, 22, 24, 29, 32, 36, 41, 63。x̄ = 27.9，σₙ ≈ 15.99。
(a)(i) 63 的 z = 63 − 27.915.99 ≈ 2.20，3 的 z ≈ −1.56，都没超过 3：按 |z| > 3 没有异常值（若用 |z| > 2，63 是异常值）。
(ii) Q₁ = 19，Q₃ = 36，IQR = 17；上界 36 + 25.5 = 61.5，下界 19 − 25.5 = −6.5：63 是异常值。
(b) 含 63：平均数 27.9，中位数 24 + 292 = 26.5。去掉 63：平均数 216 ÷ 9 = 24.0，中位数 24。平均数变化更大：异常值主要影响平均数。
Answer: (i) none with |z| > 3 (ii) 63; mean 27.9 → 24.0, median 26.5 → 24

易错
① 加常数后以为标准差也变了。
② 比较不同科目直接比原始分数。
③ 异常值的 IQR 界限用 1.5 × IQR 但忘了从 Q₁、Q₃ 出发。
常见疑惑
问：什么时候用中位数和 IQR，什么时候用平均数和标准差？ 有异常值或分布偏斜时，中位数和 IQR 更可靠；数据比较对称、没有明显异常值时用平均数和标准差，信息更完整。
