CDF 与 PDF（L31）

L31_Continuous_Random_Variables_I.pdf · PDF p1–7

概念
离散随机变量取可数个值，概率分布表满足 pᵢ ≥ 0、Σpᵢ = 1。现实中很多量（身高、体重）可以取某区间内的任何实数，这就是连续随机变量。连续时任一具体值的概率都是 0：P(X = c) = 0，所以要看「≤」的累积概率。
累积分布函数 CDF：F(x) = P(X ≤ x)，从 0 增加到 1。P(a ≤ X ≤ b) = F(b) − F(a)。（连续时用 < 还是 ≤ 没有区别。）
概率密度函数 PDF：f(x) = F′(x)。于是 P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx（PDF 下的面积）。f 必须满足：f(x) ≥ 0，且 ∫ f(x) dx = 1（总面积为 1）。
F(x) = P(X ≤ x)，P(a ≤ X ≤ b) = F(b) − F(a)
f(x) = F′(x)，P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx

例 1（L31 Spinner） A spinner measures the distance (0 to 4) round its circumference from a fixed point. Find the CDF, P(X ≤ 2.374) and P(1.4 ≤ X ≤ 2.6).

看解答

离散的四格转盘，P(X ≤ k) 依次是 0.25、0.5、0.75、1；连续转盘的累积概率是一条直线 F(x) = 0.25x（0 ≤ x ≤ 4），x < 0 时为 0，x > 4 时为 1。
P(X ≤ 2.374) = 0.25 × 2.374 = 0.5935。
P(1.4 ≤ X ≤ 2.6) = F(2.6) − F(1.4) = 0.65 − 0.35 = 0.3。

PDF of the spinner: P(1.4 ≤ X ≤ 2.6) is the shaded area 0.3

例 2（L31 Dartboard） Darts hit a circular board of radius 4 cm; X is the distance from the centre. Find the CDF and PDF.

看解答

X ≤ x 表示落在半径 x 的圆内，概率 = 面积之比：F(x) = πx²π × 4² = x²16（0 ≤ x ≤ 4）。求导：f(x) = x8（0 ≤ x ≤ 4），其他为 0。

例 3（L31 Ex 1） F(x) = 0 for x < 0, 15x + 320x² for 0 ≤ x ≤ 2, 1 for x > 2. Find (a) P(X ≤ 1.5) (b) P(0.5 ≤ X ≤ 1.5) (c) P(X = 1).

看解答

(a) F(1.5) = 0.3 + 320 × 2.25 = 0.6375。
(b) F(1.5) − F(0.5) = 0.6375 − (0.1 + 0.0375) = 0.5。
(c) 连续随机变量取某个具体值的概率为 0。
Answer: (a) 0.6375 (b) 0.5 (c) 0

例 4（L31 PDF） Explain how the PDF arises from the CDF for the spinner.

看解答

P(1.4 ≤ X ≤ 2.6) = F(2.6) − F(1.4)，形式和定积分 ∫₁.₄²·⁶ f(x) dx = F(2.6) − F(1.4) 一样，其中 F 是 f 的原函数，所以 f(x) = F′(x)。转盘：f(x) = ddx(0.25x) = 0.25（0 ≤ x ≤ 4），其他为 0；概率就是这条水平线下的面积。

PDF of the spinner: P(1.4 ≤ X ≤ 2.6) is the shaded area 0.3

看解答

f(x) = F′(x) = 15 + 310x（0 ≤ x ≤ 2），其他为 0。检查：f ≥ 0，且 ∫₀² f(x) dx = F(2) − F(0) = 1。P(0.5 ≤ X ≤ 1.5) 就是图中阴影的面积 0.5。

例 6（L31 Ex 3） Waiting time X has CDF F(x) = 1 − e^(−x/10) for x ≥ 0 (0 otherwise). (a) Find the probability of waiting more than 4 minutes. (b) Find the PDF.

看解答

(a) P(X > 4) = 1 − F(4) = e−0.4 ≈ 0.670。
(b) f(x) = F′(x) = 110e−x/10（x ≥ 0），其他为 0。
Answer: (a) e^(−0.4) ≈ 0.670 (b) f(x) = e^(−x/10)/10

Waiting time: P(X > 4) = e^(−0.4) is the shaded tail

易错
① 连续变量还去求 P(X = c) 的正数值。
② f(x) 当成概率本身：概率是面积，f 的值可以大于 1。
③ 忘了写「其他为 0」的分段。
常见疑惑
问：PDF 的值可以大于 1 吗？ 可以（如 L32 例 2(b) 中 f(1) = 2）。要求的是 f ≥ 0 且总面积为 1，概率由面积给出。

中位数、众数与期望（L32）

L32_Continuous_Random_Variables_II.pdf · PDF p1–3

概念
中位数 M：P(X ≤ M) = F(M) = 0.5。
众数：PDF 达到最高点的 x，可能在极大值点，也可能在端点（因为任一具体值的概率都是 0，不能按「概率最大的值」定义）。
期望：E(X) = μ = ∫ x f(x) dx（离散时是 Σxᵢpᵢ）。例：飞镖 f(x) = x/8，E(X) = ∫₀⁴ x²8 dx = 6424 ≈ 2.7 cm。
F(M) = 0.5
E(X) = ∫ x f(x) dx

例 7（L32 Ex 1） F(x) = 0 for x < 0, x³ for 0 ≤ x ≤ 1, 1 for x > 1. Find the median.

看解答

中位数满足 F(M) = 0.5，即有一半的概率落在 M 左边。M 在 [0, 1] 内，所以 F(M) = M³ = 0.5，开立方得 M = ∛0.5 ≈ 0.794。它比区间中点 0.5 大，说明概率集中在右侧（f(x) = 3x² 越往右越高）。
Answer: ≈ 0.794

例 8（L32 Ex 2） Find the mode for (a) f(x) = 12x²(1 − x), 0 ≤ x ≤ 1 (b) f(x) = 2x, 0 ≤ x ≤ 1.

看解答

(a) f′(x) = 24x − 36x² = 12x(2 − 3x) = 0，x = 23（x = 0 是最小值）；f″(23) = 24 − 72 × 23 < 0，是极大值：众数 23。
(b) f(x) = 2x 在 [0, 1] 上递增，最高点在端点：众数 1。
Answer: (a) 2/3 (b) 1

(a) maximum turning point at x = 2/3

(b) highest at the endpoint x = 1

例 9（L32 Dartboard Mean） Find E(X) for the dartboard (f(x) = x/8, 0 ≤ x ≤ 4).

看解答

E(X) = ∫₀⁴ x × x8 dx = [x³24]₀⁴ = 6424 = 83 ≈ 2.7 cm。飞镖更可能落在外圈（面积大），所以平均距离大于半径的一半。
Answer: 8/3 ≈ 2.7 cm

例 10（L32 Ex 3） f(x) = 12√x for 1 ≤ x ≤ 4 (0 otherwise). Find E(X).

看解答

先检查是 PDF：∫₁⁴ 12√x dx = [√x]₁⁴ = 2 − 1 = 1 ✓。
E(X) = ∫₁⁴ x × 12√x dx = ∫₁⁴ √x2 dx = [x3/23]₁⁴ = 8 − 13 = 73 ≈ 2.33。
Answer: 7/3

Ex 3: E(X) = 7/3 ≈ 2.33

易错
① 中位数令 f(M) = 0.5：应令 F(M) = 0.5。
② 众数只找导数为 0 的点，忘了检查端点（例 8(b)）。
③ 期望写成 ∫ f(x) dx（那是 1）。
常见疑惑
问：怎么从 PDF 求中位数？ 先积分得到 CDF：F(x) = ∫ f(t) dt（从下界积到 x），再解 F(M) = 0.5。
