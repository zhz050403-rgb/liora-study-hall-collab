对数函数的图像（Graphs of Logarithmic Functions）

L13 Graphs of Logarithmic Functions.pdf · PDF p1–4

概念
y = logb x 是指数函数 y = bx 的反函数（inverse function）：把 x 和 y 对调，x = by，就得到 y = logb x。所以它的图像是 y = bx 关于直线 y = x 的镜像。
ln x 是以 e（≈ 2.718）为底的对数，log x（课件写作 log10 x）是以 10 为底。
y = logb x（b > 1）的特征一般式 y = logb(x − h) + k
定义域（domain）：x > 0x > h
值域（range）：全体实数全体实数
竖直渐近线（vertical asymptote）：x = 0，即 y 轴x = h
x 截距：(1, 0)令 y = 0 求：x = h + b−k
经过点 (b, 1)；图像连续、单调递增整体平移：右移 h，上移 k

以 b = e 为例：y = bˣ 与 y = log_b x 关于虚线 y = x 对称，点 (0, 1) 翻到 (1, 0)。

画对数图的固定步骤（课件 p3）：①先画竖直渐近线；②写出定义域，确定图像在渐近线的哪一侧；③求 x 截距（以及 y 截距，如果 0 在定义域内）；④再找一个好算的点；⑤按「靠近渐近线时往下（或往上）无限延伸」连成曲线。

例 0（L13 p1） Consider y = bx (b > 1). (a) Find the equation of the inverse function. (b) Sketch y = bx and, using the reflection property, sketch its inverse on the same axes.

看解答

(a) 对调 x、y：x = by，两边取以 b 为底的对数：y = logb x。
(b) 见上图：y = bx 过 (0, 1)、以 x 轴为水平渐近线；关于 y = x 翻折后，y = logb x 过 (1, 0)、以 y 轴为竖直渐近线。点 (0, 1) 翻成 (1, 0)，点 (1, b) 翻成 (b, 1)。
Answer: y = logb x

例 1（L13 Ex 1） On the same axes, sketch the graphs of y = ln x and y = log10 x.

两条曲线都过 (1, 0)；x > 1 时 ln x 在上方，0 < x < 1 时在下方。

看解答

两条曲线都过 (1, 0)，都以 y 轴为渐近线。ln x 过 (e, 1)，log10 x 过 (10, 1)。
x > 1 时 ln x 在上方（底数越小，长得越快）；0 < x < 1 时 ln x 在下方（更快地往下冲）。两条曲线只在 (1, 0) 相交。

例 2（L13 Ex 2） Use transformation methods to sketch: (a) y = ln x + 1 (b) y = ln(x + 1) (c) y = 3 ln x (d) y = ln(−x)

(a) 上移 1；(b) 左移 1，渐近线变成 x = −1；(c) 竖直拉伸 3 倍；(d) 关于 y 轴翻折。

看解答

(a) 整体上移 1：渐近线仍是 x = 0，定义域 x > 0；x 截距由 ln x = −1 得 x = e−1 ≈ 0.37。
(b) 左移 1（括号里 +1 是向左）：渐近线 x = −1，定义域 x > −1，经过原点 (0, 0)。
(c) 竖直拉伸 3 倍：x 截距仍是 (1, 0)，渐近线 x = 0，经过 (e, 3)。
(d) 关于 y 轴翻折：定义域 x < 0，x 截距 (−1, 0)，渐近线 x = 0。

例 3（L13 Ex 3） Sketch the graphs of the following functions, stating the domain and showing essential features. (a) y = −ln x (b) y = ln(−x) (c) y = log2 2x (d) y = 2 log3(x − 3) (e) y = 1 − ln(1 − x) (f) y = 2 log5(x + 5) − 1

(e) y = 1 − ln(1 − x)：在渐近线 x = 1 左侧；(f) y = 2 log₅(x + 5) − 1：在渐近线 x = −5 右侧。两条都过 (0, 1)。

看解答

(a) 关于 x 轴翻折：定义域 x > 0，渐近线 x = 0，x 截距 (1, 0)，递减。
(b) 同例 2 (d)：定义域 x < 0，x 截距 (−1, 0)。
(c) log2 2x = 1 + log2 x：定义域 x > 0，渐近线 x = 0；2x = 1 时 y = 0，x 截距 (12, 0)；经过 (1, 1)。
(d) 定义域 x − 3 > 0 即 x > 3，渐近线 x = 3；x − 3 = 1 时 y = 0，x 截距 (4, 0)；x − 3 = 3 时 y = 2，经过 (6, 2)。
(e) 定义域 1 − x > 0 即 x < 1，渐近线 x = 1；y 截距：x = 0 时 y = 1 − ln 1 = 1；x 截距：ln(1 − x) = 1，1 − x = e，x = 1 − e ≈ −1.72。x 靠近 1 时 ln(1 − x) → −∞，所以 y → +∞；图像递增。
(f) 定义域 x > −5，渐近线 x = −5；y 截距：x = 0 时 y = 2 log5 5 − 1 = 1；x 截距：log5(x + 5) = 12，x + 5 = √5，x = √5 − 5 ≈ −2.76。

易错
① 把 ln(x + 1) 当成右移：括号里 +1 是左移，渐近线是 x = −1。
② 忘记写定义域，或写成 x ≥ 0：对数里面必须严格大于 0，渐近线那一点永远取不到。
③ 画 y = 1 − ln(1 − x) 时直接套 ln x 的形状：先看定义域 x < 1，图像在渐近线左边。
④ 曲线碰到渐近线：渐近线是「越来越近、永远碰不到」，画图时要留一点空隙。
常见疑惑
问：−ln x 和 ln(−x) 有什么区别？ −ln x 是关于 x 轴翻折（y 变号），定义域还是 x > 0；ln(−x) 是关于 y 轴翻折（x 变号），定义域变成 x < 0。
问：log2 2x 能不能看成「log2 2 乘以 x」？ 不能。它是 log2(2x)，用对数法则拆成 log2 2 + log2 x = 1 + log2 x，相当于 log2 x 上移 1。
问：考试要画得多准？ 要求是「showing essential features」：渐近线（虚线并标方程）、截距、一个代表点、定义域，以及正确的弯曲方向。不需要逐点描图。

定义域：限制定义域与自然定义域（Domain）

L14 More on Domain and Piecemeal Functions.pdf · PDF p1–4

概念
自然定义域（natural domain / largest possible domain）：题目没有限制时，所有能代入、算得出实数结果的 x。
限制定义域（restricted domain）：题目明确规定的 x 范围，它是函数的一部分，画图时只画这一段，端点用实心点（含）或空心点（不含）标出。
找自然定义域只要盯住三种「危险」：根号里 ≥ 0；分母 ≠ 0；对数里 > 0。根号在分母上时两条同时成立，变成「根号里 > 0」。

y = (x + 1)²，−2 < x ≤ 1：左端空心、右端实心；最低 0、最高 4。

例 1（L14 Ex 1） (a) Sketch y = (x + 1)2 for the restricted domain −2 < x ≤ 1. (b) State the range of the function for this restricted domain.

看解答

(a) 顶点 (−1, 0)。左端 x = −2 时 y = 1，但 −2 不含，画空心点；右端 x = 1 时 y = 4，含，画实心点（见上图）。
(b) 最低点是顶点 y = 0（取得到），最高点是右端 y = 4（取得到）。左端的 y = 1 虽然取不到，但 x = 0 时 y 也等于 1，所以 1 仍在值域里。值域：0 ≤ y ≤ 4。
Answer: 0 ≤ y ≤ 4

例 2–7（L14 Ex 2–7） State the natural (largest possible) domain of: Ex 2 y = √x；Ex 3 y = √(x − 3)；Ex 4 y = √(2 − x)；Ex 5 y = 2 − √(4 − x2)；Ex 6 y = √(x2 − 2x − 3)；Ex 7 y = √(x2 + 1)。Ex 2、3 还要画图。

根号函数只在「根号里 ≥ 0」的范围内有图像：√x 从 0 开始，√(x − 3) 从 3 开始，2 − √(4 − x²) 只在 −2 到 2 之间。

看解答

全部用「根号里 ≥ 0」：
Ex 2：x ≥ 0。图像从 (0, 0) 出发，经过 (1, 1)、(4, 2)，向右越来越平。
Ex 3：x − 3 ≥ 0，x ≥ 3。就是 √x 右移 3，从 (3, 0) 出发。
Ex 4：2 − x ≥ 0，x ≤ 2。
Ex 5：4 − x2 ≥ 0，x2 ≤ 4，−2 ≤ x ≤ 2。（图像是以 (0, 2) 为圆心、半径 2 的下半圆，值域 0 ≤ y ≤ 2。）
Ex 6：x2 − 2x − 3 = (x − 3)(x + 1) ≥ 0。开口向上的抛物线在两根外侧非负：x ≤ −1 或 x ≥ 3。
Ex 7：x2 + 1 ≥ 1 > 0 恒成立，定义域是全体实数。
Answer: x ≥ 0；x ≥ 3；x ≤ 2；−2 ≤ x ≤ 2；x ≤ −1 或 x ≥ 3；all real x

例 8–11（L14 Ex 8–11） Ex 8 Sketch y = 1x − 2 and state its natural domain. Ex 9 y = 1x2 − 4. Ex 10 y = 1√(x − 3). Ex 11 y = 1√(x − 2) + 2√(4 − x). State the largest possible domain.

看解答

Ex 8：分母 x − 2 ≠ 0，定义域 x ≠ 2。图像是 y = 1x 右移 2：竖直渐近线 x = 2，水平渐近线 y = 0，y 截距 (0, −12)。
Ex 9：x2 − 4 ≠ 0，x ≠ ±2。
Ex 10：根号在分母，x − 3 > 0，x > 3（x = 3 会让分母为 0）。
Ex 11：两项都要有定义：x − 2 > 0 且 4 − x > 0，取交集 2 < x < 4。
Answer: x ≠ 2；x ≠ ±2；x > 3；2 < x < 4

易错
① 例 1 把值域写成 1 < y ≤ 4：值域要看整段图像的最低点和最高点，顶点在定义域内，最低是 0。
② 例 6 写成 −1 ≤ x ≤ 3：那是「≤ 0」的区间，正好反了。画出抛物线再判断最稳。
③ 例 10 写成 x ≥ 3：根号在分母时等号要去掉。
④ 例 11 只算了一项：几项相加时，定义域是各项定义域的交集。
常见疑惑
问：natural domain、largest possible domain、domain 有区别吗？ 题目没给限制时，三个说法是同一个意思。
问：区间要用不等式写还是用括号写？ 两种都可以，本课课件用不等式（如 −2 ≤ x ≤ 2）。用括号时，圆括号表示不含端点，方括号表示含端点：[−2, 2]。

分段函数（Piecemeal Functions）

L14 More on Domain and Piecemeal Functions.pdf · PDF p5–6

概念
分段函数（piecemeal / piecewise function）在定义域的不同部分用不同的式子，但它仍然是一个函数：每个 x 只对应一个 y。
求值：先看 x 落在哪一段，再代入那一段的式子。
画图：每一段只画在自己的范围里；分界点取「≤ / ≥」的一段画实心点，取「< / >」的一段画空心点。
连续（continuous）：图像一笔画完、没有断开；分界点两侧的式子在分界点算出的值相等。

左：例 12，两段在原点接上，连续。右：例 13，x = 0 处实心点在上、空心点在下，不连续。

例 12（L14 Ex 12） f(x) = x2 if x ≥ 0; 2x if x < 0. (i) Find (a) f(1) (b) f(−1) (c) f(a2). (ii) Sketch the graph.

看解答

(a) 1 ≥ 0，用 x2：f(1) = 1。
(b) −1 < 0，用 2x：f(−1) = −2。
(c) a2 ≥ 0 对任何 a 都成立，所以用 x2：f(a2) = (a2)2 = a4。
(ii) 左边是过原点的直线 y = 2x，右边是抛物线右半支，两段在 (0, 0) 接上，图像连续（见上图左）。
Answer: 1, −2, a4

例 13（L14 Ex 13） Sketch f(x) = x − 1 if x > 0; 2 if x ≤ 0.

看解答

x ≤ 0 时是水平线 y = 2，在 (0, 2) 画实心点；x > 0 时是直线 y = x − 1，从 (0, −1) 的空心点开始往右上。两段在 x = 0 处接不上，图像不连续（见上图右）。

例 14（L14 Ex 14） f(x) = x + k if x ≤ 2; 2 − x if x > 2. (a) Given that the graph of y = f(x) is continuous, find k. (b) Sketch y = f(x).

看解答

注：课件把第二段条件印成了 “x < 2”，和第一段重叠；按题意应为 x > 2。
(a) 连续要求两段在 x = 2 处的值相等：2 + k = 2 − 2 = 0，所以 k = −2。
(b) x ≤ 2 时 y = x − 2，到 (2, 0)；x > 2 时 y = 2 − x，从 (2, 0) 往右下。图像是一个开口向下的「∧」形，尖点在 (2, 0)。
Answer: k = −2

例 15（L14 Ex 15） Find the equation of the piecemeal function which has been sketched, given that the curved part is a parabola. （图中：x < −1 部分是水平射线，在 (−1, 1) 处为空心点；x ≥ −1 部分是抛物线，顶点 (1, −1)，与 x 轴交于 0 和 2，左端 (−1, 3) 为实心点。）

按讲义图复原：x < −1 时 y = 1；x ≥ −1 时 y = x² − 2x（顶点 (1, −1)）。

看解答

抛物线部分：顶点式 y = a(x − 1)2 − 1。代入根 x = 2：0 = a − 1，a = 1，所以 y = (x − 1)2 − 1 = x2 − 2x。检查：x = 0 时 y = 0 ✓；x = −1 时 y = 3 ✓（图中实心点）。
水平部分：y = 1，x < −1。
f(x) = 1 if x < −1；x2 − 2x if x ≥ −1。

易错
① 求 f(a2) 时没判断 a2 落在哪一段：a2 永远 ≥ 0。
② 分界点两边都画实心点：同一个 x 只能有一个 y，只有含等号的那一段画实心。
③ 例 15 只写了式子，没写每段的 x 范围：分段函数的范围是答案的一部分。
常见疑惑
问：分段函数画出来不连续，还算一个函数吗？ 算。只要每个 x 只对应一个 y（竖直线检验最多交一次），就是函数，连不连续是另一回事。
问：怎么判断连续？ 把分界点分别代入两段的式子，两个值相等就连续（例 12：0 和 0 相等；例 13：2 和 −1 不等）。

用图像解方程和不等式（Use of Graphs）

L15 Use of Graphs.pdf · PDF p1–4

概念
f(x) = g(x) 的解：两条图像交点的 x 坐标；有几个交点就有几个解。
f(x) = k 的解的个数：画水平线 y = k，数它和 y = f(x) 交几次。
f(x) < g(x)：把两条图像画在一起，找 f 的图像在 g 下方的那些 x。建议两条线用不同颜色。

例 1（L15 Ex 1） The diagram shows the graph of y = f(x)（经过 (−8, −2)、(−7, 0)、极大值点 (−3, 5)、(0, 4)、(2, 0)、极小值点 (4, −2)、(6, 0)、(10, 5)）. (a) Find f(4). (b) Solve f(x) = 5. (c) Solve f(x) < 0. (d) Find the number of solutions to f(x) = 3. (e) Find the range of f(x) for the restricted domain 0 < x < 10. (f) Find the number of solutions to f(x) = −2x.

按讲义图上的关键点画的示意图：y = 3 与图像交 3 次，y = −2x 只交 1 次（在 −3 与 0 之间）。

看解答

(a) 图上 (4, −2)：f(4) = −2。
(b) y = 5 碰到图像两次：极大值点和 (10, 5)。x = −3 或 x = 10。
(c) 图像在 x 轴下方的部分：x < −7 或 2 < x < 6。
(d) 画 y = 3：在 −7 与 −3 之间上升段交一次，在 −3 与 2 之间下降段交一次（y 截距 4 比 3 高），在 6 以后上升段交一次，共 3 个解。
(e) x 从 0（y = 4，取不到）往右，先降到最低点 (4, −2)（取得到），再升到 x = 10 处的 5（取不到）。值域：−2 ≤ y < 5。
(f) 画直线 y = −2x（过原点、往右下）。x < 0 时直线比较高，在 −3 附近 −2x = 6 > 5，而在 x = 0 处 f = 4 > 0，所以在 −3 与 0 之间交一次；x > 0 时直线在 x 轴下方越走越低，最低只到 −8（x = 4 时），始终低于图像。共 1 个解。
Answer: −2；x = −3 或 10；x < −7 或 2 < x < 6；3；−2 ≤ y < 5；1

例 2（L15 Ex 2） The diagram shows y = f(x) where f(x) = x2(x − 3). (a) Find f(2) and f(−1). (b) State the number of times y = k cuts the graph when (i) k = 3 (ii) k = −1. (c) Find k for which f(x) = k has exactly (i) one (ii) two (iii) three real solutions. (d) Solve x3 ≥ 3x2. (f) Find the values of x for which −4 < f(x) < 0.

水平线 y = k：k = 3 交 1 次，k = −1 交 3 次；k = 0 或 −4 时交 2 次（擦过拐弯处）。

看解答

(a) f(2) = 4 × (−1) = −4；f(−1) = 1 × (−4) = −4。
(b) 图像在 x = 0 处碰 x 轴（局部最高 0），在 x = 2 处最低 −4。(i) y = 3 在 0 以上，只碰到右边上升段 1 次。(ii) y = −1 在 −4 和 0 之间，交 3 次。
(c) 看水平线能交几次：(i) 一个解：k > 0 或 k < −4；(ii) 两个解：k = 0 或 k = −4（刚好擦过拐弯处）；(iii) 三个解：−4 < k < 0。
(d) x3 ≥ 3x2 就是 x2(x − 3) ≥ 0，即 f(x) ≥ 0：图像在 x 轴上或上方的点。x ≥ 3，或者 x = 0（原点那一个点，很容易漏）。
(f) f(x) < 0：x < 3 且 x ≠ 0；f(x) > −4：因为 f(x) + 4 = x3 − 3x2 + 4 = (x + 1)(x − 2)2，所以要 x > −1 且 x ≠ 2。合起来：−1 < x < 3，且 x ≠ 0、x ≠ 2。
注：课件小题编号从 (d) 直接跳到 (f)，没有 (e)。
Answer: −4, −4；1 次，3 次；k > 0 或 k < −4 / k = 0 或 −4 / −4 < k < 0；x = 0 或 x ≥ 3；−1 < x < 3（x ≠ 0, 2）

例 3（L15 Ex 3） The diagram shows the parabola y = p(x) and the straight line y = l(x)（两者交于原点和 (3, 2)，抛物线在两交点之间位于直线下方）. (a) Solve p(x) = l(x). (b) Find the values of x for which p(x) ≤ l(x).

示意图（函数式为示意，只保留讲义图的交点 (0, 0)、(3, 2) 和上下关系）：阴影区间里抛物线在直线下方。

看解答

(a) 交点的 x 坐标：x = 0 或 x = 3。
(b) 抛物线在直线下方或相交的部分：0 ≤ x ≤ 3（「≤」包括两个交点）。
Answer: x = 0, 3；0 ≤ x ≤ 3

例 4（L15 Ex 4） (a) Sketch y = 1x + 1. (b) Use your graph to solve 1x + 1 < 2. (c) Find the value(s) of k for which the equation k(x + 1) = 1 has no solution.

绿色区域是 1/(x + 1) < 2 的解：x < −1 或 x > −½。

看解答

(a) y = 1x 左移 1：竖直渐近线 x = −1，水平渐近线 y = 0，y 截距 (0, 1)。
(b) 先求等号：1x + 1 = 2，x + 1 = 12，x = −12。再看图：左支（x < −1）全部在 y = 0 下方，当然 < 2；右支从 +∞ 往下降，过了 x = −12 就低于 2。解：x < −1 或 x > −12。
(c) k(x + 1) = 1 等价于 1x + 1 = k（x ≠ −1）。水平线 y = k 只有在 k = 0 时碰不到图像（那正是水平渐近线）。也可直接看：k = 0 时方程变成 0 = 1，无解。
Answer: x < −1 or x > −1/2；k = 0

例 5（L15 Ex 5） (a) Sketch y = |x| and y = |3x − 1| on the same axes. (b) Find the coordinates of the points of intersection. (c) Use your diagram to solve |x| > |3x − 1|.

两个交点之间（绿色）|x| 在上方：¼ < x < ½。

看解答

(a) y = |x| 是顶点在原点的 V 形；y = |3x − 1| 顶点在 (13, 0)，两边更陡（斜率 ±3）。
(b) 两种情况：x = 3x − 1 得 x = 12；x = −(3x − 1) 得 x = 14。交点 (14, 14) 和 (12, 12)。
(c) |x| 的图像在 |3x − 1| 上方的部分在两交点之间：14 < x < 12。
Answer: (1/4, 1/4), (1/2, 1/2)；1/4 < x < 1/2

易错
① 把交点的纵坐标当成方程的解：f(x) = g(x) 的解是 x 坐标。
② 例 2 (d) 漏掉 x = 0：图像在原点「碰一下」x 轴，f(0) = 0 满足 ≥ 0。
③ 例 4 (b) 两边同乘 (x + 1)：x + 1 可能是负数，乘了以后不等号方向会变，这正是要用图像来解的原因。
④ 区间端点该不该取：题目是 < / > 就不取，≤ / ≥ 才取；值域还要看端点本身是否在定义域内（例 1 (e)）。
常见疑惑
问：不知道函数式，只给图，怎么答？ 只能读图上标出的点和形状，答案也只用这些信息，比如例 1 (d) 只需说明交点个数，不用求出具体 x。
问：(c) 这类「有几个解」的题怎么系统地找 k？ 先找图像的拐弯处（局部最高、最低点）的 y 值，它们把 k 分成几段；拿一根水平线从上往下扫，记下每一段的交点个数，拐弯处单独数。
问：|x| > |3x − 1| 能不能两边平方？ 能，两边都非负时平方不改变方向：x2 > (3x − 1)2，化简为 (4x − 1)(2x − 1) < 0，结果相同。考试题目写了「use your diagram」时，要用图像说明。
