# NOTE_SPEC_V1

依据 [AMOS 长期规则第十一、十二节](https://docs.google.com/document/d/1onvndr5Tc0I0pTjTRAm2wZLB7OHV3Rd_nr9LN-NC734/edit)。本文件是项目唯一笔记验收规范。现有运行中的 SPEC 和 Prompt 尚未迁移，冲突处不得用旧标准判通过。

以课程 ID、学期 ID、周次、知识点 ID 定位。每点逐项记录 PASS、FAIL、待复核或有理由的 N/A：

1. 准确完整的英文标题在前，紧跟对应中文，沿用官方术语。
2. 独立完整的英文讲解，包括概念、原因、条件和应用。
3. 紧随英文的完整中文讲解，关键事实和结论与英文对齐。
4. 按适用性提供公式、逐步计算和必要图表。自制图注明示意或拓展。
5. 重要且适用的知识点提供题目、条件、分步解答、答案与解释。概念题可用有步骤的场景案例。不得伪造官方题、答案或页码。

机器负责结构、文件、页码、数据差异及可计算校验。语义、覆盖与学科准确性由复核者对照官方原页判定。分别记录原稿、生成数据、本地渲染、正式页面的证据。测试通过不等于内容通过。

其他 AI 只交分配课程的补丁。Codex 读取最新版本、检查预期摘要、保护课程和任务映射，以及成绩与进度，统一集成。发现冲突停止写入。每批保存输入输出摘要、差异和测试结果。通过并经 Liora 确认后锁定内容与模板。普通变更重验改动及关联项，共享结构变更扩大相应回归范围。正式发布前跑关键回归并取得本阶段要求的独立批准。

首轮范围仅 Accounting Term 1 Week 1。候选 DOCX 只提供排版结构参考，内容独立验收。
