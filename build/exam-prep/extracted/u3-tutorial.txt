Learning objectives
At the end of this tutorial, you should be able to
•
 Define accounts and apply associated debit and credit rules
•
Summarise accounting transactions using a transaction analysis table.
•
 Identify the difference between the periodic and perpetual inventory systems.
•
Investigate and classify key accounts

Before this tutorial, you should have
•
Attended the Unit 3 lecture
•
Read the Unit 3 Readings
•
Completed the Unit 3 Tutorial Questions
•
Read the In-Class Activities question

•
Complete the In-Class Activities

After this tutorial, you should
•
Consider attending one of the scheduled consultations and attempt to resolve any
questions that you have as soon as possible.
