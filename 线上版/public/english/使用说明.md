## 一、怎么打开（30 秒）

### ✅ 方式 A：在「学习小屋」里用（最推荐）

打开学习小屋（桌面 `新南2026\网站\` 里的 **打开学习小屋.bat**），登录后点顶栏 **「英语学习」** → 就是这个英语工作台。
**英语模块现在就住在学习小屋里面**（`网站\english\`），以后所有改动都会直接体现在学习小屋里，不需要任何「同步」动作。

### ✅ 方式 B：双击「启动网站.bat」（单独用英语站）

在 `D:\WorkBuddy\英语\` 双击 **`启动网站.bat`**（桌面上也有一个「Liora English.bat」快捷入口，作用相同），会弹出一个黑色小窗口 + 自动打开浏览器，直接就能用。
它和方式 A **读的是同一份文件**，内容完全一致。


- 这个小窗口就是网站本体，**关掉窗口 = 关闭网站**（学习数据已自动保存，不会丢）。
- 为什么要这样开：它能让你电脑上的网页和 AI 接口走同一个地址，避开浏览器/预览窗口的「安全白名单」拦截——否则 AI 查词、批改、对话会报「网络请求失败」。
- **完全不需要 WorkBuddy**：启动器会自己找到 Node.js（你这台电脑已装好），整个网站从打开到运行都在你本地完成。
- 启动器是纯英文界面的黑窗口（这是故意的：Windows 的 .bat 文件含中文容易乱码，纯英文最稳）。

### 备选方式：直接双击 index.html

双击 **`C:\Users\Liora\LioraEnglish\index.html`** 也能打开（这是学习小屋里英语模块的快捷入口），且**不需要任何服务**：离线功能（两篇预生成文章、生词本、复习、数据）完整可用；AI 功能也已验证可直连模型服务（实测跨域放行），Key 有效时即可用。

## 二、AI 模型：默认 WorkBuddy API（tokenmao），打开即用

应用已预置好 **WorkBuddy API**（接口地址 `workbuddy.tokenmao.cn`，OpenAI 兼容，国内可直接访问）。你的 Key 已随项目放在 `prototype/config.local.js` 里，**双击 `index.html` 打开就能直接用 AI**，无需手动填 Key。

| 配置项 | 默认值 |
|---|---|
| 服务商 | OpenAI 兼容 |
| Base URL | `https://workbuddy.tokenmao.cn/v1` |
| 模型 | `TM ·DeepSeek-V4` |
| API Key | 已放入 `config.local.js`（打开即用；也可在「设置」里改成自己的） |

**不想用本地 Key 文件？**
- 删除 `prototype/config.local.js`，然后在「设置 → API Key」里手动粘贴你的 Key 即可（之后只存于本机浏览器）。
- 强烈建议：把项目文件夹发给别人或发布前，**先删除 `config.local.js`**，避免密钥被一并带走。

**首次打开检查**
1. 打开「设置」→ 应已显示接口地址 `https://workbuddy.tokenmao.cn/v1` 与模型 `TM ·DeepSeek-V4`。
2. 点「🔌 测试连接」→ 显示“连接成功”即代表 AI 可用。
3. 如连接失败：先确认 `workbuddy.tokenmao.cn` 服务是否正常（该平台偶尔维护），再点「测试连接」重试。

> ⚠️ **Key 失效怎么办**：如果「测试连接」报 **401 / “API Key 无效或已重置”**，说明平台侧的 Key 被轮掉了（该平台维护后可能出现）。到平台「密钥/API」页面重新生成一个 Key，然后二选一：① 打开 `prototype/config.local.js` 把新 Key 替换进去；② 删掉 `config.local.js`，在「设置 → API Key」手动粘贴。两种方式都会自动生效，不用清浏览器数据。

> 你的 API Key 只保存在**你自己这台设备的浏览器 localStorage**（或在本地 `config.local.js`）中，不会发到除模型服务商以外的任何地方。

### 想换模型？

| 模型 | 特点 |
|---|---|
| `TM ·DeepSeek-V4`（默认） | 通用强模型，批改 / 陪练 / 查词都够用，性价比好 |
| `TM ·Fast` | 响应最快，适合查词、口语对话等高频低延迟场景 |
| `TM ·Auto` | 由平台自动路由到当前最佳模型 |

在「设置 → 模型名称」里改成上表中的任一名称即可，其他都不用动。

### 想换其他服务商？

- 任何兼容 OpenAI 格式的接口（DeepSeek、硅基流动、月之暗面等）都可用：把它的 Base URL 和 Key 填进「设置」即可，用法完全一样。
- 切换后 `config.local.js` 中的 Key 仅在未手动填 Key 时生效；手动填过则以「设置」里的为准。

### 🔐 安全提醒

- 你的 API Key **只保存在本机**（浏览器 localStorage 或本地 `config.local.js`），不会打进共享源码，也不发到除模型服务商以外的任何地方。
- `config.local.js` 是本地覆盖文件：**分享 / 发布项目前请务必删除它**，并到对应平台删掉旧 Key、重新生成，避免密钥泄露。
- 换设备时在新设备的「设置」里再填一次 Key（或把 `config.local.js` 复制过去）即可；想带走过学习记录，可用「导出备份 / 导入备份」。

## 三、学习闭环怎么用

```
选一篇文章  →  ① 精读（查词+长难句解析）
            →  ② 精听（单句循环+盲听）
            →  ③ 写作（300词总结，AI四维批改）
            →  ④ 口语（AI教练讨论+反馈报告）
            →  生词自动进入「生词本」间隔复习
```

### 📖 精读
- **全屏阅读**：正文自动铺满整个屏幕，采用雅思阅读试卷式标题和段落排版，没有卡片边框或常驻侧栏。
- **指词翻译**：鼠标指到单词上（约 0.3 秒）就弹出释义和发音，可一键加入生词本；**点击单词**同样可以（触屏设备用点击）。不想被弹窗打扰，去「设置 → 阅读显示」取消「指词翻译」即可。
- **选中词句**：出现工具栏，可「翻译」「长难句解析」或「🖍 高亮」；高亮会自动保存，**直接点击正文里的黄色高亮即可取消**。
- **学习工具**：点右下角「学习工具」展开解析结果、我的标注和下一步学习；点标注可定位正文，按 Esc 或 × 收起。
- **📦 两篇文章免 API**：《FS Core Text SDG 11》（`js/sdg11-cache.js`）和《The Ethics of AI: Five Pressing Questions》（`js/ai-ethics-cache.js`）这两篇文章的**全部单词点译**和**全部句子的长难句解析**已经预先生成好、存在本地。读这两篇时：点任何单词、选任何句子点「长难句解析 / 翻译」，都是**瞬间出结果、不调用 API、不费 Key**（解析末尾会标注“本地预生成内容”）。即使选中整段，也会自动匹配段内最长的一句做解析。其他文章仍走 AI 实时生成。
- **📦 音标全离线**：文章里的每个单词都带英式音标（237/237），来自本地 CMU 发音词典转写，同样不联网。
- **绿色底纹是什么**：正文里单词上的浅绿色 = 这个词**已经在你的生词本里**。导入大量词汇（如 9389 个雅思词）后几乎全文发绿，所以**默认不再标记**；想恢复这个标记，去「设置 → 阅读显示」勾选「正文中的生词标记」。关掉它不影响生词本数据，只是不显示。

### 🎧 精听
精听有两种材料，入口都在「精听」页：

**① 听力素材库（真实音频，按周次）**
- 来自你 UNSW 课程里的 "progress support listening workshop" 录音，已按 Workshop 1–4 整理好。
- 点任意一条进入播放器：播放 / 暂停、-10s / +10s、进度条拖动、倍速（0.5x–2x）。
- **A-B 复读**：设 A 点 + 设 B 点，循环听这一段直到听懂。
- **原文 / 听写对照区**：把这段音频的原文或你的听写贴进去，自动保存，下次打开还在。
- 音频文件在本机课程文件夹。若浏览器拦截了自动加载，在播放器里点「导入此文件」手动选择即可（手机/平板上也走这条）。

**② 文章 TTS 精听**
- 没有音频时，点「▶ 播放」会用浏览器自带英语语音逐句朗读（免费）。
- **单句循环**：反复听同一句直到听懂。
- **隐藏原文**：先盲听 1-2 遍，再打开原文对照。
- 语速可调（0.6x - 1.2x）。

### ✍️ 写作
- 任务默认是：读完文章后写一篇 300 词左右的 summary。
- 提交后 AI 按雅思四项打分（TR 任务回应 / CC 连贯衔接 / LR 词汇 / GRA 语法），给出**逐句修改建议**和亮点。
- 也可以切换到「自由写作」模式，任意话题练习。

### 🗣️ 口语
- 点「开始对话」，AI 教练基于你刚读的文章提问。
- **可以打字，也可以点 🎤 语音输入**。
- 说满 3 轮以上，点「🏁 结束并获取反馈」：生成语法纠正、更地道的表达、提升建议报告。

### 📚 生词本
- 精读时收藏的所有单词都在这里。
- **一键导入雅思全部词汇**：生词本页顶部有「📥 导入雅思全部词汇」按钮，点一下就把内置的《雅思词汇9400词》表（共 9389 词，含中文释义与词性）整批加入生词本，已存在的词会自动跳过，不重复。导入后立刻能在「开始复习」里按记忆曲线刷词。词汇表来源：`D:\zhz\雅思\雅思词汇9400词EXCEL版-顺序版.xls`，由 `tools/build_from_xls.js` 转换生成 `prototype/js/ielts-words.js`。
- **音标**：9389 个词里约 97% 带英式音标（如 `abandon` /əˈbændən/），显示在生词卡片、复习卡片和查词弹窗里；SDG 11 文章的单词同样带音标。音标由 `tools/build_phonetics.js` 构建（CMU 发音词典转写 + 词典 API 补漏），纯本地数据，不联网。
- 点「🧠 开始复习」：先自己想意思，再显示释义，按「忘记 / 模糊 / 记住」评分，系统按**间隔重复算法**在合适的时间再次安排复习（类似 Anki，但是全自动的）。

## 六、常见问题

**Q：打开后一片空白 / 按钮点不动？**
A：请用 Chrome 或 Edge；确认你没有移动文件位置——`index.html` 要和 `css`、`js` 文件夹放在一起（整个 `prototype` 文件夹一起拷贝）。

**Q：提示“网络请求失败”？**
A：按顺序排查：
1. **如果你是在嵌入的预览窗口里看的**（比如在编辑器/对话框里点开的预览），该窗口有安全白名单，会直接拦掉外部 AI 请求——改用双击项目根目录的 **`启动网站.bat`**，用弹出的浏览器窗口使用即可。
2. 若已是浏览器窗口，点「设置 → 测试连接」看具体报错：确认 Base URL 是 `https://workbuddy.tokenmao.cn/v1`，模型是 `TM ·DeepSeek-V4`（或 `TM ·Fast`）。
3. 该服务商上游偶尔很慢（实测单次 0.7～16 秒波动），偶发超时属正常，重试一次通常就好；急用可把模型换成 `TM ·Fast`。
4. 公司/校园网络有防火墙时，可换手机热点试一次，判断是否网络限制。
5. 读《FS Core Text SDG 11》时的点词和长难句解析**本来就不走网络**（本地预生成），如果这篇还报错，先确认是不是打开了别的文章。

**Q：提示 401 / 429？**
A：401 = Key 错误或过期，重新复制完整的 Key；429 = 太频繁或余额不足，稍等或检查账户。

**Q：内置的 7 篇文章不够用？**
A：「素材库」里可以粘贴任何英文材料，或让 AI 按你指定的主题生成一篇 B2 难度的新文章。其中《FS Core Text SDG 11》来自你的 UNSW 课程材料（约 3200 词，从 Chapter 10 综述开始，含贫民窟改造、交通、污染治理与北京 PM2.5 案例），已置顶在素材库第一位；《The Ethics of AI: Five Pressing Questions》是雅思写作 Task 2 的讨论类素材（5 段 5 个伦理问题：自动驾驶、机器人武器、AI 司法、陪伴机器人、就业冲击），已**整篇离线**（词义/解析/音标 100% 本地）。

**Q：新文章怎么也做成离线的？**
A：`node tools/extract_article.js <文章id>` 抽取全部单词和句子 → 词义优先取本地雅思词库（`js/ielts-words.js`，零成本），缺口写进 `tools/work/<id>-extra.json` → `node tools/build_article_cache.js <文章id> <文件名> <全局变量名>` 生成 `js/<文件名>-cache.js` → 缓存自动注册进 `window.LIORA_LOCAL_CACHES[文章id]`，页面按文章 id 精确取用（不会串到别的文章）。

**Q：以后想换成手机 App？**
A：数据可以导出 JSON 备份，不会白学。手机版是后续产品化阶段的事。
