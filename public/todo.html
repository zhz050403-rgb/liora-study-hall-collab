为什么 APP 模式不会被电脑拦？
安装成应用时，系统启动的是你电脑上本来就装好的浏览器，不是从网上下载的脚本 —— 所以 Windows 不会弹「已保护你的电脑」，Mac 也不会提示「身份不明的开发者」。
按钮点了没弹窗？手动两下就好（Edge / Chrome）
点地址栏最右边的「安装」小图标；或右上角 ⋯ → 应用 → 安装此站点。确认后桌面出现「学习小屋 · 待办」，双击就是没有地址栏的独立小窗。
手机 / 平板：浏览器菜单 → 添加到主屏幕。
想要一直贴在桌面、不用点开的小卡片？
用下面「下载 Windows 版」，解压后双击 打开待办网页.url（纯文本，系统不拦），再点页面上的「安装成应用」；Mac 则下载真正的 .app 应用包。两个入口都在，想给别的电脑下包直接点另一个。
不管用哪种方式，待办都是同一份，打勾会同步到网站（同一账号）。
