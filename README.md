# 新南 2026 · 学习门户（学习助手）

这是你的私人学习门户，样式仿照大学官网：汇总本学年全部课程，按 Week 1–13 清晰列出每周的**课件文件、学习任务和自动生成的预习笔记**，并提供作业批改解析入口。

## 如何打开

- **正式网址（推荐）**：`https://liora-study-hall.app.workbuddy.host/` —— 手机/电脑都能开，进度存在云端账号。
- **本地编辑入口（仅维护时用）**：`网站/线上版/public/index.html`。所有 AI 都只改这一处，不要再去改旧的根目录 `网站/index.html`（已于 2026-11-05 退役，移入 `归档/`）。
- 修改后，在 WorkBuddy 应用点「更新发布」即可上线，用上面的网址核对。

## 如何更新门户（新增课件后）

每当你把新课件放进课程文件夹（或解开一个压缩包）后，在对话中对我说：「**更新门户**」即可。我会运行一键脚本自动完成：扫描新文件 → 增量提取文字（已提取的自动跳过）→ 重建 `data.js` → 校验全部链接。脚本还会检查哪些周次还没有预习笔记并提醒我补写。你不需要改任何代码，刷新浏览器即可看到最新内容。

## 如何添加新课程（理财 / 财经 / 法律等）

1. 把新的课程文件夹复制到 `新南2026` 目录下（与现有 `Course_ ...` 文件夹并列）；
2. 在对话中对我说：「**收录新课程**」；
3. 我会自动扫描文件结构、生成周次与预习笔记，刷新 `data.js`，本门户自动更新——你不需要改任何代码。

## 目录结构

```
网站/
├── 线上版/                 # 唯一正式维护入口
│   ├── server.js           # 登录、资源服务、AI 与进度 API
│   ├── public/             # 正式页面、课程数据、英语与阅读资源
│   ├── data/               # 按账号保存的学习进度（发布时保留）
│   └── checks/             # 使用模拟数据的回归检查
├── build/                  # 课程扫描、笔记生成、链接校验
└── 归档/                   # 历史版本，仅供查阅
```

## 学习档案使用流程

1. 把练习/考试发给我批改（对话中直接发照片/截图/文件）；
2. 批改后对我说「**记录这次批改**」——我会把成绩、错题涉及的知识点写入档案（或你在「学习档案」页手动录入）；
3. 随时打开「学习档案」页查看：累计提交、平均得分率、薄弱点排行（点击可筛选记录）、各课程情况、得分趋势图；
4. 建议定期点「导出档案 JSON」备份；换电脑后用「导入档案 JSON」恢复。

## 说明

- 课件链接指向原课程文件夹，门户只读取、不修改、不删除你的任何文件。
- 周次中标注「占位周 / 资料整理中」的，表示该周在课程平台上没有单独课件（复习周或尚未下载）。
- 正式网站的学习进度先保存在本机浏览器 localStorage，再同步至当前账号的云端记录；离线时保留本机记录，恢复网络后重试同步。不同账号的进度相互隔离。
